## Advanced Attribution Models

### Attribution Model Types

**1. First-Touch Attribution**:
- **Allocation**: 100% credit to first touchpoint
- **Best For**: Awareness campaigns
- **Cost Allocation**: Full cost to first channel

**2. Last-Touch Attribution**:
- **Allocation**: 100% credit to last touchpoint
- **Best For**: Conversion-focused campaigns
- **Cost Allocation**: Full cost to last channel

**3. Linear Attribution**:
- **Allocation**: Equal credit to all touchpoints
- **Best For**: Balanced view of customer journey
- **Cost Allocation**: Equal cost across all channels

**4. Time-Decay Attribution**:
- **Allocation**: More credit to recent touchpoints
- **Best For**: Time-sensitive campaigns
- **Cost Allocation**: Weighted by recency

**5. Position-Based Attribution**:
- **Allocation**: 40% first, 40% last, 20% middle
- **Best For**: Balanced awareness and conversion
- **Cost Allocation**: Weighted by position

**6. Data-Driven Attribution**:
- **Allocation**: ML-based credit assignment
- **Best For**: Advanced attribution needs
- **Cost Allocation**: ML-optimized allocation

### Attribution Cost Allocation Framework

```python
def allocate_marketing_costs(attribution_model, touchpoints, total_cost):
    """
    Allocate marketing costs based on attribution model.
    """
    if attribution_model == 'first_touch':
        allocation = {touchpoints[0]: total_cost}
    
    elif attribution_model == 'last_touch':
        allocation = {touchpoints[-1]: total_cost}
    
    elif attribution_model == 'linear':
        cost_per_touchpoint = total_cost / len(touchpoints)
        allocation = {tp: cost_per_touchpoint for tp in touchpoints}
    
    elif attribution_model == 'time_decay':
        # Weight by recency (exponential decay)
        weights = [0.5 ** (len(touchpoints) - i - 1) for i in range(len(touchpoints))]
        total_weight = sum(weights)
        allocation = {tp: (total_cost * w) / total_weight for tp, w in zip(touchpoints, weights)}
    
    elif attribution_model == 'position_based':
        # 40% first, 40% last, 20% middle
        if len(touchpoints) == 1:
            allocation = {touchpoints[0]: total_cost}
        elif len(touchpoints) == 2:
            allocation = {touchpoints[0]: total_cost * 0.5, touchpoints[1]: total_cost * 0.5}
        else:
            first_last_cost = total_cost * 0.4
            middle_cost = total_cost * 0.2 / (len(touchpoints) - 2)
            allocation = {
                touchpoints[0]: first_last_cost,
                touchpoints[-1]: first_last_cost
            }
            for tp in touchpoints[1:-1]:
                allocation[tp] = middle_cost
    
    return allocation
```

```
LTV:CAC = LTV / CAC
```
- **Target**: 3:1 or higher

- **Poor**: < 1:1

**4. Payback Period**:
```
Payback Period = CAC / (Average Revenue per Customer per Month)
```

**5. Marketing Efficiency Ratio (MER)**:
```
MER = Total Revenue / Total Marketing Spend
```
- **Target**: 4:1 or higher
- **Good**: 3:1
- **Poor**: < 2:1

```python
def forecast_marketing_costs(historical_data, growth_rate, new_tools_cost=0):
    """
    Forecast marketing costs based on historical data and growth.
    """
    # Calculate average monthly cost
    avg_monthly_cost = sum(month['cost'] for month in historical_data) / len(historical_data)
    
    # Forecast next 12 months
    forecast = []
    for month in range(1, 13):
        forecasted_cost = avg_monthly_cost * (1 + growth_rate) ** month + new_tools_cost
        forecast.append({
            'month': month,
            'forecasted_cost': forecasted_cost,
            'growth_rate': growth_rate
        })
    
    total_forecast = sum(month['forecasted_cost'] for month in forecast)
    
    return {
        'forecast': forecast,
        'total_forecast': total_forecast,
        'avg_monthly_cost': avg_monthly_cost,
```

## Advanced ROI Measurement Framework

### Comprehensive ROI Metrics

**1. Marketing ROI (MROI)**:
```
MROI = (Incremental Revenue - Marketing Cost) / Marketing Cost × 100
```

**2. Incremental Revenue**:
```
Incremental Revenue = Total Revenue - Baseline Revenue (without marketing)
```

**3. Marketing Efficiency Ratio (MER)**:
```
MER = Total Revenue / Total Marketing Spend
```

**4. Return on Ad Spend (ROAS)**:
```
ROAS = Revenue from Ads / Ad Spend
```

**5. Customer Acquisition Cost (CAC)**:
```
CAC = Total Marketing Cost / Number of New Customers
```

**6. Customer Lifetime Value (LTV)**:
```
LTV = Average Revenue per Customer × Average Customer Lifespan
```

**7. LTV:CAC Ratio**:
```
LTV:CAC = LTV / CAC
```

**8. Payback Period**:
```
Payback Period = CAC / (Average Revenue per Customer per Month)
```

**9. Marketing Contribution Margin**:
```
Marketing Contribution Margin = (Revenue - Marketing Cost) / Revenue × 100
```

**10. Cost Per Qualified Lead (CPQL)**:
```
CPQL = Marketing Cost / Number of Qualified Leads
```

### Advanced ROI Implementation

```python
def calculate_comprehensive_marketing_roi(
    total_revenue,
    baseline_revenue,
    marketing_costs,
    new_customers,
    avg_revenue_per_customer,
    avg_customer_lifespan_months,
    qualified_leads=0
):
    """
    Calculate comprehensive marketing ROI metrics.
    """
    # Incremental revenue
    incremental_revenue = total_revenue - baseline_revenue
    
    # Basic ROI
    roi = ((incremental_revenue - marketing_costs) / marketing_costs) * 100 if marketing_costs > 0 else 0
    
    # MER
    mer = total_revenue / marketing_costs if marketing_costs > 0 else 0
    
    # CAC
    cac = marketing_costs / new_customers if new_customers > 0 else 0
    
    # LTV
    ltv = avg_revenue_per_customer * avg_customer_lifespan_months
    
    # LTV:CAC Ratio
    ltv_cac_ratio = ltv / cac if cac > 0 else 0
    
    # Payback Period
    monthly_revenue_per_customer = avg_revenue_per_customer / avg_customer_lifespan_months
    payback_period = cac / monthly_revenue_per_customer if monthly_revenue_per_customer > 0 else 0
    
    # Marketing Contribution Margin
    contribution_margin = ((total_revenue - marketing_costs) / total_revenue) * 100 if total_revenue > 0 else 0
    
    # CPQL
    cpql = marketing_costs / qualified_leads if qualified_leads > 0 else None
    
    return {
        'incremental_revenue': incremental_revenue,
        'roi_percentage': roi,
        'mer': mer,
        'cac': cac,
        'ltv': ltv,
        'ltv_cac_ratio': ltv_cac_ratio,
        'payback_period_months': payback_period,
        'contribution_margin_percentage': contribution_margin,
        'cpql': cpql,
        'total_revenue': total_revenue,
        'marketing_costs': marketing_costs,
        'new_customers': new_customers
    }
```

```python
def detect_marketing_cost_anomalies(cost_data, threshold=2.0):
    """
    Detect cost anomalies in marketing tools spending.
    """
    import numpy as np
    from scipy import stats
    
    costs = [day['cost'] for day in cost_data]
    mean_cost = np.mean(costs)
    std_cost = np.std(costs)
    
    anomalies = []
    for day in cost_data:
        z_score = abs((day['cost'] - mean_cost) / std_cost) if std_cost > 0 else 0
        
        if z_score > threshold:
            anomalies.append({
                'date': day['date'],
                'cost': day['cost'],
                'z_score': z_score,
                'severity': 'high' if z_score > 3 else 'medium',
                'deviation': ((day['cost'] - mean_cost) / mean_cost) * 100,
                'potential_causes': identify_potential_causes(day)
            })
    
    return {
        'anomalies': anomalies,
        'total_anomalies': len(anomalies),
        'mean_cost': mean_cost,
        'std_cost': std_cost,
        'threshold': threshold
    }

def identify_potential_causes(day_data):

    if day_data.get('email_sends', 0) > day_data.get('avg_email_sends', 0) * 2:
```

```python
def forecast_marketing_costs_advanced(
    historical_data,
    growth_rate,
    seasonality_factor=1.0,
    new_tools_cost=0,
    forecast_months=12,
    confidence_level=0.95
):
    """
    Advanced marketing cost forecasting with seasonality and confidence intervals.
    """
    import numpy as np
    from scipy import stats
    
    # Extract monthly costs
    monthly_costs = [month['cost'] for month in historical_data]
    n = len(monthly_costs)
    
    # Calculate trend
    x = np.array(range(n))
    y = np.array(monthly_costs)
    slope, intercept, r_value, p_value, std_err = stats.linregress(x, y)
    
    # Forecast with seasonality
    forecast = []
    for month in range(1, forecast_months + 1):
        # Base forecast
        base_forecast = intercept + slope * (n + month)
        
        # Apply seasonality (simplified - would use actual seasonal decomposition)
        seasonal_adjustment = seasonality_factor if month % 12 in [10, 11, 0, 1] else 1.0  # Q4/Q1 higher
        adjusted_forecast = base_forecast * seasonal_adjustment
        
        # Add new tools cost
        final_forecast = adjusted_forecast + new_tools_cost
        
        # Calculate confidence interval
        t_value = stats.t.ppf((1 + confidence_level) / 2, n - 2)
        margin_error = t_value * std_err * np.sqrt(1 + 1/n + ((n + month) - np.mean(x))**2 / np.sum((x - np.mean(x))**2))
        
        forecast.append({
            'month': n + month,
            'forecasted_cost': max(0, final_forecast),
            'lower_bound': max(0, final_forecast - margin_error),
            'upper_bound': final_forecast + margin_error,
            'confidence_level': confidence_level,
            'seasonal_adjustment': seasonal_adjustment
        })
    
    total_forecast = sum(month['forecasted_cost'] for month in forecast)
    
    return {
        'forecast': forecast,
        'total_forecast': total_forecast,
        'trend': 'increasing' if slope > 0 else 'decreasing',
        'r_squared': r_value**2,
        'growth_rate': growth_rate,
        'seasonality_factor': seasonality_factor
    }
```

- **Budget Planning**: Annual billing helps with budget predictability
- **Commitment**: Only commit annually if confident in platform choice
