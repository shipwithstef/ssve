# Cloud Platform Referral Programs Guide (2025)

## Overview

Comprehensive guide to referral programs across cloud platforms and hosting services to maximize credits and reduce costs.

## Major Cloud Platforms

### AWS Referral Program
**Status**: Available (varies by region)

**Benefits**:
- **Referrer**: $25-100 AWS credits
- **Referee**: $25-100 AWS credits (new accounts)
- **Requirements**: Valid referral link, new account signup
- **Limitations**: One-time credits, terms apply

**How to Use**:
1. Get referral link from AWS partner or affiliate
2. Share with new users
3. Both parties receive credits when account activated
4. Credits apply to eligible services

**Best For**: New AWS users, reducing initial costs

### Google Cloud Referral Program
**Status**: Available

**Benefits**:
- **Referee**: $300 free credits (new accounts)
- **Duration**: 90 days to use credits
- **Requirements**: New GCP account, valid payment method
- **Limitations**: Credits expire after 90 days

**How to Use**:
1. Sign up for new GCP account
2. Use referral code if available
3. Receive $300 credits
4. Use within 90 days

**Best For**: New GCP users, testing services

### DigitalOcean Referral Program
**Status**: Available

**Benefits**:
- **Referrer**: $25 credits per successful referral
- **Referee**: $200 free credits (new accounts)
- **Requirements**: Valid referral link, new account
- **Limitations**: Credits expire after 60 days

**How to Use**:
1. Get referral link from DigitalOcean account
2. Share with new users
3. Referee gets $200 credits
4. Referrer gets $25 credits

**Best For**: Reducing DigitalOcean costs, team signups

### Hetzner Referral Program
