## Pricing Overview

### Token-Based Pricing Model

All major AI providers use token-based pricing:
- **Input Tokens**: Tokens in prompts, system messages, and context
- **Output Tokens**: Tokens generated by the model
- **Token Conversion**: ~750 words = 1,000 tokens (varies by model)

### Pricing Factors

1. **Model Tier**: Higher-tier models cost more
2. **Input vs Output**: Output tokens typically cost 2-10x input tokens
3. **Context Window**: Larger context windows may have different pricing
4. **Caching**: Cached inputs cost significantly less
5. **Batch Processing**: Batch mode offers 50% discounts
6. **Volume Discounts**: Higher volume may qualify for discounts

```python
def calculate_audio_processing_costs(audio_minutes, transcription_needed=True, tts_characters=0, tts_hd=False):
    """
    Calculate audio processing costs.
    """
    costs = {}

    if transcription_needed:
        whisper_cost = audio_minutes * 0.006
        costs['whisper_transcription'] = whisper_cost

    if tts_characters > 0:
        tts_rate = 30.00 if tts_hd else 15.00  # per million characters
        tts_cost = (tts_characters / 1000000) * tts_rate
        costs['tts_generation'] = tts_cost

    total_cost = sum(costs.values())

    return {
        'audio_minutes': audio_minutes,
        'transcription_cost': costs.get('whisper_transcription', 0),
        'tts_cost': costs.get('tts_generation', 0),
        'total_cost': total_cost
    }
```

```python
def calculate_batch_savings(input_tokens, output_tokens, model='GPT-5'):
    """
    Calculate savings from batch processing.
    """
    pricing = {
        'GPT-5': {'input': 1.25, 'output': 10.00},
        'GPT-5 Mini': {'input': 0.25, 'output': 2.00},
        'GPT-5 Nano': {'input': 0.05, 'output': 0.40}
    }

    model_pricing = pricing.get(model, pricing['GPT-5'])

    # Standard pricing
    standard_cost = (
        (input_tokens / 1000000) * model_pricing['input'] +
        (output_tokens / 1000000) * model_pricing['output']
    )

    # Batch pricing (50% discount)
    batch_cost = standard_cost * 0.5

    savings = standard_cost - batch_cost

    return {
        'standard_cost': standard_cost,
        'batch_cost': batch_cost,
        'savings': savings,
        'savings_percentage': 50
    }
```

```python
def calculate_fine_tuning_costs(training_tokens, inference_input_tokens, inference_output_tokens, model='GPT-4.1'):
    """
    Calculate fine-tuning costs.
    """
    pricing = {
        'GPT-4.1': {
            'training': 25.00,
            'input': 3.00,
            'cached_input': 0.75,
            'output': 12.00
        },
        'GPT-4.1 Mini': {
            'training': 5.00,
            'input': 0.80,
            'cached_input': 0.20,
            'output': 3.20
        },
        'GPT-4.1 Nano': {
            'training': 1.50,
            'input': 0.20,
            'cached_input': 0.05,
            'output': 0.80
        }
    }

    model_pricing = pricing.get(model, pricing['GPT-4.1'])

    # Training cost (one-time)
    training_cost = (training_tokens / 1000000) * model_pricing['training']

    # Inference costs (ongoing)
    # Assume 50% cache hit rate
    cache_hit_rate = 0.5
    cached_tokens = inference_input_tokens * cache_hit_rate
    uncached_tokens = inference_input_tokens * (1 - cache_hit_rate)

    inference_cost = (
        (cached_tokens / 1000000) * model_pricing['cached_input'] +
        (uncached_tokens / 1000000) * model_pricing['input'] +
        (inference_output_tokens / 1000000) * model_pricing['output']
    )

    return {
        'training_cost': training_cost,
        'inference_cost': inference_cost,
        'total_cost': training_cost + inference_cost,
        'break_even_analysis': {
            'training_cost': training_cost,
            'cost_per_inference': inference_cost / (inference_input_tokens / 1000) if inference_input_tokens > 0 else 0
        }
    }
```

```python
def calculate_context_caching_savings(context_tokens, cache_hit_rate, content_type='text'):
    """
    Calculate savings from context caching.
    """
    # Standard input pricing (Gemini 2.5 Flash example)
    standard_input_price = 0.075  # per million tokens

    # Caching pricing
    if content_type == 'audio':
        cache_price = 0.175
    else:  # text/image/video
        cache_price = 0.025

    # Calculate costs
    cached_tokens = context_tokens * cache_hit_rate
    uncached_tokens = context_tokens * (1 - cache_hit_rate)

    standard_cost = (context_tokens / 1000000) * standard_input_price
    cached_cost = (
        (cached_tokens / 1000000) * cache_price +
        (uncached_tokens / 1000000) * standard_input_price
    )

    savings = standard_cost - cached_cost

    return {
        'context_tokens': context_tokens,
        'cache_hit_rate': cache_hit_rate,
        'standard_cost': standard_cost,
        'cached_cost': cached_cost,
        'savings': savings,
        'savings_percentage': (savings / standard_cost) * 100 if standard_cost > 0 else 0
    }
```

```python
def multi_provider_load_balancer(request, providers):
    """
    Load balance across multiple providers for cost optimization.
    """
    # Get current pricing for each provider
    provider_costs = {}
    for provider in providers:
        cost = estimate_cost(request, provider)
        availability = check_availability(provider)
        provider_costs[provider] = {
            'cost': cost,
            'availability': availability,
            'score': availability / cost  # Higher score = better
        }

    # Select provider with best cost/availability ratio
    best_provider = max(provider_costs.items(), key=lambda x: x[1]['score'])

    return {
        'selected_provider': best_provider[0],
        'estimated_cost': best_provider[1]['cost'],
        'all_options': provider_costs
    }
```

```python
def dynamic_model_selection(request, cost_constraint, quality_requirement):
```

### 3. Request Batching & Queuing

**Strategy**: Batch requests to reduce per-request overhead and leverage batch discounts.

```python
def intelligent_batching(requests, max_batch_size=100, max_wait_time=60):
    """
    Intelligently batch requests for cost optimization.
    """
    batches = []
    current_batch = []
    last_batch_time = time.time()

    # Sort requests by priority
    sorted_requests = sorted(requests, key=lambda x: x.get('priority', 0), reverse=True)

    for request in sorted_requests:
        # Check if request can be batched
        if request.get('batchable', True):
            current_batch.append(request)

            # Check if batch is full or timeout reached
            if len(current_batch) >= max_batch_size or (time.time() - last_batch_time) > max_wait_time:
                batches.append({
                    'requests': current_batch,
                    'batch_size': len(current_batch),
                    'estimated_savings': calculate_batch_savings(current_batch)
                })
                current_batch = []
                last_batch_time = time.time()
        else:
            # Non-batchable request - process immediately
            batches.append({
                'requests': [request],
                'batch_size': 1,
                'estimated_savings': 0
            })

    # Add remaining requests
    if current_batch:
        batches.append({
            'requests': current_batch,
            'batch_size': len(current_batch),
            'estimated_savings': calculate_batch_savings(current_batch)
        })

    total_savings = sum(b['estimated_savings'] for b in batches)

    return {
        'batches': batches,
        'total_batches': len(batches),
        'total_savings': total_savings,
        'savings_percentage': (total_savings / sum(estimate_cost(r) for r in requests)) * 100
    }
```

```python
def calculate_api_cost(input_tokens, output_tokens, model, provider):
    """
    Calculate API cost for given token usage.
    """
    pricing = {
        'openai': {
            'GPT-5': {'input': 1.25, 'output': 10.00},

        'input_cost': input_cost,

        'total_cost': total_cost,
        'model': model,

    }
```

```python
def batch_requests(requests, batch_size=100, max_wait_time=60):
    """
    Batch requests for cost optimization.
    """
    batches = []
    current_batch = []
    last_batch_time = time.time()

    for request in requests:
        # Add to current batch
        current_batch.append(request)

        # Check if batch is full or timeout reached
        if len(current_batch) >= batch_size or (time.time() - last_batch_time) > max_wait_time:
            batches.append(current_batch)
            current_batch = []
            last_batch_time = time.time()

    # Add remaining requests
    if current_batch:
        batches.append(current_batch)

    # Calculate savings
    individual_cost = sum(calculate_request_cost(r) for r in requests)
    batched_cost = sum(calculate_batch_cost(batch) for batch in batches) * 0.5  # 50% discount

    savings = individual_cost - batched_cost

    return {
        'batches': len(batches),
        'individual_cost': individual_cost,
        'batched_cost': batched_cost,
        'savings': savings,
        'savings_percentage': (savings / individual_cost) * 100
    }
```

```python
    intercept = (sum(y) - slope * sum(x)) / n

    # Forecast
    forecast = []
    for day in range(forecast_days):
        predicted_cost = intercept + slope * (n + day)
        forecast.append({
            'day': n + day,
            'predicted_cost': max(0, predicted_cost)  # No negative costs
        })

    total_forecast = sum(day['predicted_cost'] for day in forecast)

    return {
        'forecast': forecast,
        'total_forecast': total_forecast,
        'daily_average': total_forecast / forecast_days,
        'trend': 'increasing' if slope > 0 else 'decreasing'
    }
```

```python
class IntelligentCache:
    """
    Multi-level caching system for cost optimization.
    """
    def __init__(self):
        self.cache_levels = {
            'exact_match': {},  # Hash-based exact match
            'semantic': {},  # Semantic similarity cache
            'template': {}  # Template-based cache
        }
        self.cache_stats = {
            'hits': 0,
            'misses': 0,
            'savings': 0
        }

    def get_cached(self, prompt, model):
        """
        Check cache at all levels.
        """
        # Level 1: Exact match
        cache_key = hash(prompt)
        if cache_key in self.cache_levels['exact_match']:
            self.cache_stats['hits'] += 1
            return {
                'cached': True,
                'level': 'exact_match',
                'result': self.cache_levels['exact_match'][cache_key],
                'savings': 0.90  # 90% discount
            }

        # Level 2: Semantic similarity
        semantic_key = self.get_semantic_key(prompt)
        if semantic_key in self.cache_levels['semantic']:
            similarity = self.calculate_similarity(prompt, self.cache_levels['semantic'][semantic_key]['prompt'])
            if similarity > 0.95:  # 95% similar
                self.cache_stats['hits'] += 1
                return {
                    'cached': True,
                    'level': 'semantic',
                    'result': self.cache_levels['semantic'][semantic_key]['result'],
                    'savings': 0.70  # 70% discount (approximate)
                }

        # Level 3: Template match
        template_key = self.extract_template(prompt)
        if template_key in self.cache_levels['template']:
            self.cache_stats['hits'] += 1
            return {
                'cached': True,
                'level': 'template',
                'result': self.cache_levels['template'][template_key],
                'savings': 0.50  # 50% discount
            }

        self.cache_stats['misses'] += 1
        return {'cached': False}

    def cache_result(self, prompt, result, level='exact_match'):
        """
        Cache result at specified level.
        """
        if level == 'exact_match':
            cache_key = hash(prompt)
            self.cache_levels['exact_match'][cache_key] = result

        elif level == 'semantic':
            semantic_key = self.get_semantic_key(prompt)
            self.cache_levels['semantic'][semantic_key] = {
                'prompt': prompt,
                'result': result
            }

        elif level == 'template':
            template_key = self.extract_template(prompt)
            self.cache_levels['template'][template_key] = result
```

```python
def forecast_costs_advanced(historical_data, forecast_days=30, confidence_level=0.95):
    """
    Advanced cost forecasting with confidence intervals.
    """
    import numpy as np
    from scipy import stats

    # Extract daily costs
    daily_costs = [day['cost'] for day in historical_data]

    # Calculate trend using linear regression
    n = len(daily_costs)
    x = np.array(range(n))
    y = np.array(daily_costs)

    # Linear regression
    slope, intercept, r_value, p_value, std_err = stats.linregress(x, y)

    # Forecast with confidence intervals
    forecast = []
    for day in range(forecast_days):
        predicted_cost = intercept + slope * (n + day)

        # Calculate confidence interval
        t_value = stats.t.ppf((1 + confidence_level) / 2, n - 2)
        margin_error = t_value * std_err * np.sqrt(1 + 1/n + ((n + day) - np.mean(x))**2 / np.sum((x - np.mean(x))**2))

        forecast.append({
            'day': n + day,
            'predicted_cost': max(0, predicted_cost),
            'lower_bound': max(0, predicted_cost - margin_error),
            'upper_bound': predicted_cost + margin_error,
            'confidence_level': confidence_level
        })

    total_forecast = sum(day['predicted_cost'] for day in forecast)

    return {
        'forecast': forecast,
        'total_forecast': total_forecast,
        'trend': 'increasing' if slope > 0 else 'decreasing',
        'r_squared': r_value**2,
        'p_value': p_value,
        'confidence_intervals': True
    }
```

### Streaming Response Cost Calculation

#### Streaming Token Counting
```python
def calculate_streaming_cost(stream_response, model="gpt-4o"):
    """Calculate cost for streaming responses"""
    pricing = {
        'gpt-4o': {'input': 2.50, 'output': 5.00},
        'gpt-3.5-turbo': {'input': 0.30, 'output': 0.60}
    }

    input_tokens = stream_response.usage.prompt_tokens
    output_tokens = stream_response.usage.completion_tokens

    if model in pricing:
        input_cost = (input_tokens / 1_000_000) * pricing[model]['input']
        output_cost = (output_tokens / 1_000_000) * pricing[model]['output']
        return input_cost + output_cost

    return 0
```

#### Streaming Considerations
- **Same Pricing**: Streaming uses same pricing as non-streaming
- **Token Counting**: Count tokens as they arrive
- **Partial Responses**: Cost calculated on complete response
- **Early Stopping**: May reduce costs if stopped early

```python
class MultiLevelCache:
    """Multi-level cache for LLM responses"""

    def __init__(self):
        self.exact_cache = {}  # Exact match cache
        self.semantic_cache = None  # Semantic similarity cache
        self.ttl_cache = {}  # TTL-based cache

    def get(self, prompt):
        # Level 1: Exact match
        if prompt in self.exact_cache:
            return self.exact_cache[prompt]

        # Level 2: Semantic similarity
        if self.semantic_cache:
            similar = self.semantic_cache.find_similar(prompt)
            if similar:
                return similar['response']

        # Level 3: TTL cache
        if prompt in self.ttl_cache:
            cached = self.ttl_cache[prompt]
            if cached['expires'] > time.time():
                return cached['response']

        return None

    def put(self, prompt, response, ttl=3600):
        """Cache response with TTL"""
        self.exact_cache[prompt] = response
        self.ttl_cache[prompt] = {
            'response': response,
            'expires': time.time() + ttl
        }

        if self.semantic_cache:
            self.semantic_cache.add(prompt, response)
```

```python
class PromptCompressor:
    """Compress prompts to reduce token usage"""

    def compress_prompt(self, prompt, method='remove_stopwords'):
        """Compress prompt using various methods"""
        if method == 'remove_stopwords':
            return self._remove_stopwords(prompt)
        elif method == 'summarize':
            return self._summarize_prompt(prompt)
        elif method == 'remove_redundancy':
            return self._remove_redundancy(prompt)
        elif method == 'abbreviate':
            return self._abbreviate(prompt)
        else:
            return prompt

    def _remove_stopwords(self, prompt):
        """Remove stopwords from prompt"""
        stopwords = {'the', 'a', 'an', 'and', 'or', 'but', 'in', 'on', 'at', 'to', 'for'}
        words = prompt.split()
        compressed = [w for w in words if w.lower() not in stopwords]
        return ' '.join(compressed)

    def _remove_redundancy(self, prompt):
        """Remove redundant phrases"""
        # Remove duplicate sentences
        sentences = prompt.split('.')
        unique_sentences = []
        seen = set()

        for sentence in sentences:
            sentence_lower = sentence.lower().strip()
            if sentence_lower and sentence_lower not in seen:
                seen.add(sentence_lower)
                unique_sentences.append(sentence)

        return '. '.join(unique_sentences)

    def _abbreviate(self, prompt):
        """Abbreviate common phrases"""
        abbreviations = {
            'please': 'pls',
            'information': 'info',
            'application': 'app',
            'maximum': 'max',
            'minimum': 'min',
            'approximately': 'approx'
        }

        words = prompt.split()
        abbreviated = [abbreviations.get(w.lower(), w) for w in words]
        return ' '.join(abbreviated)
```

```python
                    'increase': cost - avg_cost,
                    'increase_percentage': ((cost - avg_cost) / avg_cost) * 100
                })

        return {
            'anomalies': anomalies,
            'recommendations': self._generate_recommendations(anomalies)
        }

    def _generate_recommendations(self, anomalies):
        """Generate recommendations for anomalies"""
        recommendations = []

        for anomaly in anomalies:
            if anomaly['increase_percentage'] > 200:
                recommendations.append({
                    'service': anomaly['service'],
                    'severity': 'critical',
                    'action': 'Immediate investigation required',
                    'steps': [
                        'Check for resource leaks',
                        'Review recent deployments',
                        'Check for misconfigured auto-scaling'
                    ]
                })

        return recommendations
```

## Major Serverless Function Platforms

### AWS Lambda

#### Free Tier
- **Duration**: Always free (not time-limited)
- **Requests**: 1 million requests per month
- **Compute Time**: 400,000 GB-seconds per month
- **Example**: ~3.2 million seconds at 128MB memory, or ~333,333 seconds at 1GB memory

#### Pricing Model
- **Requests**: $0.20 per 1 million requests (after free tier)
- **Compute**: $0.0000166667 per GB-second (after free tier)
- **Provisioned Concurrency**: $0.015 per hour per GB provisioned
- **Duration**: Billed per millisecond (minimum 1ms)

#### Cost Calculation
```
Monthly Cost = (Request Cost) + (Compute Cost) + (Provisioned Concurrency Cost)

Request Cost = (Requests - 1M) × $0.20 / 1M
Compute Cost = (GB-seconds - 400K) × $0.0000166667
GB-seconds = Memory (GB) × Duration (seconds) × Invocations
```

#### Example Scenarios
- **Small App**: 100K requests/month, 128MB, 200ms avg = $0 (within free tier)
- **Medium App**: 5M requests/month, 512MB, 500ms avg = ~$0.80 + ~$1.07 = $1.87/month
- **Large App**: 50M requests/month, 1GB, 1s avg = ~$9.80 + ~$13.33 = $23.13/month
