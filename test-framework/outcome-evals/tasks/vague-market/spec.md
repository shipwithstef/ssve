# A message from the founder

I want a small browser game where you run a market stall: buy goods, sell goods and grow your coins over the days. The economy has to stay interesting. It must not break: no infinite-money tricks, and prices should react to what the player does. Make it feel like a real little game, not a form.

Constraints: Node's standard library only, no npm packages. `server.mjs` serves the game on `process.env.PORT` (default 3000), and `node server.mjs` must start it. The game logic and money must live on the server so players can't cheat from the browser.
