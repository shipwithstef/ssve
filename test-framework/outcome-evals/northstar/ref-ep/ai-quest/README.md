# Patch Island

A point-and-click comedy adventure about AI engineering, played in the browser with the
mouse or the keyboard.

## Run

    npm install
    npm start

It serves on `PORT` (default 3000). Open `/` to play. The game rules live in `game/quest.mjs`
and run in Node without a browser.

## Test

    npm test

Plays `docs/walkthrough.json` to the end and checks the traps. Design notes and the
curriculum map are in `docs/`.
