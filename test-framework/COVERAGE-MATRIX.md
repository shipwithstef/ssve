## How to Add Coverage

### Add a tier-1.5 comprehension prompt
1. Create `test-framework/evals/tier-1.5/prompts/<skill>.txt`
2. Update `evals.json` tier-1.5 skill-comprehension skills_tested array
3. Run `bash test-framework/evals/tier-1.5/test-skill-comprehension.sh`

### Add a tier-2 integration scenario
1. Create `test-framework/evals/tier-2/scenarios/<name>.md`
2. Use a fixture if the skill needs project context
3. Update `evals.json` tier-2 scenarios array
4. Run `bash test-framework/evals/tier-2/run-tier2.sh`

### Add a health check scenario
1. Create `scripts/health-scenarios/<name>.mjs`
2. Export `name`, `setup()`, `prompt()`, and `checks[]`
3. Run `node scripts/kimi-health-check.mjs`

### Add a fixture
1. Create `test-framework/fixtures/<name>/`
2. Initialize git: `git init && git add -A && git commit -m "initial"`
3. Create `FIXTURE-README.md` documenting purpose and tested skills
4. Reference in tier-2 scenario Setup sections
