- `installed-failure.json` preserves the exact first failed activation replay: installed command, original payload (including spaces), stdout and stderr. Source: the owner's `side01-20261003T164818Z/evidence/installed-replays.jsonl`. The original parser rejected the spaced quoted `workdir` key; the compact synthetic JSON did not reproduce it.
- `installed-hook-shapes.json` inventories all 25 distinct managed command/event/matcher shapes in that evidence's installed Claude/Codex/Cursor configuration. Only source/launcher path roots are replaced by placeholders. The test replays every shell-applicable shape and preserves the Codex boundary → durable launcher → dispatcher chain.
- `native-code-envelopes.json` preserves 16 actual code-mode transport/renderer syntaxes from the bounded recent-log sample. Only literal `cmd` and `workdir` values are redacted; whitespace, quoting, property access, parentheses, renderers and batching remain native. File/line and original record hashes allow private-source correlation without committing transcripts.
- `sampling.json` records the 120-file sampling window and observed top-level tool names. This recent sample contained `exec` code-mode calls, with nested `tools.exec_command`; it contained no top-level `shell` or `exec_command` calls. Native shell aliases and Claude/Cursor payloads have separate regression controls.

Tests never execute fixture shell commands. They submit envelopes to candidate hook commands materialized under a disposable HOME. The recorded payload itself is replayed unchanged; only installed executable paths are relocated. Every native read shape also has a paired mixed-mutation envelope tested in advisory and enforce modes. Dynamic JavaScript, callbacks that call tools, shell substitutions and executable flags remain governed.
