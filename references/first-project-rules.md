# First Project Rules

## The 9 Rules

1. **Ship in 1-2 weeks** — not months
2. **Built-in distribution** — viral mechanic, existing audience, or marketplace
3. **No entity needed** — Dodo/Gumroad/LemonSqueezy handle payments
4. **Dead simple revenue model** — one price, one tier
5. **Proven demand** — someone already pays for similar
6. **Free-tier infra** — $0 out of pocket
7. **$1K+/mo evidence** — comparable products make this much
8. **Builder would use it** — founder-market fit
9. **Measurable in 30 days** — know if it's working fast

## Builder Journey

First project breaks the $0→$1 barrier.
Second project leverages lessons from first.
Third+ projects build on audience and infrastructure.

The first project is about learning to ship AND sell, not about the perfect idea.
