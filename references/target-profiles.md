# Target Profiles

## Revenue Bar

| Stage | MRR | What It Means |
|-------|-----|---------------|
| First dollar | $1 | Psychological barrier broken |
| Ramen profitable | $500-2,000 | Covers basic living |
| Sustainable | $2,000-5,000 | Can quit side gig |
| Full-time | $10,000-50,000 | Replaces salary |

## Bootstrapping Mode

For builders with $0 budget and 2-4 hrs/week:
- Target: $500-2,000 MRR in 90 days
- Build time: 1-2 weeks per product
- Ship multiple small products, double down on what gets traction
- Portfolio approach over single home run

## Break-Even Math

```
monthly_cost = infra + tools
monthly_revenue = customers × price
break_even_customers = monthly_cost / price
```

For $0 infra: break_even = 1 customer at any price.
