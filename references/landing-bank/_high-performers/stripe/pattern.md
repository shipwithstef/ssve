# Stripe — Financial infrastructure to grow your revenue

**URL:** https://stripe.com
**Captured:** 2026-04-27 (pattern.md only; hero.png/.webm TODO-capture)
**Sector:** high-performer-cross-sector (sharp-utilitarian-dev-tool)

## What it does well

- **Hero gradient is the brand asset, not decoration.** Iconic flowing-gradient mesh has become a visual signature so distinct that competitors imitate it; the gradient itself functions as a recognition cue with no logo needed.
- **Dual-track hero: "for developers" + "for businesses" via tabbed nav.** Single page serves two distinct buyer personas without creating duplicate landing pages — tab-switch reveals different value props (technical vs. operational).
- **Code-snippet panel right-side of hero with real working API call.** Shows the actual `stripe.charges.create({...})` payload — developer skims and instantly sees "this is the API I'd write." Snippet uses real product fields, not placeholder examples.
- **Customer logo strip is end-to-end famous: Amazon, Google, Salesforce, Shopify.** When you have THE famous logos, leading with logos works. When you don't, this archetype fails — Stripe earned this position with 10 years of category leadership.
- **Product matrix replaces feature list mid-page.** A 4×3 grid of Stripe products (Payments, Connect, Billing, Tax, Climate, Atlas, etc.) — visualizes the platform breadth without enumerating in prose.
- **Documentation linked equally with product nav.** "Docs" sits alongside "Products" / "Solutions" in the top nav — signals docs-as-product-surface, which the developer audience reads as quality signal.
- **Per-region landing variants (japan.stripe.com, india.stripe.com).** Country-localized hero with country-specific compliance value props (consumption tax, UPI integration). True localization, not just translation.
- **Stripe Sessions (annual conference) integrated into nav.** Owned-event functions as a category-leadership moat — competitors can't replicate the cultural-gravity of an industry-wide event.
- **Industry sub-pages (SaaS / Marketplaces / Platforms / Retail) each have unique value-prop framing.** Same products, four distinct buyer narratives — sophisticated audience segmentation without duplicating product story.

## What it gets wrong

- Page is so dense that smaller competitors (Lemon Squeezy, Polar) are wedging in as "the simpler alternative" — the surface area itself becomes a liability for SMB buyers.
- Pricing page is comprehensive but requires holding 4 dimensions in mind (currency, country, product, volume) — small operators struggle to forecast their bill.
- Brand consistency is so strong that any sub-page that deviates feels off — high cost-of-change for the design system.

## Reusable archetype name

**Dual-persona hero with code-snippet authority** — single page serves two distinct buyer personas via tab-switch (technical + operational), real working code snippet shown in hero panel as authority signal, branded gradient functions as recognition cue, end-to-end famous logos earn front-of-page placement.

## When to use this archetype

When the product genuinely serves two distinct buyer types (developer + business owner) AND has earned the right to logo-led trust through category leadership. The dual-track risks confusion if either persona is weak. NOT a fit for: single-persona products, early-stage products without famous customers.

## Feature mix surfaced

- "Financial infrastructure for the internet": full-page hero + branded gradient
- "Code-first API for developers": tabbed hero panel + real Stripe.charges.create snippet
- "Complete platform: Payments, Billing, Connect, Tax, Climate": product-grid matrix mid-page

## Adoption notes

When porting this archetype, the most common mistake is copying the surface aesthetic without copying the underlying buyer-context that makes it work. Verify the buyer-segment fit BEFORE imitating the visual signature — the archetype name names the technique, not just the look. If the buyer-context match is weak, downgrade to a borrowed sub-element (one bullet) rather than the whole pattern.
