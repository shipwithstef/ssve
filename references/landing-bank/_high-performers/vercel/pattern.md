# Vercel — Build and deploy the best web experiences with The Frontend Cloud

**URL:** https://vercel.com
**Captured:** 2026-04-27 (pattern.md only; hero.png/.webm TODO-capture)
**Sector:** high-performer-cross-sector (sharp-utilitarian-dev-tool)

## What it does well

- **Hero command-line snippet with a single working command.** `npm i -g vercel && vercel` shown literally in hero — demonstrates the "deploy in 30 seconds" claim instead of asserting it. Developers can mentally execute the snippet.
- **Geographic deploy-region map as hero secondary visual.** Shows global edge-network as physical map with live deploy pulses — communicates the platform-scale value prop visually.
- **"Made by the creators of Next.js" trust hook in hero region.** Founder-cred used as primary trust signal (rather than logos). Works because Next.js authority transfers directly to Vercel-hosting trust.
- **Customer-story tiles use real performance numbers as the headline.** "Stripe — 50% faster builds" rather than "Stripe loves Vercel." Numeric outcomes scale the credibility.
- **Hero CTA pair: "Start Deploying" (primary) + "Get a Demo" (secondary).** Self-serve PRIMARY, sales secondary — signals the buying motion (PLG default, sales for enterprise) clearly with visual hierarchy.
- **AI-stack section integrated into main scroll, not a separate page.** When the category shifted (LLMs), Vercel didn't bolt on an "AI" microsite — they integrated AI templates and AI SDK into the main narrative. Signals product velocity.
- **Footer separates "Resources" / "Company" / "Legal" / "Solutions" — four columns of dense links.** Discoverable depth for the high-context developer audience.
- **Live deployment-counter ticker on enterprise sub-page.** Real-time count of deploys-per-second functions as a scale-proof — visitors see "this platform is live and busy right now."
- **Templates gallery is one click from hero.** Reduces empty-state objection — visitors can clone-and-deploy a working app in 60 seconds without writing code.

## What it gets wrong

- "The Frontend Cloud" tagline is internal-marketing-speak; developers don't think in "cloud categories." A more concrete tagline would convert better.
- Pricing page "Pro $20/user" hides per-bandwidth and per-build-minute overage costs — surprise-bill risk that Vercel's developer audience particularly hates.
- Hobby-tier branding ("Hobby") is condescending — many indie devs use Vercel for revenue products and dislike being labeled hobbyists.

## Reusable archetype name

**Command-line-snippet hero with founder-credibility transfer** — hero shows a working CLI command instead of stating the value prop, founder/parent-product cred used as primary trust signal, customer outcomes are numeric performance gains, self-serve CTA primary with sales CTA secondary.

## When to use this archetype

When the product can be tried with a single command AND there's a founder/parent-product whose authority transfers. Works best for dev-tools where the buyer is the user. NOT a fit for: products with multi-step setup, products without strong founder/parent-product cred.

## Feature mix surfaced

- "Deploy in seconds with `vercel` CLI": full-page hero command snippet + global edge map
- "Made by the creators of Next.js": founder-trust badge below hero
- "AI Cloud — build agents and AI apps with Vercel AI SDK": dedicated mid-scroll section with template gallery

## Adoption notes

When porting this archetype, the most common mistake is copying the surface aesthetic without copying the underlying buyer-context that makes it work. Verify the buyer-segment fit BEFORE imitating the visual signature — the archetype name names the technique, not just the look. If the buyer-context match is weak, downgrade to a borrowed sub-element (one bullet) rather than the whole pattern.
