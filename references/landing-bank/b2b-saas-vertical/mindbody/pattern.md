# Mindbody — The wellness platform that fills your classes and grows your business

**URL:** https://www.mindbodyonline.com/business
**Captured:** 2026-04-27 (pattern.md only; hero.png/.webm TODO-capture)
**Sector:** b2b-saas-vertical (fitness/wellness studio software)

## What it does well

- **Hero leads with the demand-generation angle, not the management angle.** Most studio-software competitors lead with "manage classes/payments/staff" — Mindbody leads with "fill your classes" because the consumer-marketplace side (Mindbody app) is the unique moat. Leads with what only THEY can offer.
- **Hero visual shows two screens side-by-side: studio-owner dashboard + consumer-app booking flow.** Visualizes the two-sided network in one frame — owner sees the value flow (consumers booking → my class fills → revenue lands).
- **Studio-type segmentation strip uses visual icons, not text.** Yoga / Pilates / Salon / Spa / Gym icons — visitor self-identifies in 1 second; no reading required. Matches how visual-first wellness operators evaluate.
- **Hero subhead uses "X million bookings/month" through marketplace.** Numeric proof of marketplace size — the visitor immediately understands the demand-generation claim is real, not aspirational.
- **Customer story carousel uses video testimonials with revenue-uplift quotes.** "Tripled my class fill rate in 4 months" beats generic "great product" testimonials. Revenue-specific, time-bound, video-format = high credibility.
- **Pricing tiers anchored by feature need, not user-count.** "Starter / Accelerate / Ultimate / Ultimate Plus" map to business-stage progressions, not seat counts. Matches how studios buy (capability-led, not headcount-led).
- **Mid-page comparison vs. Mariana Tek / Glofox / Vagaro is candid.** Names competitors directly with feature-by-feature checks; owns the gaps where competitors win.
- **Marketplace screenshot uses real consumer-app UI with real classes.** Not a mock — actual ClassPass-style class listings from real Mindbody studios, communicating "this network is alive right now."
- **Founder/community story page with industry-veteran credentials.** CEO and product team have actual studio-ownership backgrounds — domain credibility transferred via about-page narrative.

## What it gets wrong

- Hero CTA "Get a demo" only — no free trial path. Solo wellness operators (massage therapists, single-instructor studios) convert better on self-serve trials and are abandoned by the demo-gate.
- Mobile experience compresses the dual-screen hero into a single screenshot, losing the two-sided network message.
- Pricing isn't visible at all from hero nav — high-friction discovery for SMB operators evaluating multiple tools.

## Reusable archetype name

**Two-sided network hero with demand-side proof** — hero leads with the marketplace/network value prop (what only you can offer because of network effects), visual shows both sides of the network in one frame, numeric proof anchors marketplace scale.

## When to use this archetype

When the product is genuinely two-sided (marketplace + management tool, supply + demand) AND the marketplace side is the moat against single-sided competitors. NOT a fit for: pure-management tools without consumer-side network, early-stage products where the marketplace is still small.

## Feature mix surfaced

- "Fill your classes via the Mindbody consumer app": full-page hero + dual-screen visual
- "Manage scheduling, payments, staff in one platform": secondary sub-hero + workflow strip
- "Integrated marketing automation: email, SMS, retention campaigns": mid-page section with sample campaign metrics

## Adoption notes

When porting this archetype, the most common mistake is copying the surface aesthetic without copying the underlying buyer-context that makes it work. Verify the buyer-segment fit BEFORE imitating the visual signature — the archetype name names the technique, not just the look. If the buyer-context match is weak, downgrade to a borrowed sub-element (one bullet) rather than the whole pattern.
