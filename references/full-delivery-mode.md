# Full Delivery Mode

## Chained Pipeline

```
write-vision → analyze-competitors + analyze-domain → build-personas →
validate-feature → write-spec → design-ux → design-ui → design-tech →
plan-changeset → execute-changeset
```

## Rules

- Opportunity card IS the vision seed
- Platform constraints respected
- `human_checkpoint` honored
- Blockers surfaced to user

## After execute-changeset

```
audit-implementation → review-gate → land-changeset → verify-promotion
```
