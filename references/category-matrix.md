# Product Category Matrix

## Scoring Boosts

| Factor | Boost | Condition |
|--------|-------|-----------|
| Built-in distribution | +15 | Viral mechanic, network effects, user-generated content |
| Recurring revenue | +10 | Subscription model with proven retention in category |
| AI-native | +10 | AI is core mechanic, not bolt-on feature |
| Cross-platform | +5 | Web + mobile + extension from same codebase |
| Niche dominance | +10 | Serves underserved niche with high willingness to pay |

## Domain Matching

- Builder domain expertise = strong signal, not hard filter
- If builder's day job is DevOps → scan categories 1-11, not just DevOps tools
- If builder's project history is local business → reduce domain bonus by half, seek online angles
- Prefer categories where builder has BOTH skill fit AND distribution edge
