# gstack Ethos & Documentation — Details

## Builder Ethos (ETHOS.md)

3 principles injected into every skill preamble via {{PREAMBLE}} resolver.

### 1. Boil the Lake

AI makes the marginal cost of completeness near-zero. When the complete
implementation costs minutes more than the shortcut — do the complete thing.

- "Lake" = boilable (100% test coverage, all edge cases, full error paths)
- "Ocean" = not boilable (rewrite entire system, multi-quarter migration)
- Boil lakes. Flag oceans as out of scope.
- Anti-pattern: "Choose B — it covers 90% with less code" → always choose A if delta is small

### 2. Search Before Building

Three layers of knowledge:
- **Layer 1: Tried and true** — standard patterns, battle-tested. Risk: assuming obvious = correct
- **Layer 2: New and popular** — current best practices, blog posts. Risk: crowd can be wrong
- **Layer 3: First principles** — original observations. Most valuable. The "eureka moment"

The best outcome: search, understand the landscape, find what everyone missed (Layer 3).

### 3. User Sovereignty

AI recommends, users decide. Two models agreeing is signal, not mandate.
User has context models lack: domain knowledge, relationships, timing, taste.

Pattern: generation-verification loop. AI generates → user verifies → AI never
skips verification because it's confident.

### Build for Yourself

The best tools solve your own problem. Every gstack feature was built because
it was needed, not because it was requested.

## Key Documentation

### ARCHITECTURE.md (~360 lines)

Design decisions and system internals:
- Core idea: persistent browser daemon for sub-second latency
- Why Bun: compiled binaries, native SQLite, native TypeScript, built-in HTTP
- Daemon model: persistent state, sub-second commands, auto lifecycle
- Security model: localhost only, bearer token, cookie security (5 principles)
- Ref system: ARIA tree → Playwright Locators (no DOM mutation)
- Logging: 3 ring buffers (50K entries, O(1) push, async flush)
- Template system: SKILL.md.tmpl → resolvers → committed SKILL.md
- Command dispatch: READ/WRITE/META categories
- Error philosophy: errors for AI agents (actionable, not stack traces)
- E2E test infrastructure: session-runner, eval-store, 3 tiers
- What's intentionally not here: no WebSocket, no MCP, no multi-user, no Windows cookies

## Analysis

The ethos is practical philosophy, not abstract principles. "Boil the Lake"
directly addresses the AI-era shift where completeness is cheap. "Search Before
Building" with 3 knowledge layers provides a structured approach to research.
"User Sovereignty" prevents AI agents from overriding human judgment — especially
important in a framework with 36 autonomous skills.

The design documents show deep architectural thinking. The Chrome vs Chromium
exploration is honest about what worked and what didn't (361 LOC of dead code
from the original CDP vision). The prompt injection defense doc (ML_PROMPT_INJECTION_KILLER)
is the most thorough treatment of browse-level prompt injection defense in any
open-source tool.
