# Taste Skill Capabilities

A collection of high-agency frontend engineering skills and research dedicated to breaking default LLM biases and producing premium, agency-level web interfaces.

## Core Design Skills

- **High-Agency Frontend (taste-skill):** Senior UI/UX Engineer persona that enforces metric-based rules, strict component architecture, and CSS hardware acceleration.
- **Industrial Brutalism (brutalist-skill):** Raw mechanical interfaces fusing Swiss typographic print with military terminal aesthetics.
- **Elite UX/UI & Motion (gpt-taste):** Advanced GSAP motion engineering, AIDA page structure, and Python-driven randomization for layout variance.
- **Premium Utilitarian Minimalism (minimalist-skill):** Clean editorial-style interfaces with warm monochrome palettes and meticulous macro-whitespace.
- **Principal UI/UX Architect (soft-skill):** High-end agency design patterns focusing on haptic depth, cinematic spatial rhythm, and obsessive micro-interactions.
- **Redesign Framework (redesign-skill):** Audits and upgrades existing projects to premium quality by identifying and removing generic AI patterns.
- **Google Stitch Integration (stitch-skill):** Translates anti-generic design standards into Stitch's native semantic design language.

## Output Management

- **Full-Output Enforcement (output-skill):** Overrides LLM truncation behavior, banning placeholder patterns and ensuring exhaustive, unabridged code generation.

## Research & Remediation

- **LLM Laziness Research:** Deep dive into why models produce incomplete or truncated outputs, covering root causes (RLHF, training bias, output limits) and remediation (architectural patterns, parameter tuning, prompt engineering).
- **Empirical Results:** Documented findings and reference prompts to combat LLM laziness in production environments.
