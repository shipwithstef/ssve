# Design Skills: Technical Details

Detailed extraction of the specialized frontend engineering skills found in `taste-skill`.

## 1. taste-skill (High-Agency Frontend)
- **Baseline Configuration:**
  - `DESIGN_VARIANCE: 8` (Enforces asymmetry and artsy chaos).
  - `MOTION_INTENSITY: 6` (Enforces spring physics and magnetic effects).
  - `VISUAL_DENSITY: 4` (Prioritizes whitespace/gallery airiness).
- **Viewport Rule:** `min-h-[100dvh]` is mandatory for Hero sections (fixes iOS Safari jumping).
- **Grid Rule:** CSS Grid is mandatory; flexbox percentage math is BANNED.
- **Emoji Rule:** BANNED. Replace with Phosphor or Radix icons (strokeWidth: 1.5/2.0).

## 2. brutalist-skill (Industrial Brutalism)
- **Aesthetic:** Swiss Typographic + Military Terminal.
- **Techniques:** Analog degradation (halftones, CRT scanlines, bitmap dithering).
- **Typography:** Extreme scale contrast (e.g., massive 900 weight headers vs. tiny mono labels).

## 3. gpt-taste (Elite GSAP/Motion)
- **Signature Technique:** "Inline Image Typography" — embedding small, contextual photos directly between words in headlines at type-height.
- **Page Structure:** Strict AIDA (Attention, Interest, Desire, Action) flow.
- **Bento Grids:** Must be gapless or high-density with perpetual micro-animations.

## 4. minimalist-skill (Premium Minimalism)
- **Aesthetic:** Warm monochrome (Zinc/Slate bases), flat bento grids.
- **Whitespace:** Meticulous macro-whitespace (large sections of empty space).
- **Palette:** Muted pastels only; saturation < 80%.

## 5. soft-skill (Principal UI/UX Architect)
- **Vibe:** $150k+ agency-level experiences.
- **Motion:** Haptic depth and cinematic spatial rhythm.
- **Micro-interactions:** Obsessive focus on `:active` and `:hover` states.

## 6. redesign-skill (Redesign Framework)
- **Audit Points:**
  - Replace `Inter` with `Geist`, `Outfit`, `Cabinet Grotesk`, or `Satoshi`.
  - Fix "AI Purple/Blue" gradients.
  - Fix "3 equal columns" (the generic AI layout).
  - Fix "Oops!" or "Exclamation mark" copywriting.
- **Priority:** Font swap -> Color cleanup -> Hover/Active states -> Layout/Spacing.

## 7. stitch-skill (Google Stitch Integration)
- **Function:** Translates "anti-slop" rules into Stitch's native semantic language.
- **Screen Generation:** Generates `DESIGN.md` files optimized for Stitch's AI agents.
