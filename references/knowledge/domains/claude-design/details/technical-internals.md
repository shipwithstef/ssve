# Claude Design: Technical Internals (Layer 3)

Absolute domain expertise on the A2UI (Agent-to-UI) protocol and Handoff Bundle technical specifications for high-fidelity design automation.

## 1. A2UI Protocol (v0.10)
A2UI is the declarative, streaming JSON protocol that powers the "Live Canvas" and dynamic iteration knobs.
- **Surface Model**: Decouples visual intent from implementation. Surfaces are containers (e.g., `main`, `overlay`) that host components from a registered **Catalog**.
- **The Message Loop**:
  - `createSurface`: Initializes the container and selects a `catalogId`.
  - `updateComponents`: Streams a flat adjacency list of component recipes.
  - `updateDataModel`: Modifies the underlying application state that components bind to via JSON Pointers.

## 2. Catalog Registration & Custom Components
To use your project's React/Vue components in Claude Design, you must register them in the Catalog.
- **Registration Schema**:
  ```json
  {
    "catalogId": "https://serousvibecoding.io/catalogs/v1",
    "components": {
      "VibeButton": {
        "type": "object",
        "properties": {
          "component": { "const": "VibeButton" },
          "variant": { "enum": ["primary", "sunken", "ghost"] },
          "label": { "type": "string" }
        }
      }
    }
  }
  ```
- **Sync Protocol**: The client announces supported catalogs to the agent; the agent selects the one matching the local project environment.

## 3. Dynamic "Adjustment Knobs" (`configSchemas`)
Adjustment knobs are generated by the model based on the `configSchemas` definition in the Catalog.
- **The Knob Pattern**:
  ```json
  "configSchemas": {
    "LayoutTweaks": {
      "type": "object",
      "properties": {
        "padding": { "type": "integer", "minimum": 4, "maximum": 64 },
        "hue": { "type": "number", "minimum": 0, "maximum": 360 }
      }
    }
  }
  ```
- **Implementation**: When a designer uses a slider in Live Canvas, it updates the `DataModel` in real-time, which the agent then reflects in its next code turn.

## 4. Handoff Bundle Structure (`.handoff`)
The handoff bundle is the "Final Intent" package sent from Design to Code.
- **`spec.json`**: The complete A2UI JSON tree of the finalized mockup.
- **`tokens.json`**: W3C-compliant design tokens extracted during the session.
- **`manifest.json`**: Mapping of A2UI components (e.g., `AdjustmentSlider`) to production files (e.g., `src/ui/Slider.tsx`).
- **`notes.md`**: Architectural reasoning and edge-case instructions for the implementation agent.

## 5. Integration Notes for SVC
- **Automated Cataloging**: SVC should include a script that parses `src/components/ui/` and automatically generates an A2UI Catalog JSON to ensure Claude Design is "Project Aware" out of the box.
- **Handoff Ingestion**: Use `claude implement --bundle <ID>` to trigger the protocol-level extraction, skipping the need for manual prompt engineering.
- **Two-Phase Validation**: Implement a pre-commit hook that validates the implemented code's component props against the A2UI Catalog schema used in the handoff.
