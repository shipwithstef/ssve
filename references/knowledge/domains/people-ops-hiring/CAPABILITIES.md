## Core frameworks

1. **Structured Interviewing (SI)** — same questions, same rubric, independent blind scoring per interviewer; 2× predictive over unstructured (Schmidt & Hunter meta-analysis, replicated 2025).
2. **Competency-Based Role Scoping** — IC1→IC5 leveling matrix (scope / complexity / impact / behaviours); anchors both JD and scorecard.
3. **Scorecard-Driven Loop Design** — 6–12 attributes per role, 1–5 behavioural anchors, debrief calibration before offer; each interviewer owns ≤2 dimensions.
4. **30-60-90 Onboarding Framework** — Learn (days 1-30) / Contribute (31-60) / Master (61-90); SMART milestones + structured manager check-ins at each gate.
5. **Headcount-vs-Runway Model** — headcount ≈ 60-80% opex; hire only when ≥18 months runway post-hire; factor full ramp lag (~90 days to productivity).
6. **Equity Architecture (Stage-Gated)** — grant size calibrated to funding stage and IC level; dilution pressure tracked against Option Pool Shuffle risk.

## Decision triggers

| Signal | Recommended action |
|---|---|
| Time-to-fill > 60 days for IC roles | Audit sourcing mix; shift to ≥50% outbound |
| Offer acceptance rate < 70% | Conduct comp audit against Wellfound/Levels bands; check loop friction |
| 90-day attrition > 20% | Activate onboarding remediation; add structured 30/60-day check-ins |
| Equity ask rejected by >2 candidates | Re-benchmark grant vs Index Ventures stage table |
| Runway drops below 18 months | Freeze open reqs; re-prioritise to revenue-critical roles only |
| Team size exceeds 7±2 per pod | Trigger org-design review; split or add a manager node |
| AI/ML role unfilled >45 days | Apply +15-25% comp premium; increase equity grant 1.5× baseline |
| Interviewer disagreement >2 Likert points | Force blind-rescore before debrief; check scorecard anchor clarity |
