## Core Frameworks

- **Message House** `[S]` — Roof (1 core narrative) / Walls (3–5 pillars) / Foundation (proof points + case studies); canonical brand-comms architecture used to govern all outbound copy.
- **PESO Model** `[S]` — Paid / Earned / Shared / Owned media integration; launch campaigns grade against all four channels firing in coordination.
- **Crisis Comms Golden Hour** `[V]` — Public acknowledgment ≤60 min of detection; full root-cause + corrective-action response ≤4 hr.
- **Earned Media Value (EMV/MIV)** `[V]` — Transparent-methodology EMV preferred over bare AVE (AMEC "Say No to AVEs" position); EMV = impression-weighted CPM + engagement cost, adjusted for authority + sentiment.
- **Thought Leadership Authority Ladder** `[S]` — Niche POV → trade media → tier-1 business press → keynote/book; each rung increases domain authority credibility multiplier for downstream pipeline conversion.
- **Embargo + Exclusive Sequencing** `[S]` — Embargo (broad, simultaneous publication) vs. exclusive (one outlet, head start); choice depends on story complexity and relationship capital with target outlet.

## Decision Triggers

| Condition | Trigger action |
|-----------|---------------|
| Pitch response rate < 3% over 20+ sends | Audit relevance alignment; shorten to ≤200 words; add data/proprietary angle |
| Coverage pickup rate < 8% | Add quotes + multimedia; check pitch day/time against Tue–Wed 10am–12pm window |
| Crisis detected on social | Start 60-min clock immediately; issue acknowledgment even without full facts; convene response team |
| Crisis response > 2 hr | Escalate to executive spokesperson; sentiment recovery probability drops ~61% |
| Negative content spreading fast | MIT velocity model: assume 50% audience penetration by 90 min — act before that window closes |
| Founder/CEO LinkedIn below 1 post/week consistently | Re-evaluate TL program; consistency is the highest-impact variable for feed-rank growth |
| Company page used as primary channel | Redirect to founder personal profile; 8× engagement differential makes page-first strategy inefficient |
| Brand messaging inconsistency spotted across channels | Run Message House audit: all copy must trace to a named pillar or the core narrative |
| EMV reported without methodology | Flag as unreliable; require transparent calculation (CPM + engagement cost + authority + sentiment) |
| Product launch < 2 weeks from embargo issue | Risk window: journalists have insufficient prep time; expect lower story quality and fewer features |
