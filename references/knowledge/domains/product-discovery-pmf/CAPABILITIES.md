# Product Discovery & PMF — Capabilities

## Core Frameworks

| # | Framework | One-line |
|---|---|---|
| 1 | **Continuous Discovery (Torres)** | Weekly customer interviews feeding an Opportunity Solution Tree; rhythm > episodic sprints |
| 2 | **Opportunity Solution Tree (OST)** | Four-layer visual: outcome → opportunity space → solutions → assumption tests |
| 3 | **Sean Ellis 40% Test** | "Very disappointed" survey threshold: <25% no-PMF, 25-40% approaching, 40%+ PMF, 60%+ best-in-class |
| 4 | **Retention-Curve PMF** | Flattening cohort curve (non-zero asymptote) is the quantitative complement to the survey test |
| 5 | **RICE Scoring** | (Reach × Impact × Confidence) / Effort — objective prioritization for competing bets |
| 6 | **Riskiest Assumption Test (RAT)** | Isolate the single highest-risk assumption and run the cheapest possible falsification before building |
| 7 | **Now-Next-Later Roadmap** | Time-horizon roadmap (Now 0-3 mo / Next 3-6 mo / Later 6+ mo) replacing date-locked feature trains |
| 8 | **Outcome-over-Output** | Roadmap rows are measurable outcomes (metric deltas), not deliverable names |

## Benchmark Bands / Thresholds

### PMF Survey (Sean Ellis)

| Score | Verdict | Action |
|---|---|---|
| < 25% | No PMF | Reposition / pivot audience or core value prop |
| 25–39% | Approaching | Tighten ICP, sharpen value prop for high-intent segment |
| 40–59% | PMF confirmed | Safe to invest in growth |
| 60%+ | Best-in-class | Accelerate acquisition |

Source: Sean Ellis / GrowthHackers; Reforge guide; koji.so 2026 guide

### Retention-Curve Benchmarks — Mobile Apps (all-vertical medians, Adjust 2024-2025 data)

| Day | Median (all verticals) | Good | Strong |
|---|---|---|---|
| D1 | 26% | 30%+ | 40%+ |
| D7 | 13% | 16%+ | 25%+ |
| D30 | 7% | 10%+ | 20%+ |

**PMF signal:** curve flattens (non-zero asymptote). A D30 → D90 decay of <20 pp relative suggests a retained core. Smiling curves (D90 > D30) indicate reactivation / expansion.

Source: Adjust benchmark data cited by MWM, UXCam, Plotline (2024-2025). Numbers are VOLATILE — see details file.

### RICE Scoring — Impact Scale Conventions

| Impact label | Multiplier |
|---|---|
| Massive | 3× |
| High | 2× |
| Medium | 1× |
| Low | 0.5× |
| Minimal | 0.25× |

Confidence as % (100% = solid data, 80% = reasonable estimate, 50% = guess).
Effort in person-months.

## Decision Triggers

| Signal | Threshold | Decision |
|---|---|---|
| Ellis "very disappointed" | < 25% | Stop growth spend; diagnosis + repositioning |
| Ellis "very disappointed" | 25-39% | Iterate on segment fit before scaling |
| Ellis "very disappointed" | >= 40% | Growth investment gate opens |
| D30 retention vs. category median | < category median | Investigate onboarding / core-loop gap before scaling |
| Retention curve shape | Declining to zero | No retained core — rebuild or pivot |
| Retention curve shape | Flattening non-zero | PMF signal present — qualify with Ellis score |
| NRR (B2B SaaS) | < 100% | Revenue leaking; churn > expansion; fix before investing in acquisition |
| NRR (B2B SaaS) | 100-110% | Healthy; optimize |
| NRR (B2B SaaS) | 120%+ | Strong expansion motion; accelerate |
| RICE score gap | >3× vs. next item | Clear winner; skip committee; ship |
| RAT result | Assumption falsified | Kill or pivot before any further build |
| OST opportunity age | > 4 weeks without fresh customer evidence | Stale — re-interview before betting on it |
