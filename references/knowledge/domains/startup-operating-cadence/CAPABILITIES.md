# startup-operating-cadence — CAPABILITIES

## Core frameworks

| Framework | One-line description |
|---|---|
| **Amazon WBR** | Weekly 60-min exception-driven review of controllable input metrics vs output metrics; no speculation, no strategy, pure operations |
| **Amazon 6-Pager** | Six-section narrative memo (Intro → Goals → Tenets → State of Business → Lessons Learned → Strategic Priorities); silent read 20-25 min, appendices carry data |
| **OKR cadence** | Quarterly objective + 2-4 key results per owner; 0.7-0.8 on 0-1 scale = stretch-goal success; weekly check-ins mandatory |
| **Bezos Door Test** | Type 1 (one-way, irreversible) = slow + deliberate; Type 2 (two-way, reversible) = fast + experimental; default to Type 2 speed unless genuinely Type 1 |
| **RICE scoring** | (Reach × Impact × Confidence) / Effort; relative ranking only — no universal threshold; Confidence <50% = moonshot |
| **DRI model** | One named Directly Responsible Individual per outcome; appears on every agenda; eliminates decision-by-committee |
| **Default-alive gate** | At constant expenses + current revenue growth rate, does the company reach profitability before cash runs out? If no: default dead |
| **Contradiction-mapping synthesis** | When two valid data points conflict (e.g., NPS up, churn up), map both as true, name the gap mechanism, surface at WBR before resolving |

## Decision triggers

| Condition | Trigger action |
|---|---|
| Runway < 24 months AND default-dead | Activate Plan B immediately; halt net-new hiring; initiate bridge discussions |
| OKR score consistently 1.0 | Re-set with harder targets next cycle; current targets are under-ambitious |
| OKR score < 0.3 at mid-quarter | Declare at-risk; DRI must bring remediation plan to weekly check-in |
| RICE Confidence < 50% | Flag as moonshot; do not block roadmap; park in discovery backlog |
| WBR metric owner cannot explain variance in 2 seconds | No speculation allowed; owner logs "investigating" and returns next week with root cause |
| Two-way-door decision consuming >2 days of exec time | Escalation failure — delegate down immediately |
| One-way-door decision made in <1 week | Slow down; require 6-pager or equivalent written narrative |
| Contradiction-map gap unresolved for 2+ WBR cycles | Escalate to S-team; not safe to resolve in operational WBR |
| Seed round raised and time-to-A plan < 24 months | Extend plan; 2026 median is 774 days; plan to 30 months |
