# Kimi CLI Developer Primitives

Kimi CLI is built on top of internal packages (`kaos` and `kosong`) that provide low-level abstractions for agent execution and environment interaction.

## 1. `kaos`: The File & Process Backend

`kaos` provides a unified interface for interacting with different operating environments.

### Backends
- **Local Backend**: Direct interaction with the host filesystem using `pathlib` and `subprocess`.
- **SSH Backend**: (Deep Feature) Allows the agent to run on a remote server. It abstracts SSH file transfers and remote process execution into the standard `kaos` interface.

### `KaosPath`
A highly customized path abstraction that:
- Maintains a **canonical** representation of paths.
- Handles path resolution relative to a backend's root.
- Supports platform-neutral serialized metadata for cross-process communication.

## 2. `kosong`: The Agent Loop Heart

`kosong` contains the reusable primitives for building LLM-driven agent loops.

### Message & Content Model
Supports a rich multi-modal message format:
- **`TextPart`**: Standard text fragments.
- **`ThinkPart`**: (Deep Feature) Hidden reasoning parts for thinking-capable models (e.g., DeepSeek R1).
- **Media Parts**: Direct support for `ImageURLPart`, `AudioURLPart`, and `VideoURLPart`.
- **Tooling Parts**: `ToolCall` and `ToolCallPart` for structured interaction.

### Tooling Primitives
- **`CallableTool2`**: The base class for defining typed tools with automatic Pydantic validation.
- **`streamingjson` Integration**: Uses a specialized JSON lexer to support **Streaming Tool Arguments**, allowing the agent logic to start processing or displaying tool calls before they are fully generated by the LLM.

## 3. Plugin Credential Injection

Kimi CLI plugins feature a unique **Configuration Injection** system.
- When a plugin is loaded, the `PluginManager` can inject "Host Config" (credentials, base URLs, or user-specific settings) directly into the plugin's environment.
- This ensures that lightweight local toolkits can remain stateless while leveraging the main CLI's auth context.
