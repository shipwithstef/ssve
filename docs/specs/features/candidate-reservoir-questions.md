## Five-company pattern bank

- **G — GitHub:** Issue forms enforce structured intake; Projects issue fields provide typed metadata that can be grouped, filtered, sorted, and charted. [GitHub issue-form syntax](https://docs.github.com/en/communities/using-templates-to-encourage-useful-issues-and-pull-requests/syntax-for-issue-forms), [GitHub project issue fields](https://docs.github.com/en/issues/planning-and-tracking-with-projects/understanding-fields/about-issue-fields)
- **L — Linear:** Triage is an inbox outside the normal team workflow; suggestions can be accepted or declined before issues enter normal work. [Linear Triage](https://linear.app/docs/triage), [Linear Triage Intelligence](https://linear.app/docs/triage-intelligence)
- **J — Atlassian:** Jira Product Discovery separates structured ideas from delivery work, supports numeric/slider inputs and weighted/custom formulas, and links ideas to delivery items. [Jira Product Discovery overview](https://support.atlassian.com/jira-product-discovery/docs/what-is-jira-product-discovery/), [fields reference](https://support.atlassian.com/jira-product-discovery/docs/jira-product-discovery-fields-reference/)
- **P — Productboard:** Product teams consolidate ideas and feedback, prioritize with flexible formulas, then hand selected work to delivery tools rather than treating discovery as day-to-day project execution. [Productboard overview](https://support.productboard.com/hc/en-us/articles/360058147693-What-is-Productboard), [prioritization frameworks](https://support.productboard.com/hc/en-us/articles/7400189831955-Model-common-prioritization-frameworks-in-Productboard), [discovery versus project management](https://support.productboard.com/hc/en-us/articles/360058232233-Is-Productboard-a-project-management-solution)
- **N — Notion:** Databases provide typed properties, status, formulas, relations, filters, sorting, and stable item IDs for lightweight structured inventories. [Notion database properties](https://www.notion.com/help/database-properties)

The bank is current official documentation checked on 2026-07-23. Each question's competitor section references all five codes and states the relevant pattern rather than repeating URLs.
