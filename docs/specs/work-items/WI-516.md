# WI-516: Complete the quick-fix retirement — it is still loaded as core pack

**Type:** framework cleanup
**Status:** identified
**Severity:** medium
**Filed:** 2026-08-04
**Source:** WI-512 Batch 3 adversarial review
**Lane:** framework

## Problem

WI-512 retired `quick-fix` as a lane: the SKILL.md body is a retirement notice, the `description` starts `DEPRECATED (retired as a lane)`, and the two real routing rows were rerouted to the chain.

`quick-fix` nonetheless remains in `skills-manifest.json` `corePackForRouting`, so `route-workflow` still loads the retired skill as part of its core pack on every run. The retirement is real but incomplete: the skill is deprecated in prose and still resident in context.

WI-512 could not fix this — its batch spec explicitly forbade manifest churn, and the third cited routing anchor (`route-workflow/references/routing-rules.md:86`) turned out to be a bare bullet inside a machine-generated `svc:generated:begin routing-rules-core-pack` block, i.e. a mirror of the manifest rather than an editable routing row. Removing it means editing the manifest and regenerating mirrors, which is exactly the change that batch was fenced out of.

## Scope

- Remove `quick-fix` from `corePackForRouting` in `skills-manifest.json`.
- **Also the four hand-curated doc surfaces the WI-512 global review found still routing to it** — `README.md:622`, `KIMI.md:59`, `GEMINI.md:55`, `ANTIGRAVITY.md:57`. All four still map "Quick trivial fix (≤ 3 files)" to `quick-fix` and describe it as "Fast lane for trivial changes". None sits inside a `svc:generated` block, so no generator will fix them; README's row is a curated suffix the generator explicitly preserves. Until these are updated, "retired as a lane" is true only of the svc routing tables, not of what a reader is told.
- Regenerate the mirrors (`node scripts/generate-manifest-mirrors.mjs --write`) and confirm `node scripts/lint-skills-manifest.mjs` passes.
- Decide explicitly whether `quick-fix` stays in `includedSkills` at all, or is removed entirely — and record the reasoning either way.

### Explicitly out of scope

Deleting `hooks/git/pre-commit.d/20-quick-fix-eligibility`, `scripts/quick-fix-eligibility.mjs`, or `scripts/classify-change-risk.mjs`. Those are retained deliberately as **bypass detectors** — the proposal wants speed to come from conditional stage activation, not from an unpoliced fast lane, and the detectors are what prove nobody is taking one.

## Acceptance criteria

- [ ] **AC-1** `quick-fix` is absent from `corePackForRouting`; mirrors regenerated; lint green.
- [ ] **AC-2** A `route-workflow` run no longer loads `quick-fix` as core pack — demonstrated, not asserted.
- [ ] **AC-3** The `includedSkills` decision is recorded with its reasoning.
- [ ] **AC-4** Zero diff on the three eligibility/classifier files.
