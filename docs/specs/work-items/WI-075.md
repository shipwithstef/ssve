## Goal

Stop adversarial plan reviewers (Kimi + Codex) from going off-script during reviews — enforce findings-first output, hard-exit if findings are missing, add lane-compliance to review rubric.

## Goals

Harden `scripts/review-plan-kimi.sh` and `scripts/review-plan-codex.sh` so that adversarial plan reviews (a) cannot write files, (b) cannot explore beyond the scope-locked input set, (c) produce findings in a bounded time even when the reviewer's natural instinct is to keep exploring, and (d) include a "lane-compliance" check dimension.

## Acceptance Criteria

### US-01 — Reviewers cannot write files
- AC-01.1 `scripts/review-plan-kimi.sh` invokes kimi with read-only enforcement.
- AC-01.2 `scripts/review-plan-codex.sh` retains `--sandbox read-only`.
- AC-01.3 `validate-review-plan-readonly.sh` asserts both scripts have read-only enforcement wired.

- AC-02.1 Both reviewer scripts prepend an OUTPUT-FIRST preamble.
- AC-02.2 Both scripts tail-parse output and hard-fail if findings block absent.
- AC-02.3 Exit codes: 0 findings valid, 1 tool failure, 2 findings missing, 3 reviewer not on PATH.
