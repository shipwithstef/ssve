## Problem

Past sessions wrote files into canonical skill-output paths (e.g.
`docs/specs/features/`, `docs/specs/design-tech/`, `docs/specs/plans/`) WITHOUT
invoking the responsible skill. Result: artifacts that LOOK like skill output
but have no gate-receipts in `.svc/pipeline-decisions.jsonl`. Future readers
and downstream skills cannot tell hand-rolled drafts from skill-produced.

## Scope

New PreToolUse hook `hooks/svc-skill-artifact-authenticity.mjs` matched on
`Edit|Write`. Maintains a list of canonical skill-output paths and the skills
that own them. On any Edit/Write to a canonical path, scan
`.svc/pipeline-decisions.jsonl` for a recent (default 90 min) invocation of
ANY of the responsible skills. If absent, exit 2 (HARD BLOCK).

### In scope
- New hook file + entry in `hooks/hooks.json`
- New tier-1 validator with 8 smoke tests
- Path map for: features, design-ux/ui/tech, plans, decisions, capability-plan, coverage-audit, personas, journeys, research-log
- Override: `SVC_SKILL_ARTIFACT_ALLOW=1`, recency window: `SVC_SKILL_RECEIPT_WINDOW_MIN`

### Out of scope
- Auto-emitting receipts from skills (G-12, future WI)
- Per-skill receipt schema enforcement (G-9, future)
- Settings.json wiring — `wire-hooks.mjs` picks up new hooks/hooks.json entries automatically

## Acceptance criteria

1. Hook blocks writes to `docs/specs/features/*` without recent `validate-feature` or `write-spec` invocation. ✅ smoke T1
2. Hook honors recency window via timestamp in `pipeline-decisions.jsonl`. ✅ T2 (stale → BLOCK), T3 (fresh → PASS)
3. Multiple eligible skills satisfy the check. ✅ T4 (write-spec satisfies features/)
4. Unrelated skill receipts do not satisfy. ✅ T5
5. `SVC_SKILL_ARTIFACT_ALLOW=1` bypasses the check. ✅ T6
6. Non-protected paths always allowed. ✅ T7
7. Exact-match paths (capability-plan.md) work. ✅ T8
8. Tier-1 sweep passes (40 validators). ✅
9. `node scripts/lint-skills-manifest.mjs` clean. ✅

## Risk

LOW-MEDIUM. The hook fires on every Edit/Write, not just protected paths — but the
non-matching path returns exit 0 in <5ms (one path-prefix check). Failure mode:
the bypass env var SVC_SKILL_ARTIFACT_ALLOW=1 is the explicit escape hatch.

## Rollback

Revert this commit. Hook stops firing. Counterfeit-artifact bypass becomes
possible again, but no other framework behavior changes.
