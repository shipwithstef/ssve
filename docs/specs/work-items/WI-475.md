# WI-475: Migrate Gemini CLI to AGY CLI and default to Gemini 3.5 Flash High

**Type:** framework
**Status:** DRAFT
**Severity:** medium
**Filed:** 2026-07-12
**Source:** route-workflow
**Lane:** framework

## Goal

Migrate the framework's subordinate Gemini harness from `gemini-cli` (command `gemini`) to `agy-cli` (command `agy`). Ensure all invocations of Google/Gemini models default to `gemini-3.5-flash` (specifically, `gemini-3.5-flash-high` or a fallback to orchestrator level / other harness models if unavailable).

## Acceptance Criteria (AC)

1. **Rule Rename & Content Update**:
   - `rules/research-must-use-gemini-cli.md` renamed to `rules/research-must-use-agy-cli.md`.
   - Update all rule content to refer to `agy-cli` and `agy` instead of `gemini-cli` and `gemini`.
   - Update `skills-manifest.json` to register the new rule filename and path.

2. **Codebase References & Commands Migration**:
   - Replace references to `gemini-cli` with `agy-cli` / `agy cli` across the codebase (such as in `research/SKILL.md` and related references).
   - In scripts invoking the `gemini` command (e.g. `scripts/prompt-floor-judge.sh`, `scripts/blind-floor-judge.sh`, `research/scripts/dispatch-gemini.mjs`, `research/scripts/synthesize-meaning.mjs`), replace the command `gemini` with `agy`.
   - Update `scripts/host-probes/gemini.sh` (or rename to `agy.sh`) to probe for the `agy` command instead of `gemini`.

3. **Default Model Update**:
   - Ensure all Gemini/Google model calls use `gemini-3.5-flash` (specifically, `gemini-3.5-flash-high`) as the default, and fallback to orchestrator level or other harness models if unavailable.

4. **Validation & Evals**:
   - All Tier-1 and Tier-1.5 validation scripts must pass.
   - `node scripts/lint-skills-manifest.mjs` must pass.
   - `check-install-drift.sh` must be clean.

## Verification Plan

- Run `bash test-framework/evals/run-all-evals.sh` (static checks).
- Run `node scripts/lint-skills-manifest.mjs`.
- Verify file persistence and hook wire status if applicable.
