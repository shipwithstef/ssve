## Goal

Make `setup` self-healing against orphaned rule symlinks. When a rule is renamed or removed from `skills-manifest.json`'s `rulesRegistry`, the next `./setup --host claude` run should prune the leftover symlink instead of leaving it dead for WI-079's validator to flag.

## Acceptance Criteria

- AC-01 `setup` prunes symlinks under `$SKILLS_TARGET/rules/` and `$RULES_DIR` whose targets do not exist.
- AC-02 `setup` reports `Rules:  pruned N orphan symlink(s)` when any were removed; silent otherwise.
- AC-03 Symlinks whose target points outside `$SCRIPT_DIR` are left untouched (not ours to clean).
- AC-04 `validate-claude-skills-symlinks.sh` passes after `./setup --host claude`.
- AC-05 Full tier-1 sweep PASS.
