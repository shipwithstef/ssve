## Problem

WI-310 implemented shared-config serialization and one-hop relative import
dependency expansion, but the broader proposal also called for WI-aware worker
model routing and stronger project import graph conflict detection. The current
planner does not route worker model by WI severity/type, and import expansion is
limited to local relative imports found in affected files.

## Acceptance Criteria

- [x] Worker model routing uses WI metadata such as severity, type, route,
  `needs_model`, and `needs_transport`, not only dispatch-worker skill defaults.
- [x] Planner output records selected worker model and rationale for every
  dispatchable WI.
- [x] Import/dependency conflict detection expands beyond direct relative
  imports when project tooling is available.
- [x] If dependency tooling is unavailable, planner output records an explicit
  degraded-confidence warning.
- [x] Add replay fixtures for model routing and import graph degradation.
