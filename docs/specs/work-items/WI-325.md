## Problem

The Stop hook now blocks incomplete work and missing phase receipts, and
preflight is fail-closed for declared contracts. The remaining residual is
prompt-time enforcement: long sessions can avoid Stop, skills do not
automatically emit invocation receipts, and prerequisite chains are not checked
as a first-class `chain.requires` contract.

## Acceptance Criteria

- [x] Define prompt-time progress-audit thresholds for long sessions without
      relying on Stop.
- [x] Add or explicitly reject `chain.requires` prerequisite enforcement with
      a validator-backed rationale.
- [x] Add a canonical skill-receipt emission path, or document why current
      task-graph receipts fully supersede it.
- [x] Add tier-1 fixtures proving the chosen path cannot silently skip skill
      prerequisite or receipt obligations.
