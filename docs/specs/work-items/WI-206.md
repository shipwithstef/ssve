### Resolution

The SDKG post-task trigger router still fails open for unrelated/user-request
sessions, but no longer silently disappears during framework-evolution work
when the registered SDKG registry is malformed. The Stop hook now blocks
framework-evolution closeout on router failure unless an explicit
`SVC_SDKG_FAIL_OPEN=true` emergency bypass is set and logged.

### Changes

- Updated `hooks/svc-task-completion-guard.sh` to execute
  `post-task-trigger-router.mjs` from `SVC_REPO_ROOT`, so it reads the intended
  repo's `references/sdkg-registry.json`.
- Scoped malformed-registry failures: `framework-evolution` blocks; unrelated
  sessions log a fail-open warning and continue.
- Updated `route-workflow/SKILL.md` to document the scoped fail-closed behavior.
- Added `test-framework/evals/tier-1/validate-sdkg-router-fail-closed.sh`.
