## Goal

Stop injecting ~34K tokens of rules (42 files) into every session on this machine. Add `auto_inject: always|signal|lazy` to `rulesRegistry` in `skills-manifest.json`; keep ~6 truly behavioral rules always-on in `~/.claude/rules/` (chosen via `evaluate-rule` criteria); inject the rest on demand when their subject-matter signals match — **dual trigger: PostToolUse(Read|Grep|Glob) injects while the agent EXPLORES the target area (BEFORE the first edit) + PostToolUse(Edit|Write) catch-up for unread-edit paths** — both calling `scripts/scan-concerns.mjs --paths <file> --json`, with a per-session memoized injected-set (`.svc/rule-injections-<session>.json`) so steady-state cost is one set-lookup. At execution, verify whether PreToolUse supports `additionalContext` output in current docs — if yes, prefer PreToolUse(Edit|Write) as primary (closes the first-edit residual entirely).

Expected effect: ~25–30K tokens/turn reclaimed in EVERY session, every project — the single largest mistake-reduction lever found by the evaluation (instruction-following degrades with instruction count; the repo's own context-budget doctrine says context is the scarcest resource).
