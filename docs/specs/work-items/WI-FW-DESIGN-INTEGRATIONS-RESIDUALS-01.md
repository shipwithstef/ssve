# WI-FW-DESIGN-INTEGRATIONS-RESIDUALS-01: Reassess optional design integrations

**Type:** framework
**Status:** backlog
**Filed:** 2026-09-06
**Lane:** framework
**Source:** proposals/2026-06-19-evolution.md

## Problem

The eight June design-integration findings describe additive capabilities, not a
reproduced blocker in the current dedicated-session optimization. Their MCP
availability, authentication and vendor feature claims are historical and must
not be assumed available today. Keep useful opportunities visible without
turning them into compulsory provider calls or new release gates.

## Acceptance criteria

- Reassess F1 token transforms against the project's actual token/component
  source and an appropriate small round-trip fixture; do not install a transform
  stack merely because the proposal names one.
- Reassess F2 Figma and F7 code-to-design against actual requested frame/component
  mappings. Preserve code ownership and explicitly record structural parity
  limits instead of assuming bidirectional fidelity.
- Reassess F3 accessibility and visual comparison using actual product states and
  focused checks; automated scans alone do not prove accessibility compliance.
- Reassess F4 Canva, F5 Stitch, F6 design-sync and F8 external preview only when the
  owner wants those surfaces and their current provisioned routes are available.
  Do not revive obsolete skill targets or assume a June login still works.
- Give each F1–F8 an implemented, rejected, duplicate, or concrete child-WI-owned
  disposition with source evidence and prerequisites. No aggregate done claim
  from the presence of an MCP name or knowledge document.

## Boundaries

Separate approved optional integration work from the preserved UX improvement
skill being finished in current Stage B. This WI neither delays that skill nor
claims it complete. Existing specs, persona fit, real code and meaningful UX
alternatives remain required independently of design-tool access. No unavailable
Claude or standalone Grok call, login flow, credential change or purchase is
permitted by this backlog record. Use the owner's resource policy at execution.
