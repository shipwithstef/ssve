# WI-188: Manifest excludes real top-level skills

## Problem

The framework reliability review found HIGH issue F-018: Manifest excludes real top-level skills.

## Evidence

`skills-manifest.json` has 77 `includedSkills`, while 79 top-level `SKILL.md` files exist. `base44-environment` and `design-logo` are unmanifested.

## Impact

Install/setup can see skills that route-workflow and manifest lints do not fully model.

## Proposed Fix

Either add them to the manifest with lane/core-pack decisions or mark them as non-framework addon skills in a separate explicit registry.

- AC2: A targeted validator, replay fixture, or documented verification command proves the fix.
- AC3: Relevant framework state, docs, hooks, or skill contracts are updated in sync.

## Closeout

Closed 2026-05-10. The two real top-level skills excluded from `includedSkills` are now modeled in the manifest, and the manifest linter now rejects future top-level `SKILL.md` directories that are not listed.

- Added `design-logo` and `base44-environment` to `skills-manifest.json` `includedSkills`.
