## Problem

WI-111's decision matrix in `ingest-guide/SKILL.md` had an unresolved conflict:
when a claim hits BOTH `catalog-overlap-strong` AND comes from an `addon-novel`
multi-skill source AND has `project-fit:strong`, two rows fired with different
defaults. Agent picked whichever it read first → non-deterministic routing.

## Scope

Adds:
1. A new **`selective-blend`** routing option to Step 10 (alongside discard/store/blend-or-link/promote).
2. A **Tie-break precedence** sub-section between the matrix and Step 10 specifying
   that source-level rows only fire when ≥1 surviving claim is `catalog-novel`,
   otherwise the source-level recommendation is `selective-blend` against the
   existing svc skill via `improve-framework`.
3. Updates the JSON decision-log schema to include `selective-blend` count.

## Acceptance criteria

1. Matrix rows for addon sources are split into 3 cases (≥1 catalog-novel claim
   → blend-or-link; all overlap → selective-blend; weak fit → store-as-reference). ✅
2. Step 10 documents the new `selective-blend` routing option. ✅
3. JSON log schema has `selective-blend: N`. ✅
4. Lint clean, tier-1 sweep passes. ✅
