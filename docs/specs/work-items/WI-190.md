# WI-190: `write-journeys` has known P0 coverage debt

## Problem

The framework reliability review found CRITICAL issue F-020: `write-journeys` has known P0 coverage debt.

## Evidence

[FRAMEWORK-STATE.md](/workspace/seriousvibecoding/FRAMEWORK-STATE.md:251) records `write-journeys` progressive-disclosure violation, zero tier-2 scenarios, weak self-verify, pending refresh trigger, and no tier-3 judge.

## Impact

Journey generation is central to acceptance coverage, but one of the largest skills has shallow automated proof.

## Proposed Fix

Split `write-journeys`, add tier-2 journey generation scenarios, and add trace validation for its mandatory process steps.
