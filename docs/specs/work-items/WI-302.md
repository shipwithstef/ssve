# WI-302: Delivery graph replay fixtures and autorun proof

## Goal

Prove the delivery graph works through replay fixtures and autorun skeleton checks. This is the bridge from static graph definition to confidence that route-workflow actually compiles and mutates the graph under real workflow shapes.

## Required Fixtures

1. Example Marketplace WI-233 partial corrective graph.
2. CSS-only/browser-visible chore.
3. User-facing bugfix.
4. Backend Base44 function.
5. Docs-only change.
6. User-challenged closeout.
7. Autorun greenfield, brownfield bugfix, and framework-evolution skeletons.

- AC1: Tier-1 fixtures prove graph validator pass/fail behavior for all required fixture classes.

- AC4: `bash test-framework/evals/run-all-evals.sh` passes with the new graph fixtures.
- AC5: WI-194 is updated or cross-linked if its autorun coverage is subsumed by this WI.
