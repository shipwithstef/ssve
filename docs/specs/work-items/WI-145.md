## Findings being fixed

1. **MEDIUM — Path traversal in `readKnowledgeBase`** (`scripts/lib/structured-gate-engine.mjs`)
   `slug` and `topic` flow into `path.join(kbBase, slug)` and `path.join(dir, ${topic}.md)` with no sanitisation. A slug containing `..` reads outside `references/knowledge/competitors/` and the contents leak into the returned `competitors[].capabilities`. Fix: `path.resolve` + `startsWith(kbBase)` containment check; reject otherwise (still fail-open by recording as missing, never throwing).

2. **MEDIUM — Code/comment mismatch in `validate-lane-tasks-integrity.sh`**
   Header comment says completed tasks must have `skip_reason` OR (`skill_receipt.loaded_at` AND (`output_artifact` OR `validation_output`)). The python check only verifies `skip_reason OR output_artifact OR validation_output` — a task with `output_artifact` set but no `loaded_at` passes ghost-completion. Fix: tighten code to match comment.

3. **LOW — Python-in-shell-heredoc with `$lt`/`$REGISTRY` interpolation** (both new validators in 6faec96)
   Filenames containing single-quotes/`$` would break the python. Fix: pass via argv.

4. **LOW — Silent 2000-byte truncation in `readKnowledgeBase`**. Add `truncated` boolean.

5. **LOW — `process.cwd()` fallback for `repoRoot`**. Resolve via `git rev-parse --show-toplevel` when `repoRoot` not provided.
