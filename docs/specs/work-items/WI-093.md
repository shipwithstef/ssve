# WI-093: Router Miss — capture-idea Did Not Auto-Trigger on "I have idea I want to realise"

## Goal
Add the trigger phrase "I have idea I want to realise" (and close variants) to the router intent table so `capture-idea` auto-routes when the builder phrases an idea this way.

## Context
In session 2026-04-24, the builder said *"I have idea I want to realise (somehow capture-idea skill didn't pop)"* — `route-workflow`'s freeform intent matcher did not recognize the phrase as a `capture-idea` trigger, even though the intent was a textbook backlog intake. The user had to explicitly invoke the skill.

## Hypothesized Value
Lower friction for backlog intake (the cheapest, highest-leverage fast lane). Reduces the chance the builder gives up and types the idea into a notes app instead of routing it through svc.

## Broad Scope
- Add trigger phrases to `route-workflow/references/intent-routing.md`:
  - "I have idea I want to realise"
  - "I have an idea"
  - "want to realise"
  - related conjugations / typos as natural-language patterns rather than exact strings
- Cross-check `capture-idea/SKILL.md` description trigger list and align.
- Add a regression case to `test-framework` evals so future router changes don't drop this trigger.

Framework maintainer / svc operator.
