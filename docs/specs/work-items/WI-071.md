# WI-071: Gemini CLI hangs after activating large skills

**Type:** bugfix
**Status:** VERIFIED
**Severity:** high
**Lane:** bugfix
**Source:** user-report
**Captured:** 2026-04-19

## Root Cause
Skill activation in Gemini CLI returns the entire `SKILL.md` body. Large skills like `route-workflow` (~150KB) and `write-e2e` (~120KB) were overwhelming the harness rendering and context management.

## Fix
Refactored `route-workflow` and `write-e2e` to use the "Progressive Disclosure" pattern. Core workflows remain in `SKILL.md` (now <10KB), while detailed protocols, tables, and examples were moved to `references/` files.
