# WI-185: Preflight hook is fail-open by design

## Problem

The framework reliability review found HIGH issue F-015: Preflight hook is fail-open by design.

## Evidence

`hooks/hooks.json` says `Always exits 0 (fail-open)` for `svc-preflight-skill` at [hooks/hooks.json](/workspace/seriousvibecoding/hooks/hooks.json:31).

## Impact

The framework can know a skill lacks required inputs and still proceed.

## Proposed Fix

Keep fail-open for unknown hosts, but fail-closed for first-party hosts once a skill declares a preflight contract.

## Resolution

Closed 2026-05-11. `scripts/preflight.mjs` now supports `--hook --fail-closed`. In hook mode, missing or unparsable hook payloads, non-Skill events, and missing `.svc/preflight-<skill>.json` contracts still fail open. Once a skill has declared `.svc/preflight-<skill>.json`, missing inputs, blocked outputs, or malformed declared config block with exit 2 under first-party fail-closed wiring.

The canonical Claude hook and Claude hook wirer now install `node scripts/preflight.mjs --hook --fail-closed`.
