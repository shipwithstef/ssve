# WI-510: Make skip-integrity validation phase-receipt aware

**Type:** bugfix
**Status:** verified
**Severity:** high
**Filed:** 2026-07-23
**Source:** WI-498 promoted replay and WI-509 diagnosis
**Lane:** framework

## Problem

The Tier-1 skip-integrity validator still treats legacy `skip_reason` prose as
the only acceptable proof that a phase was intentionally skipped. Current task
graphs carry structured phase receipts and explicit delivery-graph skip
metadata, so the validator can reject a valid graph after the runtime path has
already enforced and receipted the decision.

## Boundary

This is independent of WI-509. WI-509 restores bounded reconcile so governed
work can start; WI-510 then corrects the validator/schema interpretation without
weakening the no-silent-skip invariant.
