# WI-565: Canonical Cursor Auto and Grok Build review transports

**Type:** bugfix
**Status:** in_progress
**Severity:** high
**Filed:** 2026-08-30
**Source:** user-reported Example Marketplace G5 failure
**Lane:** bugfix
**Risk Flags:** cross_runtime_integration

## Problem

The owner review topology correctly selects external stations from configuration, but the canonical launcher implements transports only for Codex, AGY, and Claude. A configured Cursor station therefore fails before invocation with `no review transport for host cursor`; Grok Build is provisioned as a supported host but has the same missing transport.

## Evidence

- Example Marketplace failure receipt: `.svc/external-review-artifacts/posthog-replay-exec-round1/receipt.json` reports the Cursor capability failure.
- `scripts/run-external-review.mjs` at the filed base has a three-entry `REVIEW_HOST_TRANSPORTS` map.
- Live installed CLI probes on 2026-08-30 prove Cursor Agent `2026.08.25-3e8eec8` supports noninteractive plan-mode JSON output and Grok Build `1.0.13` supports plan-mode schema output with server-observed `grok-4.6-build` usage.

## Root cause

Host provisioning and owner-configurable topology evolved independently from the canonical reviewer launcher. There was no parity validator requiring every review-capable configured host to have capability probing, read-only invocation, parsing, attestation, schema validation, and receipt tests.

## Acceptance Criteria

- AC-1: Owner-configured `cursor/multi/cursor-auto/high` completes through the canonical launcher in read-only plan mode and emits a schema-valid receipt without fabricating an underlying provider model.
- AC-2: Owner-configured `grok/xai/grok-4.6/high` completes through the canonical launcher in plan mode, enforces the findings schema, and records server-observed `grok-4.6-build` model evidence.
- AC-3: Capability probes for both hosts are zero-review-invocation and fail closed when required CLI flags are absent.
- AC-4: Existing Codex, AGY, and Claude transport regression coverage stays green.
- AC-5 (post-land verification): The all-host installer publishes the launcher and reports no install drift. This cannot be precondition evidence for the pre-land G5 review.
- AC-6 (post-land verification): The original Example Marketplace Cursor failure is replayed successfully after installation. This cannot be precondition evidence for the pre-land G5 review.
