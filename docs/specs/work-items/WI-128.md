## Goal

Codify the pattern: skills emitting > N tokens write the full output to disk and put a compact summary inline. Without this, skills that produce long structured outputs (analysis reports, audit results, knowledge dumps) cause "Prompt is too long" failures and truncate transcripts.

## Approach (cheapest unlock)

Single rule doc at `rules/long-output-to-file.md` declaring:
- Soft threshold (~800 lines / ~10K tokens)
- Disk-write convention (where outputs land per skill)
- Summary template (file path + 3-bullet abstract)
- When the rule applies vs doesn't (interactive vs analysis)

This is enforcement-by-rule, not by validator. A validator can come later if drift is observed.

## Promotion rationale

Original WI-099 promotion condition: "we hit one more output-length truncation that an inline summary can't fix; OR when CLAUDE.md Response Length rule proves insufficient on its own."

Neither of those triggered. **Manual promotion** because (a) the rule doesn't yet exist (the proposal assumed CLAUDE.md had a Response Length rule — it doesn't), so the "insufficient" condition is technically already met by absence; (b) the user asked to unlock T2/T3 items in 2026-04-26 session.
