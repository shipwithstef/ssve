## Problem
`route-workflow/SKILL.md` line 285 hardcodes the concern scanner path as:
```bash
node ~/.claude/skills/scripts/scan-concerns.mjs
```
This path is wrong for Kimi (`~/.kimi/skills/`), Codex (`~/.codex/skills/`), Gemini (`~/.gemini/skills/`), and OpenCode (`~/.config/opencode/skills/`).

## Impact
On non-Claude hosts, the concern scanner fails or is skipped silently. A CRITICAL-severity concern could be missed because the script path doesn't exist.

## Acceptance Criteria
- [x] Replace hardcoded path with host-resolved path (use `scripts/detect-host.sh` or `SKILLS_PATH` env var)
- [x] Verify scanner runs successfully on Kimi, Codex, Gemini, and OpenCode
- [x] If scanner binary is missing, fail-open with stderr log (existing behavior) but do not fail due to wrong path
- [x] Update `references/concern-routing.md` if it references the hardcoded path
