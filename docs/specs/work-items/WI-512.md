## Risk acceptance (owner-directed lightweight mode)

Blocking ceremony and tests are disabled for this run via sanctioned levers only: `.svc/chain-policy.json` → `warn`, `SVC_HOOK_PROFILE=minimal`, `SVC_SKIP_TIER1_GATE=1`, `SVC_EVAL_MODE=none`, targeted `SVC_DISABLED_HOOKS`, `SVC_VERIFICATION_GUARD_DISABLE=1`, `SVC_END_TO_END_STOP_DISABLE=1`, `SVC_BREAK_GLASS=1`.

**Receipts are NOT skipped.** This run dogfoods the one-lane principle it is landing: the same stage list is emitted every time, and stages skipped by condition are recorded as `na` **with the condition stated in the receipt body**. Verification budget for the run: `node --check` on every touched `.mjs`, one targeted smoke invocation per new or modified script, `node scripts/lint-skills-manifest.mjs` once, one Opus adversarial review per batch, one fresh-context global Opus review.

**Restore condition:** at landing, `.svc/chain-policy.json` returns to `refuse`, all env overrides are unset, and a restore row is logged in `.svc/pipeline-decisions.jsonl`. The first non-exempt push after restore hits the tier-1 gate anyway — self-correcting.

**Same-family review debt:** Codex quota is exhausted, so both batch review and global review are Anthropic-family. The cross-family fence will WARN on `anthropic == anthropic`. That warning is honest §4g drain-queue debt, recorded, to be re-reviewed cross-family when Codex quota returns.
