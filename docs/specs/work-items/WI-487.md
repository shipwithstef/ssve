# WI-487: Durable installed enforcement source

**Type:** framework installation regression
**Status:** VERIFIED
**Severity:** critical
**Filed:** 2026-07-15
**Lane:** framework
**Source:** proposals/2026-07-15-framework-improvement-durable-install-source.md and Fable 5 high-effort intake review
**Related:** WI-485
**Affected Files/Specs:** setup, install drift, session-start healthcheck, host install receipts, and dangling-source fixtures

## Problem

Installed hooks and skills can resolve through an ephemeral source that later disappears. A previously active safety guard can then stop executing silently, producing fail-open behavior and oscillating enforcement.

## Affected Files

- Framework `setup` and install-drift checks
- Session-start healthcheck and host install receipts
- Canonical-source and dangling-pointer fixtures

## Acceptance criteria

- [ ] Setup refuses or durably materializes ephemeral install sources.
- [ ] Missing/dangling enforcement produces a visible fail-closed result for governed mutations.
- [ ] Existing bad installs are detected and deterministically repaired or rejected.
- [ ] Canonical repository worktree development remains supported.
- [ ] Hooks and skills share one recorded effective source and repair atomically.
- [ ] Setup and repair are idempotent and preserve unrelated host configuration.
- [ ] Blocking hooks emit identity, reason code, affected operation, and exact recovery; anonymous code-1 failures are forbidden.
- [ ] Hosts that swallow stderr expose the same diagnostic through a durable per-session receipt/log referenced by the visible failure.
- [ ] Identical failures are deduplicated/rate-limited by session and state digest without failing open.
- [ ] A versioned first-run migration repairs every configured host and reports per-host before/after state.
- [ ] Migration is transactional, resumable, bounded, idempotent, and preserves user work.
- [ ] Old install and supported WI state align through one first-run entrypoint; WI transformation delegates to WI-486, otherwise terminates fail-closed without a retry loop.

## Route recommendation

Full framework regression chain with explicit migration and rollback fixtures. First reproduce why existing canonicalization and self-heal safeguards missed the observed install.
