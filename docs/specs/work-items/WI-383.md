# WI-383: Receipt-mined gate telemetry → measured ceremony tiering

**Stage:** S4 (telemetry substrate ships in S2)

## Problem
Two missing halves of one loop. (a) 183 git-note receipts carry `findings[]` + `iteration_count` + `files_touched`/`test_results`, but NOTHING aggregates them, and route-workflow picks delivery tier by per-run LLM judgment. (b) WI-369's demotion logic depends on rule-hit telemetry that does not exist in usable form — `docs/analysis/decay-report-2026-06-08.md` proves it live: "observed telemetry: 0d"; `svc-rule-injector.mjs` writes only a per-session gitignored memo.

## Mechanism (as built)
`scripts/mine-receipts.mjs` walks `refs/notes/svc-receipts` → per-lane stats cached at regenerable `.svc/gate-stats.json` (gitignored). `--tier <lane>` is a PURE, fenced predictor; `--demotion-list` / `--learning-fires` produce WI-369's 90-day zero-hit list + 3+-fire elevation candidates from `.svc/rule-hits.jsonl` (append-only, union-merge per WI-398). Lane-tagging added to the plan-manifest receipt so telemetry buckets per-lane (untagged → 'unknown', never compresses — safe).

**Value-reduction containment (this is the only forward WI that can drop a review pass):**
- Compression is **default OFF** — route-workflow only acts on a `compressed` recommendation when `.svc/chain-policy.json` opts in (`ceremony_tiering:"measured"`); otherwise the recommendation is advisory-only and the tier stays `full`.
- Only the plan-level adversarial round can ever be tiered; review-exec G6, audit-implementation, and the pre-push 5-receipt envelope are NEVER tiered.
- All four fences (AC1–AC4) are golden-tested in `validate-gate-telemetry.sh`.

**Protected-file note:** the spec's "~3-line injector append" to `hooks/svc-rule-injector.mjs` is blocked by the config-protection guard (hot-path hook; needs explicit user authorization). Implemented the non-protected path instead: the injector already writes per-session memos (`.svc/rule-injections-<session>.json`); `mine-receipts --stats` aggregates those into `rule-hits.jsonl` (dedup by session+rule, `now` timestamps → monotonic). **Authorized follow-up:** the real-time injector append closes the best-effort gap (a memo cleaned before `--stats` runs is missed) — file it when the user authorizes the protected edit.
