## Goal

One command must produce a complete yes/no answer per governed final commit:

| Final SHA | Task / skill | Why mandatory | Evidence identity | Result |
|---|---|---|---|---|
| `<sha>` | `<task-id> / <skill>` | route rule / condition | receipt type + digest | PASS / MISSING / INVALID / AUTHORIZED_NA |

- YES only when every applicable mandatory task validates (or holds a policy-authorized NA decided before completion).
- NO on any missing/malformed/wrong-binding/failed evidence.
- UNKNOWN/INFRA_FAILURE — never YES — when the authoritative note cannot be read.

## Design decisions locked at planning

1. The `skill-coverage` receipt is an **index, not self-asserted proof**: the checker recomputes every referenced child receipt; a forged `verdict:"pass"` fails closed.
2. Compiled `required[]` lives inside the content-addressed receipt and binds to the reviewed task graph via `graph_digest` (sha256 over normalized lane-tasks JSON) — validation never depends on `.svc` tracked-ness.
3. Receipt terminates in the Git note envelope (`refs/notes/svc-receipts`) — emitting it creates no new commit and therefore no recursive obligation.
4. Merge finalization is atomic from the operator's perspective: validate-before-merge → squash → translate receipts onto GitHub's final SHA → push notes (CAS) → verify → only then report Done; otherwise `MERGED_UNVERIFIED`.
5. Enforcement arming: the checker **strictly validates any present `skill-coverage` receipt** and the finalizer **always emits one** from day one; making it a hard-required type for all future SHAs is an explicit owner decision recorded in FRAMEWORK-STATE after replay proof (proposal Human Checkpoint honored).

## Boundaries

In scope:
- `schemas/receipts/skill-coverage.schema.json`
- `scripts/lib/skill-coverage.mjs` (compile + bind + verify library)
- `scripts/check-chain-receipts.mjs` integration (recognize + strictly validate type; `--coverage <sha>` human-readable verdict mode)
- `scripts/merge-pr-with-review-receipt.mjs` post-merge finalization contract
- tier-1 validator + fixtures proving compile/binding/tamper/termination/concurrency
- contract + state doc updates

Out of scope:
- weakening mandatory routing or the existing five-type chain
- blanket docs/recovery exemption (evidence-carrier bypass)
- rewriting historical Git trees; deleting #826 evidence
- treating reviewer PASS as proof unrecorded skills ran
