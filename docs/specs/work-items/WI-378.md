## Goal
ONE install mechanism per host class. Claude host: `setup --host claude` provisions
PLUGINS (svc-core — skills + hooks.json auto-wired on enable, retiring wire-hooks
settings-mutation there — plus pack plugins), declared in `provision/hosts/claude.json`,
drift-checked by the existing validator family. Symlink farm remains ONLY for hosts
without plugin support (codex/kimi/gemini/opencode/cursor — unchanged). The WI-377
migration script + svc-pack-marketplace become a documented transitional shim,
deleted at completion.

## Why not done at WI-377
Packs were never setup-owned (npx-skills installed them outside provision); the WI-377
quick fix wrapped that foreign half for the per-project win. The coherent fix is
setup-owned plugins end-to-end — bigger surface (setup, provision schema, wire-hooks
retirement on one host, drift validator updates) ⇒ its own chained WI.

## Guardrails
- Other hosts byte-identical behavior (live-probed at WI-377: they carry zero pack links)

- Rollback: setup --host claude re-links (current behavior preserved behind a flag until G7)
