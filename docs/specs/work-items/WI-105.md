## Goal

produce a read-only aggregator that scans a configured list of project roots (`~/.svc/projects.json`) and extracts each project's `docs/specs/project-state.md`, work-item INDEX, last-N learnings, and FRAMEWORK-STATE.md. Emits a compact cross-project snapshot at `~/.svc/state-snapshot.json`.

## Acceptance Criteria

- Given 3 fake project dirs with mixed states, the aggregator emits a single snapshot listing: per-project active WI count, blocked-on-what, time-since-last-commit, and a framework row.
- Read-only across project boundaries — no mutation (validated by a tier-1 check grepping for write operations outside the svc repo).
- Aggregation time under 2s for 10 project roots.
