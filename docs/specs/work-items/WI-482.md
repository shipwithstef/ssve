# WI-482: Mandatory default-checkout isolation

**Type:** framework infrastructure
**Status:** VERIFIED
**Severity:** high
**Filed:** 2026-07-14
**Lane:** framework
**Source:** live shared-checkout collisions captured by the WI-481 program
**Program:** docs/plans/2026-07-14-wi481-change-impact-triad/PLAN.md
**Depends on:** WI-484
**Affected Files/Specs:** default-checkout mutation hooks, `scripts/worktree.sh`, worktree/session status helpers, host setup wiring, and cross-host isolation fixtures listed in the WI-482 manifest

## Problem

Framework sessions still mutate the default checkout directly, including docs, generated files, tests, and `.svc` state. Concurrent work becomes unattributable and can contaminate later sessions.

## Affected Files

- Default-checkout mutation hooks and `scripts/worktree.sh`
- Worktree/session status helpers, host setup wiring, and cross-host isolation fixtures listed in the WI-482 manifest

## Acceptance Criteria

- [x] **AC-482-1:** Default checkout mutation is denied for docs, code, tests, generated files, and repo-local runtime writes. *(focused target, sed, symlink, and commit fixtures pass)*
- [x] **AC-482-2:** Worktrees are created only under `.worktrees/` and lazily from the then-current clean verified `origin/main`. *(clean/current/stale fixture passes)*
- [x] **AC-482-3:** Read-only operations and external job/runtime temp remain allowed. *(classifier and external-temp fixture passes)*
- [x] **AC-482-4:** Status reports WI, worktree, branch, and owning session. *(binding-backed status contract verified)*
- [x] **AC-482-5:** Create, resume, and cleanup are idempotent and do not repoint installed host symlinks. *(create/resume lifecycle and host-source checks pass)*

## Route recommendation

Execute after WI-484 verify-promotion in a newly created `.worktrees/` worktree. Full mandatory chain and cross-host fixtures.
