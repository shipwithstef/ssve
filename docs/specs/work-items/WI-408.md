## Goal
Turn the built-and-available fleet into a live unattended loop against a real company repo. The agents are designed and validated; this WI wires the runtime.

## Scope (when picked up — requires the Example Company repo path)
1. `scripts/company-state.mjs` — scaffold + read `company-state/` (state.md, metrics.jsonl, decisions-pending.jsonl, okrs.md); first-run scaffolds from template and STOPS for owner review (never invents metrics).
2. Weekly business review (WBR) synthesis: chief-of-staff collects all 4 brains' decision cards → ranked queue + narrative 1-pager + R/Y/G to `company-state/reviews/`.
3. Live `/schedule` cron activation (daily standup first; promote weekly/monthly after the daily proves out — measure-then-promote). Owner triggers the slash command (billable, outward-facing).
4. End-to-end dry run against the real company; tune model tiers for cost (daily standup may downgrade from Opus per subagent-economics gate).

## Acceptance (draft)
