**Status:** VERIFIED
**Lane:** framework
**Severity:** critical

Replace the public repository history with one privacy-sanitized root commit while preserving a complete private recovery archive.

- **AC-537-6:** All original remote branches except `main`, all original tags, and the historical SVC notes ref are removed only after backup verification.
- **AC-537-7:** Every formerly open pull request is closed with an archive pointer before its head branch is removed.
- **AC-537-8:** Framework Tier-1, manifest lint, repository privacy audit, Git object integrity, and GitHub ref/contributor checks pass after publication.
- **AC-537-9:** The publication tree contains no identifiable source-product or source-company names, repository paths, URLs, product-only work items, screenshots, marketing assets, or implementation evidence; reusable examples use the canonical anonymous identities.

## Constraints

- Never print raw secrets or newly discovered personal values.

- Keep the archive repository private.
