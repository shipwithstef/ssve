# WI-096: Skill Pre-Flight Prerequisite Check

**Type:** feature
**Status:** VERIFIED (v1 helper + advisory validator + pattern doc)
**Closed:** 2026-04-24
**Follow-up:** per-skill rollout deferred; each skill family gets its own WI to add the `## Preflight` section
**Severity:** medium
**Filed:** 2026-04-24
**Source:** capture-idea (from /insights friction analysis)
**Lane:** framework

## Goal
Every skill validates required input files exist + output write paths are writable BEFORE doing any work. Aborts with an explicit list of what's missing.

## Context
Per /insights friction analysis: at least 6 sessions stalled mid-execution because (a) Write tool was sandbox-blocked, (b) prerequisite files were missing (vision.md, builder-profile.md, etc.). Affected skills: mine-builder, write-vision, plan-changeset, stage-revenue, find-opportunity. Output ended up presented inline rather than persisted, leaving sessions in partial states.

## Hypothesized Value
Skills either run cleanly or fail loudly in 30 seconds — never half-complete with output trapped in chat.

## Broad Scope
- Add a "Preflight" section at the top of every skill SKILL.md template that:
  1. Lists all required input files explicitly.
  2. Checks they exist + are readable.
  3. Checks all output paths exist + are writable (Write tool dry-run or directory check).
  4. Aborts with a clear missing-list before doing any work.
- Add a shared helper script (e.g. `scripts/preflight.mjs`) so each skill calls one function rather than duplicating the check.
- Add a tier-1 eval that fails any skill missing a Preflight section.

## Persona Fit
Framework operator. Affects every skill author too.
