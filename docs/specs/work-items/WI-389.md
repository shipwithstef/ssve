# WI-389: spec-index query tool + forbid raw Read of the index

**Status:** in_progress (worktree wi389; query tool + validator built & verified — 3/3, idempotent + ≤2K bounded)
**Lane:** framework
**Size:** S
**Stage:** S2
**Source:** flow-architecture audit (wf_e0063433), 2026-06-08

## Problem
`.svc/spec-index.json` = 692,030 bytes / ~28,494 lines. `_shared/before-starting.md` + route-workflow + recall-stack-knowledge + dispatch-waves instruct every skill to "use" it as context-spine source #2, but `scripts/` ships only `build-spec-index.mjs` — no query tool. recall-stack-knowledge documents the fallback as "manual Read against docs/specs/**/*.md", i.e. loading the whole index.

## Mechanism
Ship `scripts/query-spec-index.mjs` (`--surface`/`--wi`/`--json`, hard-capped ≤2K tokens); a tier-1 validator forbids raw Read of the index. The index is already a structured `path#anchor` object with per-section `byte_range`, so the tool is straightforward.

## Acceptance Criteria (deterministic exit)
- [x] `query-spec-index.mjs` idempotent: same index+query → byte-identical ≤2K output (golden test). *(Verified: `--wi WI-071` run-twice byte-identical; broad query 5929 chars + `--json` 5951 chars, both ≤6000 chars = ≤2K tokens even for token-dense anchor paths. `--wi`/`--surface`/`--json`; matches sorted by anchor; returns `path#anchor [byte_range] — title` pointers, never section content.)*
- [x] `validate-spec-index-no-raw-read.sh` fails on any `Read` of the index. *(Verified: precise patterns `Read/cat <index>` + `readFileSync(...spec-index.json)` outside the allowed tools; flagged the one offender — recall-stack-knowledge's stale fallback line — now re-pointed at the query tool. before-starting + recall-stack-knowledge steer to `query-spec-index.mjs`.)*
- [x] Classifier half (intent→lane front-end) is NOT filed here — folded into WI-366's route-workflow diet. *(Honored — scope kept to the query tool + no-raw-read gate.)*

## Tier-1 promotion note (rules/tier-1-promotion.md)
- **validator_path:** `test-framework/evals/tier-1/validate-spec-index-no-raw-read.sh`
- **failure_class:** a skill/reference instructing a RAW full Read of the 692KB `.svc/spec-index.json` (a ~170K-token context blow-up), or the query tool regressing past its ≤2K-token bound / losing idempotency.
- **promotion_signal:** condition 3 — protects the context-spine read path used at 5-7 skill starts per WI (`_shared/before-starting.md`, route-workflow, recall-stack-knowledge, dispatch-waves all route through it); a regression silently re-introduces the worst-case raw-read.
- **expected_runtime_budget:** <1s (a run-twice golden + a markdown scan; no git/network/LLM).
- **why_tier_2_or_targeted_is_insufficient:** the raw-read anti-pattern is one careless doc edit away from returning, and it costs context on every routed WI; only an every-lint fail-closed gate keeps the 692KB index behind the bounded query tool.
