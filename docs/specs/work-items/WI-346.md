# WI-346: route-workflow closeout can leave completed worktrees and branches open

## Problem

After completing the Example Marketplace WI-115 RLS slices, the code, deployment, and
evidence were merged, but completed linked worktrees and branch refs remained
registered. The user had to ask why a completed worktree was still open.

This was not a missing `land-changeset` doctrine issue. `land-changeset` and
`WORKTREES.md` already require cleanup after promotion. The gap is route-workflow
closeout for end-to-end/manual PR/deploy flows that bypass `land-changeset`.
Those flows can finish publication and validation while leaving scoped
worktrees, local branches, or remote branches behind.

## Impact

Completed workspace residue makes the next session misread stale branch state as
active work, hides whether cleanup was intentionally deferred, and can leave
future agents operating from old linked checkouts.

## Fix

- Add a route-workflow Worktree/Branch Hygiene Closeout section.
- Add `route-workflow/references/worktree-branch-hygiene-closeout.md` for the
  full cleanup procedure without bloating the route-workflow hot path.
- Require final closeout to inspect scoped worktrees, local branches, and remote
  branches.
- Require completed clean worktrees/branches to be removed, or a precise
  preservation reason to be reported.
- Harden `scripts/worktree.sh remove` so a branch merged into `origin/main` is
  deleted even when local `main` is behind.
- Add a tier-1 validator for the new route-workflow hygiene contract and the
  `origin/main` fallback in `worktree.sh remove`.
- Harden two tier-1 validators that false-failed under `set -o pipefail` when
  `grep -q` exited early: `validate-skill-structure.sh` and
  `validate-self-verify-sections.sh`.

## Acceptance Criteria

- [x] `route-workflow/references/worktree-branch-hygiene-closeout.md` carries

      `git branch --list '<scope-pattern>*' -vv`, and
      `git ls-remote --heads origin '<scope-pattern>*'`.
- [x] The contract distinguishes removable completed clean work from dirty,
      unmerged, open-PR, or user-requested preserved work.
- [x] `route-workflow` Self-Verify includes a worktree/branch hygiene row.
- [x] `scripts/worktree.sh remove` deletes branches merged into `origin/main`
      even when local `main` is behind.
- [x] A tier-1 validator fails if the route-workflow hygiene contract or
      `origin/main` branch-removal fallback is removed.
- [x] The full tier-1 sweep passes after the framework change and validator
      hardening.
