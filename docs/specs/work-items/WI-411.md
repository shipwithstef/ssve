# WI-411: craft-prompt — emit world-class output-shaped prompts, proven never worse than the baseline

**Status:** verified (merged PR #76; WARN/shadow, default OFF)
**Lane:** framework
**Size:** M
**Source:** owner directive ("make better prompts, sheep-level, but don't spend billions of tokens — evaluate two options") + ultracode research dossier `docs/analysis/wi411-craft-prompt-research.md` (wf_86817540), 2026-06-22

## Problem
svc cannot CRAFT a great standalone output prompt. `route-workflow`'s Prompt Composer is a **router** (lane/sequence/evals/closeout), not a prompt-crafter — a grep for `persona|few-shot|exemplar|output-format` over it returns zero hits, and the 84-skill manifest has **zero** prompt-craft skills. The base model already knows the craft; svc has never (a) exposed an authoring rubric that unlocks it, nor (b) given the user a cheap guarantee that a crafted prompt is **never worse than the bare/"sheep" baseline**.

## Scope decision (owner, locked) — LEAN, not the token monster
The base model already knows how to make a great prompt, so v1 does **NOT** build the expensive optimizer (generate-N, run-on-many-synthesized-inputs, train/test holdout, DSPy/OPRO, leveling ledger — all deferred). v1 = **rubric + best-of-2 floor** ("evaluate two options"). The edge over the sheep is not a giant search; it is (1) the rubric, and (2) a cheap floor proving never-worse — reusing WI-410's machinery at best-of-2 (~2-3 model calls, opt-in only), not best-of-N.

## Mechanism (best-of-2, reuses WI-410 verbatim)
1. **Rubric craft** — `craft-prompt/references/authoring-rubric.md` emits a candidate **F**: persona/role line, **literal copy-paste output_format block**, 1-2 diverse few-shot (good vs bad) examples, explicit constraints/forbidden-words. Grounded in Anthropic's prompt-improver 4 steps + the in-house OUTPUT-FIRST/persona/format-lock patterns (`review-plan-codex.sh`, `ad-strategist.md`). 2026 anti-patterns encoded: **no last-turn prefill** (deprecated on Claude 4.6+), prefer `effort` over `budget_tokens`, **dial back CRITICAL/you-MUST/ALWAYS** over-prompting (Opus over-triggers).
2. **Baseline B** — the user's hand-crafted/"sheep" prompt, kept **immutable**; if none given, synthesize the obvious bare one-line prompt as B so the floor still runs. Never a refine-the-baseline edit loop (intrinsic self-correction degrades quality — Huang et al. ICLR 2024).
3. **Run both once** on ONE representative input (user-given, else one synthesized + surfaced for confirmation).
4. **Floor** — `prompt-element-extract.mjs` turns each OUTPUT into requirement-coverage `{elements:[{key,content}]}` (objective-first keys: word-count, CTA-present, format-block-present, forbidden-words-absent — regex/count, applied symmetrically to B-output and F-output). `blind-floor-check.mjs` (REUSED VERBATIM) isolates any requirement the baseline covered that F dropped; `prompt-floor-judge.sh` (fork of `blind-floor-judge.sh`, cross-family, OUTPUT-FIRST, "longer is NOT better", default-REJECT) certifies subjective rows on the OUTPUTS. Ship **F** only if it covers every baseline-covered requirement (`floor_verdict=pass`); else ship **B verbatim** (`blind-adopted` = logged negative-ROI).
5. **Receipt** — `emit-receipt --type prompt-floor` (floor_verdict, element_ledger, judge family, tree_hash).

## Invariant — NEVER-WORSE-THAN-BASELINE (honest bound, copied from WI-410)
- **Mechanical + fail-closed** only for *dropped requirements* the baseline covered.
- **Judge-conditional** for semantic quality (mitigated, not proven, by cross-family + pessimistic tie-break + content-binding).
- **Unconditional never-worse** only via baseline-retention.
- The receipt may **NEVER** assert "svc beats the sheep" as fact — only `blind-adopted` (negative-ROI) or `judge-certified-improvement` (judge family X, content-bound). A single green run is an existence proof, not a population claim.

## Economics & scope (v1 = WARN/shadow, default OFF)
Best-of-2 + running 2 prompts once multiplies tokens modestly; gate it via `prompt-floor-route.mjs` (clone of `blind-floor-route.mjs`: default OFF, opt-in `.svc/chain-policy.json`, kill-switch `.svc/prompt-craft.off`, SKIP trivial, token ceiling 1.5x). Run only when the user explicitly asks to craft/optimize/beat a prompt. WARN-only; `prompt-floor` NOT in `REQUIRED_TYPES_FULL`.

## Acceptance Criteria
- [ ] **AC1 (rubric hits the 5 elements):** the emitted prompt contains a persona/role line, a literal output_format block, 1-2 diverse few-shot examples, and explicit constraints/forbidden-words. Fixture asserts all present.
- [ ] **AC2 (2026 anti-pattern guards):** the emitted Claude-target prompt contains no last-turn assistant prefill, no `CRITICAL`/`you MUST`/`ALWAYS` caps-lock over-prompting, and uses `effort`/adaptive-thinking language not `budget_tokens`. Fixture greps fail if present.
- [ ] **AC3 (floor mechanical + fail-closed):** `planted-requirement-drop` fixture (F's output drops a baseline-covered requirement, e.g. the CTA) → `blind-floor-check.mjs` exits non-zero (`fail`). Run-twice-golden.
- [ ] **AC4 (retention never-worse):** `judge-unavailable` fixture → ship baseline verbatim (`blind-adopted`, exit 0), zero judge dependence.
- [ ] **AC5 (cross-family anti-self-grade + anti-replay):** a certification with `reviewer_family==anthropic` is rejected as forged self-cert; a stale `for_content_sha` is rejected.
- [ ] **AC6 (one real beat-the-baseline proof):** one proof-session on a REAL viral baseline (awesome-chatgpt-prompts cold-email: "under 100 words, one CTA, P.S. social proof") + one real input runs the full best-of-2 floor and emits a valid `prompt-floor` receipt (`pass` or `blind-adopted`); no "beats sheep" claim.
- [ ] **AC7 (economics gate):** `prompt-floor-route.mjs` returns `run:false` for trivial/not-opted-in/kill-switch; `run:true` only opted-in + non-trivial + judge available. Pure unit fixture.
- [ ] **AC8 (shadow-mode safety):** static assertion that `prompt-floor` is NOT in `check-chain-receipts.mjs` `REQUIRED_TYPES_FULL`.
- [ ] **AC9 (registry sync + prior-art + tier-1 green):** `craft-prompt` added to `includedSkills` + README (lint green); `intent-routing` row added; `validate-prompt-floor.sh` green under `run-all-evals.sh --tier1`.
- [ ] **AC10 (DISTINCT-NEW provenance):** spec records no existing skill crafts a standalone output prompt; does NOT fold into create-skill (trigger-description, same-family) or Prompt Composer (router).
