## Residual 1 — svc-stop-quality hermetic runtime denial proof

WI-487 AC-487-7 requires every blocking hook to emit the actionable 5-field
`emitDenial` envelope. 10 of 11 `adopt-emitDenial` hooks are RUNTIME-driven to
their real block path in `validate-actionable-hook-denial.sh`. `svc-stop-quality`
is asserted only at SOURCE level (its block path routes through `emitDenial`, but
driving the actual block hermetically needs a detected tsconfig + `npx tsc`
producing NEW type errors versus a recorded session baseline + a populated
edited-files accumulator — not reproducible in a network-free <5s tier-1 fixture).
The reviewer certified this a dispositionable High EVIDENCE risk, not a Critical.

**Goal:** a hermetic (or gated tier-1.5) fixture that drives svc-stop-quality's
real block path and asserts the full 5-field envelope + durable receipt + block
exit, closing the last runtime-coverage gap.

## Residual 2 — opencode / mimo-code durable pre-mutation enforcement

WI-487 routes governed hooks through the durable non-symlinked launcher for the
hosts that have a launcher-routable command-hook (claude/codex/gemini/kimi).
`opencode` and `mimo-code` are declared `governed:false, enforcement:"git-pre-commit"`
because their host model exposes no command-hook the launcher can be inserted
into — so their pre-mutation enforcement remains checkout-bound (it vanishes if
the checkout is deleted, the exact WI-487 failure class, for those two hosts only).
The reviewer certified the EXPLICIT `governed:false` disposition truthful and
acceptable, provided git-pre-commit is not represented as pre-mutation enforcement
(it is not). Durable pre-mutation enforcement for these two hosts needs a
host-native launcher-routable hook that does not currently exist.

**Goal:** if/when OpenCode + MiMo-Code expose a pre-mutation command-hook, add a
launcher-routable adapter so their governed enforcement becomes durable too; until
then, keep the explicit `governed:false` declaration and ensure drift/healthcheck
surface these hosts as non-launcher-durable (not silently converged).
