## Goal
Add `.claude/agents/ad-video-producer.md` — a native locked agent that turns a WI-400 **beat sheet** into a single **consistent ~60s video**, working around the hard reality that no model renders a coherent 60s clip in one shot (Veo 3.1 8s; Runway/Kling/Pika ~10s; only Sora 2 16–20s). It owns the tools, the continuity tricks, and the render APIs.

## The render pipeline (sourced 2026 tooling — Path A default)
```
BEAT SHEET (6×~10s, from ad-video-script)
   │  per beat:
   ▼
1. KEYFRAME  → Nano Banana Pro (gemini-3-pro-image), same 3 char/product refs → consistent first frame   ◄ consistency won here
2. CLIP      → Veo 3.1 image-to-video (motion prompt + "Ingredients" refs, native audio)
3. CHAIN     → seed beat N+1 from beat N's last frame, OR Veo native scene-extension (7s/hop → 148s)        ◄ shot-to-shot continuity won here
4. AUDIO     → one ElevenLabs VO track + one music bed (Suno/Udio via swappable iface), ffmpeg sidechaincompress duck
5. STITCH    → ffmpeg concat demuxer (uniform) / xfade; or Veo extend already-continuous
   ▼
~60s ad, consistent character/style/audio
```
Escape hatch: **fal.ai / Replicate** (one key) front Kling 2.6 (start+end frame, Elements) / Runway Gen-4 (References) when a shot needs a different look or longer clips.

## Scope (when picked up)
1. `.claude/agents/ad-video-producer.md` locked agent (model via `resolve-model.sh`; scoped to generate-visuals + the render tools).
2. Extend `generate-visuals` (or a new `references/video-render-pipeline.md`) with the chained-beat pipeline: keyframe → i2v → last-frame chain → stitch → audio.
3. Provider interface with two paths: **Path A Veo 3.1 via Gemini API** (default, fewest seams); **Path B aggregator (fal/Replicate)** for Kling/Runway. Swappable music provider (Suno/Udio unofficial — flagged supply-chain risk).
4. Async job model: submit → poll → fetch per clip; assemble; emit the final asset + a per-beat manifest (which tool/seed/refs produced each clip — reproducibility).
5. Continuity QA: verify character/style consistency across beats (the lens that catches "clip 3 changed her apron color").

## Guardrails
- Requires API keys (Gemini/Vertex for Veo, or fal/Replicate, + ElevenLabs) — `provider-auth-or-token` blocker class; gate on keys present, do not fake-render.
- Suno/Udio have **no official API** — behind a swappable interface; never hard-wire. Sora 2 sunset (OpenAI doc) — do not hard-depend.
- Subagent economics gate (CC guidelines): measure-then-promote, kill-switch to serial.
- No fabricated product features propagate from script to render (inherits WI-400 §8).
