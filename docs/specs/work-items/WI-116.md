## Problem

`hooks/hooks.json` declares only PreToolUse, PostToolUse, Stop. Claude Code supports
~27 lifecycle events. Missing hooks (SessionStart, UserPromptSubmit, PreCompact,
SessionEnd, Notification) leave the framework blind to entire classes of failure,
including the WI-111 dangling-symlink class. The fix is not to keep hooking
exploits one-by-one but to ensure every lifecycle event has a documented posture.

## Scope

### In scope
- New `hooks/hook-coverage-spec.md` enumerating Claude Code events with svc posture (block/warn/observe/skip) and Wired? flag
- New tier-1 validator `validate-hook-coverage.sh` enforcing spec → wiring contract
- 5 new hook scripts: SessionStart healthcheck, UserPromptSubmit stale-state, PreCompact snapshot, SessionEnd log, Notification surface
- 5 new entries in `hooks/hooks.json` for the corresponding events

### Out of scope
- StopFailure, PostCompact, SubagentStart, SubagentStop wiring (documented but not yet wired)
- Per-host wire scripts (covered by WI-118)
- Settings.json wiring — `wire-hooks.mjs` already enumerates these events and will pick up new entries automatically

## Acceptance criteria

1. `hooks/hook-coverage-spec.md` lists all key Claude Code events with posture + Wired? flag. ✅
2. `validate-hook-coverage.sh` parses the spec and asserts every Wired=Yes block/warn event is in `hooks/hooks.json`. ✅ 5/5 passing
3. 5 hook scripts created, all executable, all fail-open (never block). ✅
4. `hooks/hooks.json` has SessionStart, SessionEnd, UserPromptSubmit, PreCompact, Notification entries. ✅
5. Tier-1 sweep passes with new validator counted. ✅
6. `node scripts/lint-skills-manifest.mjs` clean. ✅

## Risk

LOW. All new hooks are observe/warn — none block. Failure mode: a buggy hook prints
to stderr but exits 0, so the host pipeline is unaffected. Each hook ≤80 lines pure node.
