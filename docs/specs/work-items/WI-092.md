## Goal
Allow the builder to fan out N pasted guides into independent worktree sessions, each running `ingest-guide` (WI-091) end-to-end, with a coordinator that aggregates results back into one report.

## Context
When the builder has a backlog of guides to process, doing them serially in one session is slow and pollutes context. Parallel sessions in worktrees keep contexts clean and let extraction/validation happen concurrently.

## Hypothesized Value
Bulk throughput for knowledge ingestion. Lets the builder dump 10–20 guides at once and come back to a digest of what got promoted, what got stored, what got discarded — instead of doing them one at a time.

## Broad Scope
- Thin orchestrator skill (NOT a new lane). Reuses existing worktree convention from `scripts/worktree.sh`.
- Input: list of pasted guides (or a directory of pre-pasted files).
- Spawns N worktree sessions, each invoking `ingest-guide` (WI-091) on one guide.
- Coordinator collects per-session outputs and emits a single digest: per-guide decision (discard / store / promote), promoted-skill drafts ready for `create-skill` review.
- Failure isolation: one failing session does not block the others.

## Persona Fit
Framework maintainer / svc operator (specifically when in batch-ingestion mode).
