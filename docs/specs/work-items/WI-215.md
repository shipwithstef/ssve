# WI-215: Trim route-workflow hot-path skill body

## Goal

Reduce repeated `/route-workflow` context injection by moving non-routing detail out of the hot-path `SKILL.md` body.

## Context

The audit estimated that `/route-workflow` injected roughly 10K tokens per invocation and around 50K duplicated tokens in one session. The skill already references detail files, but the top-level contract still carries too much repeat content for a universal entry point.

## Acceptance Criteria

- AC1: `route-workflow/SKILL.md` is reduced to the routing-critical contract and operational checklist, targeting 80 lines or less where practical.
- AC2: Existing detailed sections are moved to focused files under `route-workflow/references/`.
- AC3: All references from the trimmed skill resolve to existing files.
- AC4: Existing tier-1 route-workflow and manifest checks still pass after the split.

## File Impact

- `route-workflow/SKILL.md`
- `route-workflow/references/*.md`
- Any manifest or documentation files that enumerate route-workflow references
