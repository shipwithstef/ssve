# WI-203: Cross-cutting infrastructure does not generate journeys

## Status: Closed — duplicate of WI-169

This item was filed from review finding F-033 ("cross-cutting infrastructure does not generate journeys"). On audit, the same gap is already captured by [WI-169](WI-169.md) — `catalog-domain-capabilities → write-journeys` auto-chain for table-stakes capabilities (multi-language, theme-switching, auth-state-recovery, etc.). WI-169's proposal is the same intervention F-033 calls for: when the capability matrix knows a cross-cutting capability is in scope and the stack matchers fire, journey skeletons are auto-generated.

Track this finding under WI-169. F-033 should be considered resolved when WI-169 lands.

## Original Problem (preserved for reference)

The framework reliability review found HIGH issue F-033: Cross-cutting infrastructure does not generate journeys. User-facing flows such as language switching and theme toggles can ship without journeys because they are treated as infrastructure.
