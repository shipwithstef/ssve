# WI-218: Union-merge append-only svc jsonl logs

## Goal

Prevent recurring mechanical merge conflicts in append-only `.svc/*.jsonl` state logs.

## Context

The audit found three `.svc/pipeline-decisions.jsonl` conflicts during a stacked PR merge cycle, all resolved identically. These logs are append-only and fit Git's union merge behavior.

## Acceptance Criteria

- AC1: `.gitattributes` configures `.svc/*.jsonl` with `merge=union`.
- AC2: The change is additive and does not alter existing log content.
- AC3: Git recognizes the attribute for `.svc/pipeline-decisions.jsonl`.

## File Impact

- `.gitattributes`

## Completion

Implemented in the same changeset that filed this WI by adding `.svc/*.jsonl merge=union` to `.gitattributes`.
