# WI-332: Brownfield iteration PR and review binding enforcement

**Type:** enabler
**Status:** VERIFIED
**Severity:** high
**Filed:** 2026-05-12
**Source:** proposals/done/2026-05-05-evolution.md#P0-F2-P1-F3
**Lane:** framework
**Related:** WI-305, WI-323, WI-219, WI-320

---

## Problem

The delivery graph compiler covers normal brownfield-feature flows, and WI-323
tracks PR merge receipt enforcement. The remaining brownfield-iteration gap is
earlier in the path: visual or feature iteration task graphs can still encode a
review step as unbound prose, and direct commits on `main` can bypass the
worktree/PR discipline before `gh pr merge` is ever reached.

## Evidence

- `proposals/done/2026-05-05-evolution.md#P0-F2`
- `proposals/done/2026-05-05-evolution.md#P1-F3`
- `route-workflow/references/lane-model.md` defines review and promotion
  obligations for feature-class work, but there is no canonical
  `brownfield-iter-visual` task template with `metadata.skill: "review-gate"`.
- Existing PR merge receipt enforcement is tracked by WI-323, but it does not
  block direct-to-main commits before a PR exists.

## Acceptance Criteria

- [x] Define or reject a first-class brownfield iteration lane/template with a
      validator-backed rationale.
- [x] If retained, every review task in that template must bind
      `metadata.skill: "review-gate"`.
- [x] Add a branch/worktree guard that blocks feature or brownfield-iteration
      implementation commits on `main` unless an explicit framework-docs
      exception applies.
- [x] Add tier-1 fixtures for direct-main blocked, allowed docs exception, and
      review task missing `metadata.skill`.
- [x] Coordinate with WI-323 so PR merge receipts and pre-PR branch discipline
      are not duplicate gates.

## Route Recommendation

Run as a framework hardening WI after or alongside WI-323.

## Closeout

Implemented on 2026-05-12.

- Kept `references/templates/brownfield-iter-visual.json` as the first-class
  brownfield visual iteration template and added
  `scripts/validate-brownfield-iteration-guard.mjs` to fail review tasks that
  are not bound to `metadata.skill: "review-gate"`.
- Extended `hooks/svc-workflow-guard.mjs --bash-guard` with
  `svc-direct-main-feature-commit`, blocking feature/brownfield-iteration
  implementation commits on `main` while allowing docs/framework exception
  commits.
- Added `test-framework/evals/tier-1/validate-brownfield-iteration-guard.sh`
  with fixtures for direct-main blocked, docs exception allowed, and review
  metadata binding.
- Left PR merge receipt enforcement under WI-323; this WI covers the pre-PR
  branch discipline and review-task binding surface.

Verification:

  PASS, 5 passed / 0 failed.
