## Goal

Run an independent review once, then verify the exact immutable evidence from any
worktree, canonical main, or post-promotion checkout without rerunning the
reviewer, fabricating receipts, or preserving the original execution worktree.

## Context

The genuine WI-542 plan and execution reviews were performed earlier by AGY
(Gemini 3.7 Flash High through `dispatch-agy.mjs`). Their Git-note receipts carry
valid hashes and relative evidence entries, but the launcher receipts and command
provenance self-bind absolute paths beneath:

`.../.worktrees/bugfix-wi-542-grok-sessionstart-healthcheck/.svc/external-review-artifacts/...`

`scripts/lib/reviewer-evidence.mjs` resolved evidence relative to the current
checkout and required the launcher receipt's absolute artifact path to equal that
new location. Therefore `check-chain-receipts --sha f27a143a` passed only where
the original worktree-local layout existed and failed from canonical main.
Copying unchanged bytes did not satisfy absolute self-binding; rewriting the
receipt would change its digest and fabricate evidence.

## Acceptance Criteria

- [x] AC-547-1: `check-chain-receipts --sha f27a143a` passes from canonical main using the original AGY-produced bytes and no reviewer invocation.
- [x] AC-547-2: The same check does not require the original WI-542 implementation worktree to still exist (digest store + relocation).
- [x] AC-547-3: Original launcher receipts, findings, packages, transport receipts, and Git-note hashes remain unchanged.
- [x] AC-547-4: A changed byte, symlink source, or conflicting relocation fails closed.
- [x] AC-547-5: A new successful review promotes artifact bytes into the shared store (`run-external-review` relocate after write).
- [x] AC-547-6: Artifact promotion and legacy relocation are idempotent.
- [x] AC-547-7: Focused tests cover digest store, legacy relocate, worktree deletion, tampering, and symlink refusal.

## Implementation

- `scripts/lib/review-evidence-store.mjs` — objects under `$(git rev-parse --git-common-dir)/svc-review-evidence/`
- `scripts/relocate-review-evidence.mjs` — copy exact bytes; record historical path → object id
- `scripts/lib/reviewer-evidence.mjs` — resolve missing/absolute paths via the store; compare outputs by digest
- `scripts/lib/external-review-provenance.mjs` — verify issuance by content hashes, not worktree-absolute paths
- `scripts/run-external-review.mjs` — promote successful artifact dirs into the store
