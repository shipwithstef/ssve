## Problem

Sessions produce N load-bearing framework learnings per run; the framework's learning pipeline is read-only at session start and write-only on user request, so the learnings get discarded at session end. The WI-341 tranche 1 session (PRs #121, #122) produced 5 framework-grade learnings that required explicit user demand to capture; without it they would have been lost. See `proposals/2026-05-12-auto-learning-capture-hook.md` for the full root-cause + design.

## Evidence

- `hooks/svc-learning-preload.mjs` — reads learnings at session start
- `hooks/svc-session-end-log.mjs` — logs session-end metadata but not learnings
- `references/framework-learnings.jsonl` — entries 73-77 (added 2026-05-12) were manually captured ONLY after user directive "LEARNING SHOULD BE AUTOMATIC"
- `.svc/pipeline-decisions.jsonl` — captures in-flight decisions but does NOT promote them to learnings
- `audit-session-execution` + `manage-learnings` skills — both user-invoked

## Acceptance Criteria

- [ ] Add `hooks/svc-auto-capture-learnings.mjs` wired via the existing `scripts/wire-hooks.mjs` / `scripts/wire-kimi-hooks.mjs` machinery per host. Claude Code: `Stop`, `PreCompact`, `PostToolUse` (Edit/Write matcher). Codex and other hosts: `Stop` equivalent only (no `PreCompact` available). Per-host config flows from `provision/hosts/<host>.json`. No direct `settings.json` reference in the hook code.
- [ ] Add `scripts/lib/learning-candidate-detector.mjs` implementing the 6 signal heuristics from the proposal (correction-after-failure, review-finding remediation, hook side-effect, recursive failure observation, stale-capability rediscovery, new rule-class observation).
- [ ] Add `scripts/lib/learning-dedup.mjs` — hash key + confidence dedup; skip-if-existing-equal-or-higher.
- [ ] Add `scripts/lib/resolve-user-memory-path.mjs` — host-neutral resolver. Returns `~/.claude/projects/<slug>/memory/` for Claude Code, host-equivalent for Codex/Gemini/Kimi/OpenCode (per `provision/hosts/<host>.json`), falls back to `~/.svc/per-host/<host>/projects/<slug>/memory/` for hosts without a native equivalent.
- [ ] Add `scripts/capture-session-learnings.mjs` — standalone CLI for the manual case (`node scripts/capture-session-learnings.mjs [--summary] [--review] [--scope <window>]`).
- [ ] Add `scripts/promote-auto-learnings.mjs` — explicit promotion path. Reads `.svc/auto-learnings.jsonl`, classifies entries, emits review prompt, writes approved entries to the appropriate tracked file. NEVER auto-promotes.
- [ ] **Default capture target is the gitignored audit log only.** The hook writes ONLY to `.svc/auto-learnings.jsonl` by default. It MUST NOT write to `references/framework-learnings.jsonl`, `docs/learnings/learnings.jsonl`, or any tracked user-memory path without explicit user invocation of `scripts/promote-auto-learnings.mjs` (or `manage-learnings promote --from-auto`). Verified by tier-1 fixture: a default-mode run that scans a session with N learning candidates produces ZERO `git diff` against tracked files.
- [ ] Opt-in `SVC_AUTO_LEARN_SUMMARY=1` adds a 3-line session-end summary; storage target unchanged (still gitignored audit log only).
- [ ] Opt-in `SVC_AUTO_LEARN_REVIEW=1` writes to `.svc/auto-learnings.draft.jsonl` and waits for user merge; tracked files still untouched.
- [ ] Add `.svc/auto-learnings.jsonl` and `.svc/auto-learnings.draft.jsonl` to `.gitignore`.
- [ ] Update `hooks/svc-learning-preload.mjs` to ALSO read `.svc/auto-learnings.jsonl` for in-session entries so the next session preloads them even before promotion.
- [ ] Add `concerns/auto-learning-capture.md` declaring the signals + required_skills per `rules/concern-routing.md`.
- [ ] Tier-1 validator `validate-auto-learning-capture.sh` covering 5 fixtures: (a) correction-after-failure session captures entry to gitignored log, (b) duplicate-confidence dedup skips, (c) silent mode produces no stdout, (d) summary mode emits 3-line output, (e) **default-mode run leaves `git status` clean for all tracked learning files** (the regression test for the F-2-class leakage Codex flagged). Promotion note per `rules/tier-1-promotion.md` is in the proposal.
- [ ] Replay fixture using THIS session's 5 captured learnings (from `references/framework-learnings.jsonl` entries 73-77) — prove the hook would have caught them automatically AND would have written them to `.svc/auto-learnings.jsonl` (gitignored), not directly to the tracked file.
- [ ] Hard runtime budget on the scanner: ≤200ms timeout; on timeout, log warning and skip without blocking session end.
- [ ] Cross-link: `rules/learning-preload.md` (reader contract), `rules/plan-changeset-trigger.md` (this WI's risk class), `hooks/svc-learning-preload.mjs` (the consumer), `audit-session-execution/SKILL.md` (the deeper-analysis sibling that this hook does NOT replace).
