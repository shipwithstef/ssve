## Goal

Resolve every review and subagent invoke from owner-external configuration at
`now`, then an optional work overlay, then an explicit session override. Never
silently remap Grok, Cursor, or AGY to Claude or Codex.

## Boundaries

In scope: schema, `scripts/resolve-dispatch.mjs`, callers of `resolve-model.sh`,
`review-topology-v2.mjs`, `resolve-adversarial-reviewer.sh`, review launchers,
stage executors, dispatch-waves, Task/Agent spawn.

Out of scope: continuation lifecycle (WI-552), host Stop chmod (WI-545),
receipt store (WI-547/WI-550).

AGY is a reviewer transport, not a general orchestrator.

## Acceptance Criteria

- [ ] AC-551-1: Single resolver reads `~/.svc/dispatch-policy.json` or `SVC_DISPATCH_POLICY` at invoke time.
- [ ] AC-551-2: Missing global file refuses; it does not fall back to `svc-default` / Sonnet 5 / Claude.
- [ ] AC-551-3: Session override applies only when requested and receipted; otherwise equals global ⊕ work overlay.
- [ ] AC-551-4: Work overlay does not leak to another WI.
- [ ] AC-551-5: Deny is per-role and fail-closed. `svc-default` cannot bypass a deny.
- [ ] AC-551-6: Gemini / AGY is last-resort or explicit ask, never a default independent while preferred stations are available.
- [ ] AC-551-7: Grok stays Grok and Cursor stays Cursor when the effective policy names them. Remap-to-Claude fixtures fail.
- [ ] AC-551-8: Example schema ships; live entitlements never land in this repo.
- [ ] AC-551-9: Focused tests cover the proposal AC-10 replay matrix. No paid provider.

## Affected files / contracts

- new `schemas/dispatch-policy.schema.json`
- new `scripts/resolve-dispatch.mjs`
- `scripts/resolve-model.sh`, `scripts/review-topology-v2.mjs`, `scripts/resolve-adversarial-reviewer.sh`
- `scripts/review-plan-codex.sh` / `scripts/run-external-review.mjs` (consume resolver; do not hardcode claude|codex)
- session-contract override field
- example at `examples/dispatch-policy.example.json`

## Migration

Owner copies the example to `~/.svc/dispatch-policy.json` and edits entitlements.
Until that file exists, resolver refuses rather than remapping.

## Rollback

Keep unknown-host refusal (`missing owner file` and `unknown host` both refuse).
Restore prior host→profile tables only behind that refuse. Do not restore
silent remap to Claude/Codex as a working default.

## Provider cost

Resolver itself is free. Later production reviews pay only the stations the
owner file requires.
