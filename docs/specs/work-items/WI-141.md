# WI-141: design-logo skill — remove designer-handoff exit, reach designer-grade via AI orchestration alone

**Type:** framework
**Status:** VERIFIED
**Severity:** high
**Filed:** 2026-05-02
**Source:** Promoted from `proposals/2026-05-02-design-logo-evolution.md`. Filed after Example Marketplace session 2026-05-01 → 2026-05-02 ran 4 rounds + 60+ generated logo options across multiple image-gen providers (Codex SVG, Base44 GPT-image) and could not exit ~58/70 plateau. User caught the failure mode: "this can't be the solution — the current arch looks like nothing special, weird position, can't be the answer." Same pattern as WI-139 (skill self-grades PASS while user catches the actual quality gap on first eyeball).
**Lane:** framework

## Symptom

design-logo (current SKILL.md) has a Phase 9 saturation gate that routes <60/70 outputs to a designer-handoff brief ("AI ceiling reached → hire human"). In the AI era this is the wrong exit. The framework's own founder explicitly: "AI ERA → NO DESIGNER. Remove the designer rule. Change to achieve designer-grade creativity."

Every plateau the skill currently treats as "AI hit ceiling, hand to human" is in fact a **search-space problem** — a constraint hasn't been added that breaks the pattern. The skill has no mechanism to escalate constraints when iterations flatline; it just gives up and produces a handoff brief. Result: real founders never get a designer-grade mark out of the skill.

Secondary symptoms surfaced in the same session:

1. **Skill never auto-triggers from ad-hoc image-gen URL pastes.** route-workflow doesn't recognize Base44/OAI/Midjourney URL pastes as design-logo runs. 60+ options were evaluated by-eye outside any formal phase.
2. **No love-test gate.** Every check is "competent / legible / on-brand." Nothing tests "memorable / impressive / lovable / would-tattoo-it."
3. **No lockup-stutter test.** A monogram of letter X cannot sit next to a wordmark starting with X. "H + Example Marketplace" is visual stutter — caught manually after declaring round-4 #6 (H-Bauhaus) the winner.
4. **Breadth-over-depth.** Phase 8 says "iterate top 3" but in practice the skill keeps generating NEW concepts each round rather than refining 2-3 in depth.
5. **Founder-shrug not decisive.** When founder says "it's fine / okay / I guess" the skill doesn't treat that as saturation failure; rubric score overrides the eyeball.

## Root causes

1. **Phase 9 saturation gate has a handoff exit.** This is the load-bearing wrong assumption.
2. **Phase 8 "iteration loop" is 3 generic passes** (optical correction, kerning, distinctiveness pump). Real designer-grade refinement is a multi-tool pipeline (geometry hand-edit → style transfer → vector trace → motion test → sand-grain polish). The skill collapses 5 stages into 3 vague passes.
3. **No constraint-escalation when plateau hits.** Senior designers respond to plateaus by ADDING constraints (one-color only, must work in negative space, must hide a second meaning, ≤5 path ops). The skill has no such ladder.
4. **Exemplar bank lacks "memorable hook" entries.** Current bank entries score on principle alignment but don't isolate the hidden-meaning quality (FedEx arrow, Toblerone bear, Wendy's mom) that separates great marks from competent ones.
5. **Image-gen output is treated as terminal.** It is a sketch stage. The skill doesn't have an explicit refinement stack from sketch → vectorized geometry → motion-tested mark → context-validated final.

## Fix direction

Eight additive changes + 2 validators + 10 exemplar-bank extensions. Per the proposal:

### A. DELETE Phase 9b designer-handoff entirely

Remove SKILL.md sections "Designer-handoff brief", "What's done (don't redo)", "What's needed from you (8–15 hrs)", "Why we stopped". Replace with one paragraph stating the skill cannot stop below 65/70 and plateau = constraint problem, not craft-ceiling problem.

Tier-1 validator `validate-design-logo-no-handoff.sh` greps SKILL.md for forbidden phrases ("hire a designer", "designer handoff", "AI ceiling", "human designer", "external designer") — fails lint if any present.

### B. Phase 1c — Concept commitment ledger

`docs/specs/logo-pack/concept-ledger.md` tracks round number + mode (`exploration | refinement | polish | terminal`). After round 2, mode flips to `refinement`. After round 5, flips to `polish`. New concepts after round 2 = skill failure.

### C. Phase 5b — Love-test gate

5 questions on top-3 concepts: (1) tattoo test, (2) $5k test, (3) reverse-jealousy test, (4) 5-year test, (5) outsider stranger test. Failures route to constraint escalation, not handoff.

### D. Phase 7b — Lockup-stutter test

If the chosen mark is a single letter AND that letter is the brand wordmark's first letter, render mark + wordmark side-by-side at 4:1 horizontal lockup. If letter visually duplicates against wordmark first character, the mark is disqualified for production lockup use regardless of rubric score. Loop back to Phase 3 for non-letterform alternatives.

### E. Phase 8 rewrite — 5-stage multi-tool refinement pipeline

Replace the current 3-pass loop with: Stage A geometry refinement (vectorize + optical correction) → Stage B style-transfer iteration (img-to-img with senior-studio prompts) → Stage C vector trace + kerning audit → Stage D motion + context test → Stage E sand-grain polish. Each stage MUST improve combined score by ≥2 points or stage is failed and retried.

### F. Phase 8b — Constraint-escalation ladder

When refinement round produces zero score improvement, escalate constraints: one-color only → must work in negative space → must contain hidden second meaning → ≤5 path operations → must embed brand-vocabulary glyph. Each plateau adds the next constraint. After 3 plateaus despite stacked constraints, log framework-gap entry naming the failure mode (do not handoff).

### G. Phase 9 rewrite — saturation gate without handoff

Score table: ≥65/70 → promote with love-test re-check. 60-64 → Phase 8 full pipeline rerun + Phase 8b plateau escalation. 56-59 → all constraints stacked simultaneously + cross-model judge re-score. <56 → brief itself is broken, re-enter Phase 0. No handoff exit at any tier.

### H. Phase 13 amendment — Founder-shrug as decisive saturation failure

After in-app verification screenshot capture, ask the founder one question: "Looking at this on the live site with fresh eyes — does this impress you, or does it just look fine?" A "fine / okay / I guess / sure" answer = hard-fail. Loop back to Phase 8 Stage A with constraint escalation. Cannot be overridden by rubric score.

### I. route-workflow auto-invoke on image-gen URL pastes

When user pastes ≥3 image URLs from known image-gen domains (`media.base44.com`, `oaiusercontent.com`, `r2.cloudflarestorage.com`, `imagine-image.app`, `cdn.midjourney.com`) AND surrounding text mentions "logo / mark / brand / concept", route-workflow auto-invokes design-logo in **evaluation mode** (skip Phase 1-3, enter at Phase 5 with pasted images as concepts).

### J. Exemplar bank — extend with 10 hidden-hook entries

FedEx (negative-space arrow), Toblerone (bear in mountain), Amazon (a-to-z curve), Hershey's Kisses (Kiss in wordmark gaps), Tour de France (cyclist in R), Pittsburgh Zoo (gorilla + lion negative space), Wendy's (hidden "mom"), Baskin-Robbins (31 in BR), Tostitos (two friends + chip + salsa), Galleries Lafayette (G-L ligature). Each entry documents the hook's discovery rule.

## Why high severity

Same archetype as WI-139 — skill self-grades PASS while user catches the gap on first eyeball. WI-139 was for `landing-page`; this is for `design-logo`. The recurrence pattern (skill produces ~60/70 work that founder shrugs at) is now framework-wide for visual-output skills. Promoting from incident to pattern: per `rules/learning-preload.md` learning-to-rule threshold (≥3 sessions same signature), the visual-skill-self-grading-failure mode now warrants a framework-level fix.

Cost of NOT fixing: every founder running design-logo gets a handoff brief instead of a finished mark. Skill becomes shelfware in the AI era — the very era it was designed for.

Cost of fixing: bounded (~1 week of framework work). All changes are additive to one skill + 2 small validators + intent-routing tweak.
