## Problem
The 7 mandatory-chain skills (~2,958 lines post-WI-366 diet) all run in ONE orchestrator session per WI. `references/context-budget.md` classifies that single accumulating context as DEGRADING (50-70%) → POOR (70%+, "silent partial completion"); the 2026-06-06 eval estimated 25-45% mandatory-step dropout. `references/context-budget.md:47` mandates "orchestrator routes, subagents execute" — the prose chain mechanically violates it.

## Mechanism
Re-base the chain onto per-stage fresh subagents (or a saved native Workflow segment). Each stage boots a clean context loaded with only its own SKILL.md + the prior stage's receipt/baton, works in the single shared worktree, and returns a ≤1K-token schema-forced summary. Orchestrator holds only session contract + stage summaries + receipts index. Stages stay strictly sequential — this isolates CONTEXT, not ordering.

## Tier-1 promotion note (rules/tier-1-promotion.md)
- **validator_path:** `test-framework/evals/tier-1/validate-stage-isolation.sh`
- **failure_class:** a stage segment SILENTLY CONTINUING past a missing receipt (the fail-closed SHA-verify regressing to fail-open), the kickback ladder losing a backward path (a CRITICAL/structural finding not forcing re-execute/re-plan), or the segmentation drifting off the human_checkpoint seams.
- **promotion_signal:** condition 3 — this governs how the mandatory chain executes; a fail-open segment runner would let an unreceipted (unreviewed) stage pass.
- **expected_runtime_budget:** <2s (pure state-machine unit + a temp-git-repo receipt-verify roundtrip; no network/LLM).
- **why_tier_2_or_targeted_is_insufficient:** the fail-closed receipt-verify + the kickback backward-control-flow are the safety of the isolated chain; a silent regression lets a stage skip its gate, so they must be re-proven every lint.

## Value-preservation
Increases value: a script cannot skip a stage (dropout → ~0), and review-exec/audit in fresh contexts cannot see the executor's reasoning — directly mitigating self-preferential bias. **Risk:** fresh contexts lose cross-stage nuance UNLESS the baton (WI-381) lands first — hard dependency.

## Vision fit (whole-company / versatile PM)
Gives each department its own focused room with a clean desk so the CEO's attention never degrades across a full delivery — the precondition for one orchestrator to run every role end-to-end as a company, not a single overloaded employee.
