# WI-401: `ad-strategist` evolving locked agent + CTR/CPA feedback loop

**Type:** framework
**Status:** backlog
**Severity:** medium
**Filed:** 2026-06-18
**Source:** WI-400 scope split (self-improving-agent research, 2026-06-18)
**Lane:** framework
**Depends on:** WI-400 (the `ad-video-script` skill must exist first), WI-372 (native locked-agent policy)

## Goal
Add `.claude/agents/ad-strategist.md` — a native locked role-agent that **wields** the `ad-video-script` skill and **levels up over time** from real performance data. This is the "gets better, earns experience" agent the user asked for; it is split from WI-400 because the leveling-up property requires a real CTR/CPA signal that cannot be fabricated in a static skill.

## Architecture (from research — ExpeL two-pool + eval-gate + retrieval)
Reuse svc's existing machinery (`learnings.jsonl` + confidence 1–10 + promotion ≈ ExpeL's scored insight pool), retargeted at campaign outcomes:

```
NEW BRIEF ─► GENERATE (persona/voice block + top-k WINNING examples retrieved by brief similarity
                       + active PLAYBOOK heuristics) ──► ad-video-script skill renders
                 │ script ships
                 ▼
            MEASURE  ◄── CTR / hook-rate / hold-rate / CPA   (the load-bearing input)
                 ▼
            APPEND → campaigns.jsonl                         (episodic, immutable)
                 ▼
            GATE (eval: hook_rate/CTR ≥ bar?)
               yes → promote to winning-examples.jsonl       (procedural bank, performance-tagged)
               no  → Reflexion "why it lost"                 (scored lesson)
                 ▼
            DISTILL → playbook.md heuristics (semantic; confidence +1 holds / −1 contradicted;
                      bounded ~20 rules so the persona stays sharp, not bloated)
                 └──► feeds next GENERATE  (loop closes)
```

## Scope (when picked up)
1. `.claude/agents/ad-strategist.md` locked agent (model via `resolve-model.sh`; scoped to the marketing skill subset incl. `ad-video-script`, `generate-visuals`, `build-personas`).
2. `campaigns.jsonl` schema (episodic) + eval-gate threshold config + `winning-examples.jsonl` (procedural bank) + `playbook.md` (semantic, confidence-scored).
3. Performance ingest adapter (Meta/TikTok ad API or Motion export) → diagnostic matrix (hook×hold quadrants) → score updates.
4. Per-placement winning-pattern libraries (feed-ad / landing / pdp / launch leveled independently).
5. v2-only (defer to v3): DSPy/GEPA prompt-optimization pass once ≥50–100 CTR-labeled scripts exist.

## Guardrails
- Subagent economics gate (per CC guidelines): dispatch tree, model tiers, ≤4 lenses/≤1K returns, measure-then-promote (≤1.5× tokens + quality non-regression), kill-switch to serial.
- The leveling-up loop is inert without a real CTR/CPA signal — do not ship a fake/simulated signal; gate on real data being wired.
- No fabricated proof stats propagate into the winning-examples bank (inherit `ad-video-script` self_verify §8).

## Acceptance (draft)
- AC1: `ad-strategist` agent file exists, valid locked-agent frontmatter, scoped tool/skill set.
- AC2: A campaign outcome appended to `campaigns.jsonl` and passing the eval gate is promoted to `winning-examples.jsonl`.
- AC3: A subsequent brief retrieves ≥1 promoted winner into context (the loop demonstrably closes).
- AC4: Distill pass updates `playbook.md` with confidence-scored heuristics; contradicted rules decay.
- AC5: Subagent-economics measure-then-promote evidence recorded before activation.
