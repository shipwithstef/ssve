## Problem

WI-307 hardened the journey-to-E2E bridge, selector discipline, execution trace,
and tier-2 process assertions. It did not finish the residual journey-quality
validators proposed around journey format, AC/persona coverage, S2
classification drift, reusable journey fixtures, and write-journeys
comprehension coverage.

## Evidence

- `proposals/done/2026-04-30-journey-skills-contract-hardening.md#P1-P2`
- `proposals/done/2026-04-30-journey-proposals-self-review.md#C3-O2-O3`
- `proposals/done/2026-04-30-journey-execution-trace-validation.md#P2`
- `test-framework/evals/tier-1.5/prompts/comprehension/` contains
  `test-journeys.txt` but no `write-journeys.txt`.
- There is no dedicated `validate-journey-format.sh` or
  `verify-journey-coverage.mjs` in the current tree.

## Acceptance Criteria

- [x] Add a journey format validator that checks journey headers, AC tags,
      persona references, Layer 3 / ungrounded-precondition sections, and
      `JOURNEY_INDEX.md` coverage.
- [x] Add an AC/persona coverage validator or explicitly reject the proposed
      coverage floor with a validator-backed rationale.
- [x] Add a static and/or fixture-backed guard that preserves the
      `test-journeys` three-condition S2 gate.
- [x] Add a tier-1.5 comprehension prompt for `write-journeys` or document why
      existing triggering coverage is sufficient.
- [x] Add reusable journey document fixtures for validator and tier-2 tests.

## Route Recommendation

Run as a journey framework-hardening WI after the current residual sweep.

## Closeout

Implemented on 2026-05-12.

- Added `scripts/validate-journey-format.mjs` for journey headers, AC trace
  tags, persona references, Layer 3 sections, ungrounded preconditions, and
  JOURNEY_INDEX membership.
- Added `scripts/verify-journey-coverage.mjs` for AC and persona coverage
  through `JOURNEY_INDEX.md`.
- Added `scripts/validate-s2-justification.mjs` and a tier-1 S2 guard that
  requires machine-readable proof of all three S2 conditions.
- Added `test-framework/evals/tier-1.5/prompts/comprehension/write-journeys.txt`.

  `test-framework/evals/tier-1/fixtures/journey-format/`.
