## Goal

produce `~/.svc/capabilities/registry.json` — a persistent, per-builder inventory of paid + free AI/dev resources, separate sub-budgets, quotas, reset cadence, last-verified date, and host mapping.

## Acceptance Criteria

- `node scripts/capability-registry.mjs list` enumerates ≥7 resources from the illustrative inventory in WI-094 (GPT Business, Claude Max ×5, Kimi, Gemini Pro, MiMo, Base44, Namecheap).
- Each entry carries separate-budget capabilities as nested fields (e.g. GPT Business → Codex CLI + Deep Research as separate meters).
- Registry survives across sessions (on disk under `~/.svc/capabilities/`).
- Schema validated by a tier-1 script `validate-capability-registry.sh`.

## File Impact

pure state + CRUD. No recommendations, no cross-project reads, no auto-discovery. One JSON file + one validator + one SKILL.md for updating it.
