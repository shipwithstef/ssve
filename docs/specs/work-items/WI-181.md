# WI-181: Stop completion guard wiring discards hook stdin

## Problem

The framework reliability review found CRITICAL issue F-011: Stop completion guard wiring discards hook stdin.

## Evidence

`hooks/hooks.json` wires the guard as `printf '%s' | bash hooks/svc-task-completion-guard.sh` at [hooks/hooks.json](/workspace/seriousvibecoding/hooks/hooks.json:138), while the guard reads stdin with `INPUT=$(cat)` at [hooks/svc-task-completion-guard.sh](/workspace/seriousvibecoding/hooks/svc-task-completion-guard.sh:16).

## Impact

Host-provided Stop payloads are replaced by an empty string, weakening session-id, subagent, and input parsing.

## Proposed Fix

Wire as `bash hooks/svc-task-completion-guard.sh` when the host passes JSON on stdin, or document and test the intended wrapper per host.

## Resolution

Completed on 2026-05-09.
