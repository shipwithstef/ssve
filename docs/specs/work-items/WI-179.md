# WI-179: Preflight rollout is still 0/79 and advisory-only

## Problem

The framework reliability review found HIGH issue F-009: Preflight rollout is still 0/79 and advisory-only.

## Evidence

`validate-preflight-coverage.sh` reports `coverage: 0 / 79 skills carry a ## Preflight section` while the script always exits 0 at [validate-preflight-coverage.sh](/workspace/seriousvibecoding/test-framework/evals/tier-1/validate-preflight-coverage.sh:45).

## Impact

Missing inputs, unreadable artifacts, and unwritable outputs are still discovered mid-skill.

## Proposed Fix

Add family-level preflight sections and flip the validator from advisory to blocking once each family is migrated.

- Review: [2026-05-09 framework reliability/performance review](../reviews/2026-05-09-framework-reliability-performance-review.md)

## Resolution

Closed 2026-05-11. Preflight coverage is now enforced through `references/preflight-registry.json` plus direct `## Preflight` sections where a skill adds one later. The tier-1 validator is blocking and requires every `skills-manifest.json` `includedSkills` entry to have direct or family-level preflight coverage.

This fixes the original 0/79 advisory failure without editing all 79 skill bodies at once.
