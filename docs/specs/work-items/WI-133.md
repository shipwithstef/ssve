# WI-133: validate-skill-structure.sh flakes — different random skill failure each run with no source change

**Type:** bugfix
**Status:** VERIFIED
**Severity:** medium
**Filed:** 2026-04-27
**Source:** Observed repeatedly during WI-127/128/129/130/131 sweeps — same input files, retry produces different "failing" skill or PASS.
**Lane:** framework

## Symptom

Running `bash test-framework/evals/tier-1/validate-skill-structure.sh` over an unchanged tree produces non-deterministic results:
- Run 1: FAIL on skill A
- Run 2: FAIL on skill B (A passes)
- Run 3: PASS

No source files changed between runs. Other tier-1 validators are stable.

## Hypothesized cause

Likely interaction between `set -euo pipefail` and `grep -q` in subshells when the grep target is a large `find` output piped through xargs/while-read. SIGPIPE on early grep success may propagate to the parent pipeline as a non-zero exit on a randomly-selected iteration.

Possible secondary cause: ordering of `find` output is filesystem-inode-dependent on ext4/wsl2; first-fail short-circuits hide later failures and surface different "first" failures across runs.

## Why it matters

Tier-1 sweeps gate every framework PR. A flaky validator forces retries and erodes trust in the green bar — at some point an agent will re-run "until green" and miss a real regression.

## ACs

- AC-01 — Reproduce the flake deterministically (`for i in 1..20; do bash validate-skill-structure.sh > /tmp/run-$i.log; done` and diff)
- AC-02 — Identify root cause (pipefail/SIGPIPE vs find ordering vs subshell var leakage)
- AC-03 — Patch produces identical output across 20 sequential runs on unchanged tree
- AC-04 — All previously-real failures still detected (regression test: introduce a known-bad skill, confirm validator catches it)

## Out of scope

- Rewriting the validator from scratch (only fix the nondeterminism)
- Migrating to a Node.js validator (would be a separate proposal)

## Workaround until fixed

Re-run the sweep up to 3 times if a single skill fails; if same skill fails twice in a row, treat as real.
