## Problem

WI-314 adds route-time blocker classification and design/plan gates, but the
proposal also called for a first-class `capability-preflight` skill and a
persistent blocker schema for `framework-gaps.jsonl`-style learning. That
persistence layer is not implemented by the WI-314 route-time classifier.

## Evidence

- `proposals/done/2026-04-25-capability-blocker-auto-diagnosis.md#P1`
- `proposals/done/2026-04-25-capability-blocker-auto-diagnosis.md#P2`
- `docs/specs/work-items/WI-314-residual-map.json`

## Acceptance Criteria

- [x] Decide whether `capability-preflight` should be a new skill or an
      extension of `capability-registry`/`capability-concierge`.
- [x] Define a persistent blocker ledger schema for capability gaps, recovery
      attempts, and routed owner skill.
- [x] Add a validator that rejects malformed blocker entries.
- [x] Wire route-workflow or preflight to write/read the ledger without
      duplicating `.svc/lane-tasks-<WI>.json`.
- [x] Add replay fixtures for recovered, blocked-on-user, and false-positive
      blocker states.

## Route Recommendation

Run after WI-314 so the first version can reuse `references/capability-blockers.json`.

## Implementation

- Decision: no new `capability-preflight` skill. The behavior extends
  `route-workflow`, `capability-registry`, and `capability-concierge` so the
  existing preflight and capability surfaces stay authoritative.
- Added `references/capability-blocker-ledger.md` defining
  `.svc/capability-blockers.jsonl` as the durable blocker ledger.
- Extended `scripts/diagnose-capability-blocker.mjs` with `--ledger`,
  `--state`, `--wi`, `--source`, and recovery/false-positive fields so detected
  blockers can be appended through the atomic state writer.
- Added `scripts/validate-capability-blocker-ledger.mjs` to reject malformed
  ledger rows and enforce recovered, blocked-on-user, and false-positive
  state-specific fields.
- Updated `route-workflow` to append and validate the ledger while keeping
  `.svc/lane-tasks-<WI>.json` as the execution source of truth.
- Updated `capability-registry` and `capability-concierge` to read the ledger
  when capability inventory blockers are routed to those skills.
