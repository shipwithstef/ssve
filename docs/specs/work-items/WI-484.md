## Problem

Shared task graphs, contracts, claims, relative paths, and fallback WI resolution can apply one session's completion pressure or writes to another session's work.

## Affected Files

- Session contracts, WI claims, task/completion guards, and receipt ownership resolution
- Absolute worktree path handling and concurrency fixtures listed in the WI-484 manifest

## Acceptance Criteria

- [x] **AC-484-1:** A mutating session has at most one WI/worktree binding; read-only/reviewer/research roles may have zero.
- [x] **AC-484-2:** Fresh foreign claims downgrade to allow/advisory before completion status is calculated.
- [x] **AC-484-3:** Claim schema variants normalize without accepting agent-name-only ownership.
- [x] **AC-484-4:** Completion pressure caps at three and all state paths are absolute/worktree-resolved.
- [x] **AC-484-5:** Two-session/two-worktree fixtures have zero state, receipt, path, or continuation cross-talk.
