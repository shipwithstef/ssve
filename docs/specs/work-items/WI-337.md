# WI-337: End-to-end continuation audit policy

## Problem

WI-198 made `execution_mode: end_to_end` a real session mode and blocks
permission-seeking stop trailers. The source proposal also asked for auditable
continuation decisions, blast-radius thresholds, and recursion limits so
automatic continuation is distinguishable from arbitrary unilateral decisions.

Those policy details are not yet first-class artifacts.

## Evidence

- `proposals/done/2026-05-08-end-to-end-execution-without-permission-checkpoints.md#F-07`
- `proposals/done/2026-05-08-end-to-end-execution-without-permission-checkpoints.md#Open-Questions`
- `hooks/svc-task-completion-guard.sh` blocks stop trailers, but does not record
  a dedicated continuation decision type.
- `.svc/pipeline-decisions.jsonl` accepts general decision records, but has no
  typed `end_to_end_continuation` policy contract.

## Acceptance Criteria

- [x] Define an `end_to_end_continuation` decision record shape with original
      commitment phrase, seam crossed, gap classification, and next action.
- [x] Add route-workflow guidance that records that decision whenever
      verification-discovered same-lane work auto-continues.
- [x] Define recursion/continuation limits for auto-filed child WIs before
      escalation.
- [x] Define blast-radius thresholds that still pause under end-to-end mode
      (destructive git, paid spend, schema/data risk, security escalation).
- [x] Add a tier-1 fixture proving the decision record is required for
      auto-continuation across a verification seam.

## Route Recommendation

Run after the current proposal residual sweep; this is policy hardening on top
of WI-198, not a replacement for WI-198's stop-hook enforcement.

## Closeout

Implemented on 2026-05-12.

- `route-workflow/references/end-to-end-continuation.md` defines the
  `end_to_end_continuation` decision record, recursion limit, and blast-radius
  pause thresholds.
- `route-workflow/SKILL.md` requires the decision record when end-to-end mode
  crosses a verification/review/closeout seam and discovers same-lane work.
- `scripts/validate-end-to-end-continuation.mjs` validates continuation
  records and requires matching decisions for task-graph mutations marked
  `requires_continuation_decision`.
- `test-framework/evals/tier-1/validate-end-to-end-continuation-policy.sh`
  includes failing fixtures for missing decision records and risky continuation
  without a pause.
