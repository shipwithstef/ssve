# WI-322: Work item archival and open-backlog hygiene

**Type:** chore
**Status:** backlog
**Severity:** medium
**Filed:** 2026-05-11
**Source:** OPEN-PROPOSALS.md FP-019
**Lane:** framework
**Related:** WI-132, WI-222

---

## Problem

Verified work items remain in the primary index indefinitely, making open backlog scans noisy. The framework needs an archival rule for old verified/done items so active work remains readable without losing audit history.

## Evidence

- `OPEN-PROPOSALS.md` FP-019
- Current `docs/specs/work-items/INDEX.md` contains many verified historical WIs before the active backlog entries.

## Acceptance Criteria

- [ ] Define archival criteria for VERIFIED/DONE/CLOSED work items.
- [ ] Add or update a script to rotate eligible closed WIs to `DONE.md` or `INDEX-ARCHIVE.md` while preserving links.
- [ ] Ensure `list-work-items` reads the archive correctly and keeps default output focused on open work.
- [ ] Add a validator fixture for archived and active WI parsing.
- [ ] Document the final status lifecycle.

## Route Recommendation

Run as a low-risk framework housekeeping WI after critical validation connector work.

## Notes

This should not delete historical evidence; it should reduce active backlog noise.
