## Problem

`scripts/wire-hooks.mjs`, `wire-kimi-hooks.mjs`, `wire-codex-hooks.mjs`, and
`wire-gemini-hooks.mjs` each install hooks per their host's settings format.
Today no tier-1 validator confirms that the same set of canonical gates is
enforced across all 4 hosts. A bypass closed on one host can stay open on
another silently.

## Scope

### In scope
- New `references/canonical-gates.json` with 5 gates and per-host MUST/MAY mapping
- New tier-1 validator `validate-cross-host-hook-conformance.sh` enforcing the matrix

### Out of scope
- Per-host hook smoke-mode wrappers (R-3 step 3, future WI)
- Adding G-4 (skill-artifact-authenticity) to host wire scripts (deferred — currently MAY)

## Acceptance criteria

1. canonical-gates.json declares ≥5 gates with must_hosts / may_hosts arrays. ✅
2. Validator greps each (gate, host) MUST pair and HARD FAILs on missing. ✅
3. MAY gates are SOFT WARN only. ✅
4. Day-1 baseline: all MUST checks pass (no day-1 fail). ✅ 12 MUST passed, 0 failed
5. Tier-1 sweep passes. ✅
6. lint-skills-manifest clean. ✅
