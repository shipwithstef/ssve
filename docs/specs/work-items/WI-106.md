## Goal

implement the three lenses as an on-demand skill `capability-concierge`:
1. Ship-the-current-project lens — smallest move to push the highest-priority unfinished project toward first revenue. Invokes `roadmap-evaluation` and `assess-market-readiness` under the hood.
2. Idle-resource lens — which resources in the registry are under-used this reset window vs capacity.
3. Side-earning lens — invoke `find-opportunity` filtered by the capabilities the builder actually holds.

Output is a single ranked list: recommendation + lens + rationale + required resource + acceptance test if executed.

## Acceptance Criteria

- Invoking `capability-concierge` on a fixture (registry + cross-project snapshot + mocked reset windows) produces exactly one ranked recommendation per lens (3 recs) with evidence-graded rationale.
- Every recommendation cites the registry entry + snapshot row it came from.
- No hallucinated capabilities — if a recommendation references a resource not in the registry, the skill fails with an explicit error.

## File Impact

runs on existing state. Does not maintain state. Does not do auto-discovery. Reinvestment doctrine is a configurable parameter here, not a separate WI.
