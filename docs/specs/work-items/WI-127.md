## Goal

Stop the immediate noise: the 2 most user-visible Kimi hooks (`svc-kimi-session-start.sh`, `svc-kimi-preflight-guard.sh`) emit `/flow:svc-lane-executor` and `/flow:svc-auto-router` strings on every Claude SessionStart and UserPromptSubmit. Those slash commands don't exist outside Kimi.

## Phase 1 (this WI)

Add early-exit host guard to both hooks: if `detect-host.sh` returns anything other than `kimi`, exit 0 with no output. Self-disabling — works even when host's settings.json incorrectly wires the hook.

## Out of scope (follow-on)

- Phase 1.5: guard the other 17 kimi hooks the same way
- Phase 2: build host-parity hooks under `hooks/claude/`, `hooks/codex/`, `hooks/gemini/` — emit skill-based reminders instead of flow-based
- Phase 3: doc sweep across `route-workflow/SKILL.md`, `strategic-decision/SKILL.md`, `templates/.svc/orchestrator-state.json`
- Phase 4: tier-1 validator `validate-host-flow-leakage.sh` to catch future regressions
- User's local `~/.claude/settings.json` cleanup (out of repo scope)
