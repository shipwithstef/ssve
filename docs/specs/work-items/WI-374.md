## Policy facts (confirmed from official sources, 2026-06-07)

Announced 2026-05-14, effective **2026-06-15**, no grace period. Programmatic usage
exits the subscription pool into a separate monthly **Agent SDK credit**, billed at
**standard API list rates**, per-user, **no rollover**, one-time opt-in to claim
(email instructions before 06-15; refreshes automatically after).

**Counts against the credit:** `claude -p` (headless), Claude Agent SDK (Py/TS),
Claude Code GitHub Actions, third-party apps authenticating via Agent SDK/ACP (Zed, JetBrains).
**Stays on subscription:** interactive Claude Code TUI — including Agent-tool
subagents, Workflow fan-outs, and hooks inside interactive sessions — claude.ai,
Cowork (incl. scheduled tasks), direct API keys (separate pay-as-you-go).

| Plan | Monthly credit |
|---|---|
| Pro | $20 |
| Max 5× | $100 |
| Max 20× | $200 |
| Team Standard / Premium | $20 / $100 |
| Enterprise usage-based / seat-Premium | $20 / $200 |

**Exhaustion:** credit drains first; overflow to usage credits at API rates only if
explicitly enabled, otherwise requests **hard-stop** until cycle reset. Community
mental model: the "Enter Key Test" — human pressed enter → interactive; automation
pressed it → credit.
