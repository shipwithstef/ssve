## Goal

One owner invocation can finish a workflow that requires a fresh host session.
The framework persists a hash-bound baton, launches the configured native
transport exactly once, transfers or delegates authority, consumes structured
proof, and closes out. Owner copy/paste is a last-resort blocker, not the
normal path.

## Boundaries

In scope: continuation baton schema, `svc-auto-drive` lifecycle, land/verify
hooks, exactly-once launch receipts, result consumption.

Out of scope: re-implementing WI-502 authority; implementing Execution
Controller v2 Luna/capsule runtime; dispatch policy itself (WI-551).

If a host exposes no automatable fresh-session transport, return an explicit
capability-limited blocker. Do not remap to Claude.

## Acceptance Criteria

- [ ] AC-552-1: A WI with `requires_fresh_session` lands, launches one fresh proof session, verifies, and reports without another owner prompt.
- [ ] AC-552-2: Proof session id differs from the implementation session and starts after the deploy receipt.
- [ ] AC-552-3: Reconcile does not spawn a second session after a valid launch/result receipt.
- [ ] AC-552-4: Child is mechanically denied `diagnose-bug`, `plan-changeset`, and `execute-changeset`.
- [ ] AC-552-5: Read-only proof needs no mutating lease. Closeout mutation uses an isolated worktree and generation-bound handover. Canonical main stays clean.
- [ ] AC-552-6: Launch asks resolver role `verify.restart`. Grok stays Grok when configured.
- [ ] AC-552-7: Child returns schema-valid evidence. “Prompt to send” is a failure.
- [ ] AC-552-8: Ordinary verification without restart launches zero new sessions.
- [ ] AC-552-9: Parent-process death after launch resumes from receipts.
- [ ] AC-552-10: Focused tests cover the happy path with a fake transport. Live Grok launch is scheduled in WI-546, not this WI’s unit budget.

## Migration

Disabled by default until a host manifest declares `fresh_session_launch` and
the owner policy names `verify.restart`. Existing manual closeout remains the
capability-limited path.

## Rollback

Disable the controller. Surface one explicit blocker after land. Do not treat
prompt copy/paste as success.

## Provider cost

One native session per declared restart boundary. No paid review relaunch.
