**T2-A. Long-output-to-file pattern**
- Skills emitting > N tokens write to file + chat summary instead of pure inline output.
- Evidence: WI-076 close-out failed "Prompt is too long"; multiple sessions had transcripts truncated.
- **Promote when:** we hit one more output-length truncation that an inline summary can't fix; OR when CLAUDE.md "Response Length" rule proves insufficient on its own.

**T2-B. validate-feature cannot be skipped without explicit override**
- Pipeline mechanically refuses to advance past a lane step that requires validate-feature unless an override is logged to `.svc/pipeline-decisions.jsonl` as `taste`.
- Evidence: WI-077 skipped validate-feature, classified entities as KILL on missing-code reasoning, full revert + v2 rerun.
- **Promote when:** WI-095 (hard close-out gate) lands — verify whether 095's gate already catches this; if not, file as standalone.

**T2-C. Strict TDD loop in route-workflow**
- Phase 1 must commit a *failing* E2E test against current production before any implementation begins. Phase 2 implements until local green. Phase 3 deploys + retries against prod up to N times. Close blocked unless prod is green.
- Bigger version of WI-095. Differs by being structural (test-first contract) rather than gate-only (verify-at-end).
- **Promote when:** WI-095 lands AND we observe ≥2 sessions where the close-out gate caught a problem too late (i.e. would have been caught earlier by red-test-first).

### Tier 3 — aspirational, file when foundations are solid

**T3-A. Parallel multi-lane execution**
- Spawn parallel sub-agents per lane (spec/design/implement/E2E/deploy/verify) within a single route-workflow invocation. Coordinator enforces dependency ordering and quality gates.
- Source: /insights "On the Horizon".
- **Promote when:** WI-095 + WI-097 + WI-098 all landed AND verified stable across ≥10 sequential runs (so we don't multiply premature-completion or number-collision failures by N).

**T3-B. Nightly autonomous backlog burndown**
- Scheduled agent picks top 3 unblocked WIs at 11pm, runs route-workflow autonomously to production, posts a 7am digest. Auto-pauses on non-recoverable error.
- Source: /insights "On the Horizon".
- **Promote when:** T3-A is landed and burning down WIs reliably in foreground sessions. Adding a scheduler before that just multiplies risk.
