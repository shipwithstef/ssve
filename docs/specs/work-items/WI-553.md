## Goal

When a change matches a small risk-flag set, extra plan/exec contracts become
mandatory and are checked mechanically. Unmatched work pays zero extra model
review.

## Boundaries

In scope: flag table, design-tech skip denial, `plan-contract.json` optional
sections, mechanical plan checks, execute completion gated on receipts.

Out of scope: host wirers, SessionStart healthcheck, dispatch, continuation.

## Acceptance Criteria

- [ ] AC-553-1: Shared flags: `runtime_concurrency`, `external_state_writer`, `config_schema_migration`, `lossless_rmw`, `idempotent_rewriter`, plus existing `cross_runtime_integration`.
- [ ] AC-553-2: “No product UI / no data model” cannot skip `design-tech` when any AC-553-1 flag is set or implied by planned files.
- [ ] AC-553-3: `plan-contract.json` grows only the matched sections.
- [ ] AC-553-4: Mechanical review rejects WI-542 shapes: check-then-write under concurrency; one backup path as both immutable baseline and rolling rollback; “preserve user entries” without a fixture per documented entry type.
- [ ] AC-553-5: `execute-changeset` cannot complete without schema-valid `plan-manifest`, `review-plan`, and `exec-record` for the current tree (staging allowed pre-commit).
- [ ] AC-553-6: A docs-only or parser-only bugfix with no flags skips the extra path. Negative fixture required.
- [ ] AC-553-7: Synthetic WI-542-shaped plan fails; the corrected shape passes. No paid provider.

## Migration

Flags default off. Only new/changed graphs are evaluated. Existing completed
graphs are not rewritten.

## Rollback

Revert flag table, skip checker, plan-contract extensions, mechanical checks,
and execute completion gate together. Do not weaken money/ownership
plan-contract or the pre-push 5-receipt envelope.

## Provider cost

None at plan time. No extra adversarial review stage.
