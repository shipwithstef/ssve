## Problem

The company-operating-fleet runs a weekly unattended cadence and the ad fleet levels up from a campaigns ledger, but neither has a *loop-state contract*: no watermark of what was already processed, no dedupe keys, no per-entity cooldowns, no in-flight guards, and no cap/allowlist/kill-switch machinery for any future promotion of a brain from propose-only to bounded execution. svc's mandatory chain guards *commits*, not *recurring external actions*. Upstream coreyhaines `marketing-loops` solved this (state file + two-tier action model + guardrails); this WI ports the governance layer, svc-native.
