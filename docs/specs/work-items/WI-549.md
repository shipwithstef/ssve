## Goal

Every linked worktree, closeout tree, and canonical checkout observes the same
owner-selected chain-policy mode, with provenance. Missing or unreadable policy
must not silently downgrade `refuse` to `warn`.

## Boundaries

In scope: policy resolver used by pre-commit, pre-push, `svc-reconcile`,
Stop/finalization, and worktree create/reattach.

Out of scope: receipt identity (WI-550), host adapters (WI-545/WI-546),
dispatch policy (WI-551), review-evidence store (WI-547).

## Acceptance Criteria

- [ ] AC-549-1: Resolution order is `SVC_CHAIN_POLICY` → `$(git-common-dir)/svc-chain-policy.json` → `~/.svc/chain-policy.json` → fail-closed `refuse`.
- [ ] AC-549-2: A worktree without `.svc/chain-policy.json` still observes the shared refuse mode of the canonical clone.
- [ ] AC-549-3: A worktree-local file that disagrees with the shared file is a conflict, not a silent override; stderr/receipt names both paths and hashes.
- [ ] AC-549-4: `svc-ensure-worktree` and `worktree.sh create` do not treat a per-worktree copy as authority.
- [ ] AC-549-5: Focused tests cover missing local file, shared refuse, conflicting local file, env override, and provenance report.
- [ ] AC-549-6: No paid provider is invoked.

## Affected files / contracts

- `scripts/svc-reconcile.mjs`
- `scripts/check-chain-receipts.mjs`
- `hooks/git/pre-commit.d/*`, `hooks/git/pre-push.d/*` policy readers
- `scripts/svc-ensure-worktree.mjs`, `scripts/worktree.sh`
- new `scripts/lib/chain-policy.mjs` (single resolver)
- focused tier-1 `validate-shared-chain-policy.sh`

## Migration

Seed `$(git-common-dir)/svc-chain-policy.json` from the current canonical
`.svc/chain-policy.json` once. Existing worktree-local files remain as
non-authoritative mirrors if byte-identical; otherwise they fail closed until
reconciled.

## Rollback

Keep `scripts/lib/chain-policy.mjs` as a fail-closed reader of
`$(git-common-dir)/svc-chain-policy.json` (missing → refuse). Remove only
new worktree-copy/mirror writers. Do not restore silent warn-on-missing.

## Provider cost

None.

## Overlap

Absorbs the WI-358 follow-up “worktrees see mode=warn.” WI-358 stays VERIFIED.
