## Problem

WI-205 corrected the false hook claim by making live visual evidence a
route-workflow task-graph obligation, and `_shared/live-evidence.md` now defines
the capture contract. The remaining residual is automation and integration:
there is no framework-level capture helper that projects can invoke directly,
and motion-heavy landing work has no validator that checks it uses the canonical
motion pattern reference when motion is present.

## Evidence

- `proposals/done/2026-05-05-evolution.md#P0-F1`
- `proposals/done/2026-05-05-evolution.md#P2-F5`
- `_shared/live-evidence.md` defines the screenshot/report contract but leaves
  script internals to project-local copies.
- `landing-page/SKILL.md` references `references/motion-patterns.md`, but no
  tier-1 validator enforces citation or use when motion code is introduced.

## Acceptance Criteria

- [x] Add a reusable capture helper or documented project-local generator path
      that emits the `_shared/live-evidence.md` matrix and `report.json` shape.
- [x] Add a tier-1 validator or skill self-verify check that visual-output skills
      with motion cite `references/motion-patterns.md` or use its canonical
      tokens.
- [x] Include reduced-motion handling in the validator or explicit self-verify
      row.
- [x] Add fixtures for motion present with citation, motion present without
      citation, and no-motion visual work.
- [x] Keep the obligation framed as task-graph enforcement unless a real
      host-installed hook is added.

## Route Recommendation

Run as visual-evidence hardening after the current proposal residual maps are
complete.

## Closeout

Implemented on 2026-05-12.

- Added `scripts/live-evidence-capture.mjs --init <file>` to generate a
  project-local Playwright capture script that emits the required viewport/theme
  matrix and `report.json`.
- Updated `_shared/live-evidence.md` to name that generator while preserving the
  task-graph obligation framing.
- Added `scripts/validate-motion-pattern-usage.mjs` to require canonical
  motion-pattern citation/tokens and reduced-motion handling when motion is
  present.
- Updated `landing-page/SKILL.md` to run the motion validator for motion-bearing
  visual work.
- Added `test-framework/evals/tier-1/validate-visual-evidence-motion.sh` with
  good, bad, and no-motion fixtures.
