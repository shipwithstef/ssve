# WI-222: list-work-items ignores YAML-frontmatter WI status

## Problem

`list-work-items/scripts/list_work_items.mjs` only parsed legacy markdown fields like `**Status:** VERIFIED`. Newer WI files use YAML frontmatter, so verified items with `status: verified` were misclassified as open backlog.

## Impact

Backlog ranking was polluted with already-closed WIs, which undermines the framework-evolution loop's "rank current list" requirement.

## Fix

`list_work_items.mjs` now parses scalar YAML frontmatter for `status`, `priority` / `severity`, dependencies, and dates, while preserving legacy markdown-field support. `SVC_WORK_ITEMS_DIR` allows hermetic fixture validation.

## Closeout

Closed 2026-05-10.

Evidence:
- `bash test-framework/evals/tier-1/validate-list-work-items-frontmatter.sh` — PASS
- `node list-work-items/scripts/list_work_items.mjs --json` — verified YAML-frontmatter WIs are excluded from the open backlog
