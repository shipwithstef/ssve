# WI-184: `svc-wi-pillars-check` is still a soft warning on VERIFIED

## Problem

The framework reliability review found HIGH issue F-014: `svc-wi-pillars-check` is still a soft warning on VERIFIED.

## Evidence

`hooks/hooks.json` says `SOFT WARN` and `Never blocks` for WI pillar verification at [hooks/hooks.json](/workspace/seriousvibecoding/hooks/hooks.json:75).

## Impact

A WI can be marked verified while pillar coverage is malformed.

## Proposed Fix

Promote VERIFIED transitions to hard block. Keep warnings only for draft/in-progress edits.
