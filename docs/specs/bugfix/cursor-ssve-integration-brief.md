# Cursor CLI SSVE integration and authority recovery

WI: WI-546 (WI-FW-CURSOR-CLI-01). Resolves Cursor CLI SSVE hook integration, native wire protocol, prompt authority arming, and authority-v2 worktree recovery.

## Reproduction
1. Cursor CLI parses flat hook entries in `~/.cursor/hooks.json`. Nested `matcher` / `hooks: [...]` entries generated by earlier wirers cause `TypeError: paths[0] ... Received null` in Cursor CLI internal bundle `190.index.js`.
2. Lack of a dedicated `beforeSubmitPrompt` adapter prevented Cursor from arming positive prompt authority leases (`SVC OWNER OVERRIDE`) or recording prompt authority into `.svc/prompt-authority.jsonl`.
3. Cursor CLI pretool hook execution requires native wire protocol output `{ permission: "allow" | "deny" | "ask", user_message, updated_input }`. Standard Codex JSON output or non-zero exit codes cause unexpected host errors or broken input piping.
4. Unchecked `fs.realpathSync` on dead or unpruned temporary worktrees in `git worktree list --porcelain` threw unhandled `ENOENT` crashes during worktree scanning.
5. In `scripts/svc-ensure-worktree.mjs`, external worktrees with active `controller-lease-v2` (`tuple.state === "v2_present"`) were rejected by `existingResumeApproval` and lacked a recovery branch in `resumeExisting`.

## Correction
1. Created `hooks/cursor/svc-cursor-ssve-adapter.mjs` implementing `--before-submit-prompt` (records prompt authority, arms owner override) and `--pretool` (handles safe observation fast-path, rewrites `Shell` via `updated_input`, delegates mutation governance to Codex pretool dispatcher).
2. Updated `scripts/wire-cursor-hooks.mjs` to emit flat `{ "command": "..." }` entries for Cursor hooks and wired `beforeSubmitPrompt` and `preToolUse`.
3. Updated `hooks/codex/svc-codex-pretool-dispatcher.mjs` and `hooks/lib/hook-decision.mjs` to recognize Cursor host identity and emit native `{ permission, user_message, updated_input }` responses.
4. Wrapped worktree path resolution in `try/catch` across `scripts/svc-ensure-worktree.mjs` and `hooks/codex/svc-codex-pretool-dispatcher.mjs` to safely skip vanished paths.
5. Added `v2_present` support to `existingResumeApproval` and implemented V2 controller lease recovery/resume in `resumeExisting`.
6. Updated `provision/hosts/cursor.json` and tier-1 acceptance validators to declare `beforeSubmitPrompt` and `preToolUse`.
