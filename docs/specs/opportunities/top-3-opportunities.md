### #1: WordMind AI — Personalized Daily Word Game

**Score:** 70 / 100 | **Evidence Strength:** 5 / 10

**Category:** Mobile Game (Word/Puzzle)
**What:** Like Wordle, but the daily word is AI-generated based on your interests (movies, sports, science, memes). Share your personalized puzzle with friends.
**Reverse-engineered from:** Wordle (2M daily players, sold to NYT for $1M+)

**Evidence:**
1. Wordle reached 2M daily players and sold to NYT for low-seven-figures (public, 2022)
2. NYT Games subscription ($40/yr) has 10M+ subscribers — word games convert to paid
3. Wordle clone "Worldle" (geography variant) hit millions of players — mechanic is endlessly remixable
4. Mobile word games are a top-10 App Store category with proven IAP revenue
5. "Connections" (NYT) and "Strands" (NYT) prove the puzzle-a-day model still works in 2024-2025

**Why you:**
- React Native/Expo = same stack Wordle mobile clones use
- AI integration is a single OpenAI API call with structured JSON output
- Viral share mechanic is built into the game design (share your result grid)

**MVP:**
- Interest selection screen (pick 3 topics: movies, sports, tech, music, etc.)
- AI generates a 5-letter word related to your interests
- Standard Wordle gameplay (6 guesses, color feedback)
- Share result as text/image
- Daily streak tracking

**Revenue Model:**
- Free: 1 personalized puzzle/day
- Premium ($2.99/mo or $19.99/yr): Unlimited puzzles, custom word lengths, create puzzles for friends

**Infrastructure:**
- Replit (free Agent + deploy + DB)
- React Native/Expo (iOS + Android)
- OpenAI API (user-funded via credits)
- Replit built-in auth + database

**Distribution Plan:**
1. First 10: Post in r/wordle, r/puzzles, r/iosgaming with "I made a Wordle that learns what you like"
2. First 100: TikTok/Shorts showing "my Wordle was 'PIXAR' because I picked movies" — personalized = viral
3. Scale: App Store ASO for "wordle alternative," "personalized word game"

**Build Time:** 18-22 hours

**Risks:**
| Risk | Mitigation |
|------|------------|
| NYT could send cease-and-desist | Don't use "Wordle" name. "WordMind" or similar. Mechanics ( Mastermind ) are not copyrightable. |
| AI generates offensive/inappropriate words | Content filter on prompt. Pre-screen with banned word list. |

### #2: PixelHabit AI — AI-Powered Habit Tracker Game

**Score:** 70 / 100 | **Evidence Strength:** 5 / 10

**Category:** Mobile Game (Lifestyle / Gamified Productivity)
**What:** Track habits → AI generates pixel art rewards. Build a pixel world with your streaks. Like Habit Pixel but AI generates infinite art.
**Reverse-engineered from:** Habit Pixel ($0 → $1K MRR in 8 months, React Native/Expo, solo dev)

**Evidence:**
1. Habit Pixel (IndieHackers, Jan 2026): React Native habit tracker → $1K MRR, $4.99/mo premium
2. Habitica (5M+ users): Gamified habit tracker proves the RPG-habit crossover works
3. Forest (30M+ users): Focus timer + virtual tree proves gamified productivity monetizes
4. Streaks app (Apple Design Award): Simple habit tracker = premium App Store feature potential
5. Pixel art aesthetic is trending on TikTok/Instagram (retro gaming nostalgia)

**Why you:**
- Identical stack to Habit Pixel (React Native/Expo) — proven path
- AI art generation = differentiation from Habit Pixel and Habitica
- You already know this stack from Example Marketplace (React)

**MVP:**
- Add habits (name, frequency, color)
- Check off habits → AI generates a pixel art tile
- Tiles combine into a pixel world/cityscape
- Streak counter with pixel art character that grows
- AI generates new tile types based on habit category

**Revenue Model:**
- Free: 5 habits, basic tiles
- Premium ($4.99/mo or $29.99/yr): Unlimited habits, AI art themes, custom pixel characters, export world as wallpaper

**Infrastructure:**
- Replit (free Agent + deploy + DB)
- React Native/Expo
- OpenAI DALL-E 3 or image generation API
- Replit built-in auth + database

**Distribution Plan:**
1. First 10: r/productivity, r/getdisciplined, r/habitica — "I made a habit tracker that AI-draws pixel art"
2. First 100: TikTok showing pixel world growing over time — satisfying visual content
3. Scale: App Store ASO for "habit tracker," "pixel art," "gamified habits"

**Build Time:** 20-24 hours

**Risks:**
| Risk | Mitigation |
|------|------------|
| AI image generation costs | Use DALL-E 3 only on habit completion (not every render). Cache tiles. Cost per user ~$0.10/month. |
| Habitica is free and established | AI art + better mobile UX differentiates. Habitica is cluttered and web-first. |

### #3: Suika AI — Physics Merge Game with AI Objects

**Score:** 70 / 100 | **Evidence Strength:** 5 / 10

**Category:** Mobile Game (Physics / Puzzle)
**What:** Drop and merge objects. AI generates new object chains and themes. Like Suika Game but every theme is AI-generated (food, animals, tech, emojis).
**Reverse-engineered from:** Watermelon Suika Game (1.1M plays, viral on TikTok, simple physics)

**Evidence:**
1. Suika Game went viral on TikTok/YouTube with 100M+ views across creators
2. Suika Game clones flooded App Store and Google Play — some hit top-10 free games
3. Physics puzzle games have low dev complexity but high engagement (satisfying "pop" sounds, visual feedback)
4. 2048 (merge mechanic predecessor) had 10M+ downloads — merge genre is proven
5. Mobile ad revenue for hyper-casual/physics games: $0.01-$0.05 per play session, scales with volume

**Why you:**
- Physics engine (Matter.js) works in React Native
- AI generates object SVGs/themes — infinite content from one codebase
- Extremely demo-able: judge plays for 30 seconds, gets it immediately

**MVP:**
- Basic physics container (drop objects from top)
- Two identical objects merge into next tier
- 10 object chain (e.g., emoji: 😀 → 😂 → 😍 → 🤯 → 👑)
- AI generates new themes on demand ("generate a food chain" → 🍒 → 🍓 → 🍎 → 🍊 → 🍉)
- Score + high score

**Revenue Model:**
- Free with ads (rewarded video for undo/continue)
- Premium ($2.99): Remove ads, unlock all themes, custom themes
- Theme packs ($0.99 each): Space, Ocean, Dinosaurs, etc.

**Infrastructure:**
- Replit (free Agent + deploy)
- React Native + Matter.js (physics)
- OpenAI API for theme generation
- AdMob or similar for mobile ads (free to integrate)

**Distribution Plan:**
1. First 10: r/gaming, r/casualgames, r/iosgaming
2. First 100: TikTok/Shorts showing satisfying merge moments — "AI generated a tech theme and I got to iPhone"
3. Scale: App Store "New Games" feature, ASO for "merge game," "physics puzzle"

**Build Time:** 16-20 hours

**Risks:**
| Risk | Mitigation |
|------|------------|
| Physics can be buggy/janky | Use well-tested Matter.js. Keep object count low (<20 on screen). |
| Ad revenue requires volume | Launch free, add premium IAP. Ad revenue is bonus, not primary. |
