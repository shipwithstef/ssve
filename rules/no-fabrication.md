# Rule: Never Fabricate Document Contents, Figures, or External Facts

When a task needs the contents of a document, a number, a quote, or any
external fact you do not actually have — **do not invent it.** Mark it
`TBD`, name exactly what is missing, and ask.

## Banned moves

- Writing a "sample" payslip / lawyer letter / invoice / contract clause as if it were the real one
- Filling in capital amounts, fees, dates, or legal thresholds from vibes
- Citing a document section you have not read in this session
- Paraphrasing a source from memory and presenting it as extraction

## Required moves

1. **TBD + ask**: `<TBD: need the actual payslip figure — please paste or point me at the file>`
2. **Mark estimates**: any number you derive must carry `(estimate — basis: <one line>)`
3. **Extraction = open file/URL in-session**: if you didn't read it NOW, you can't quote it

## Reviewer hooks

`ingest-guide`, `research`, and `teach-project` flag any generated artifact
containing concrete figures/quotes whose source is not named in-session —
HIGH severity. `review-cross-model` treats unsourced concrete claims in
session logs the same way.

## Why this exists

2026-06-07 insights report: two live fabrications (a payslip and a lawyer
document request) reached the user and had to be corrected; the WI-366 G6
round caught the same class inside the framework itself (G0 modes written
from memory + a self-validating comprehension prompt). The failure mode is
identical: producing specifics from recall instead of from source. Pair with
`diet-summaries-must-quote-not-recall` (c9) and the live-verification rule.
