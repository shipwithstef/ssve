## Blend items

### 1. Metric-Based Design Dials → `design-ui/SKILL.md`

**From:** `skills/taste-skill/SKILL.md`
**Into:** `design-ui/SKILL.md` (New: Aesthetic Configuration section)

**The problem in svc today:**
Design requests are currently purely qualitative (e.g., "make it look clean"). This leads to "safe," middle-of-the-road designs that satisfy the literal prompt but lack the specific "vibe" the user intended.

**How the source solves it:**
Uses four explicit dials (Creativity, Density, Variance, Motion Intent) on a 1-10 scale. This forces the model into a specific "distribution" of its training data (e.g., Variance 10 = artsy/chaotic asymmetry).

**What this changes in svc:**
The `design-ui` skill will now output an **Aesthetic Config Block** in the UI spec. The agent will read this block to decide whether to use symmetric grids or bold editorial layouts.

**Why this matters:**
It transforms "Vibe Coding" from a guessing game into a deterministic engineering process.

### 2. "Liquid Glass" Refraction → `design-ui/SKILL.md`

**From:** `skills/taste-skill/SKILL.md` (Section 4: Liquid Glass)
**Into:** `design-ui/SKILL.md` (Component Styling Patterns)

**The problem in svc today:**
AI-generated "glassmorphism" usually just applies `backdrop-blur`. This looks fake and lacks the physical depth of premium agency-level work.

**How the source solves it:**
Mandates a 1px inner border (`border-white/10`) and a subtle inner shadow (`shadow-[inset_0_1px_0_rgba(255,255,255,0.1)]`).

**What this changes in svc:**
Adds a mandatory "Materiality" check to `design-ui`. Any component using blur MUST also use refraction highlights.

**Why this matters:**
Increases the perceived "cost" and quality of the generated interface without adding code complexity.

### 3. Inline Image Typography → `design-ui/SKILL.md`

**From:** `skills/stitch-skill/DESIGN.md` (Section 5: Hero Section)
**Into:** `design-ui/SKILL.md` (Hero Section patterns)

**The problem in svc today:**
Hero sections generated by AI are often centered text over a generic image. This is a classic "AI Slop" fingerprint.

**How the source solves it:**
Embedding small, rounded, contextual images directly between words in the H1. It uses images as "visual punctuation."

**What this changes in svc:**
Adds this technique as a "High-Variance (8+)" recommendation in `design-ui`. When the Creativity dial is high, the agent will attempt this editorial layout.

**Why this matters:**
It is a signature technique that immediately differentiates the output from standard "bootstrap-style" AI generations.

### 4. Hardware-Accelerated Motion → `design-tech/SKILL.md`

**From:** `skills/taste-skill/SKILL.md` (Section 5: Performance Guardrails)
**Into:** `design-tech/SKILL.md` (Frontend Constraints)

**The problem in svc today:**
LLMs often animate `height`, `width`, or `top/left` (CPU-based), which causes "jank" (stuttering) especially on mobile devices.

**How the source solves it:**
Strictly bans animation of any property except `transform` and `opacity` (GPU-accelerated).

**What this changes in svc:**
The `design-tech` skill will now include a "Motion Guardrail" section that explicitly forbids non-transform animations in the technical spec.

**Why this matters:**
Ensures that the "expensive" agency look doesn't result in a "cheap" laggy feel.

### 5. Full-Output Pause/Resume → `execute-changeset/SKILL.md`

**From:** `skills/output-skill/SKILL.md`
**Into:** `execute-changeset/SKILL.md` (Persistence Model)

**The problem in svc today:**
On long files (e.g., a complex dashboard), the AI starts using `// rest of code here` to save tokens or avoid time-outs. This breaks the implementation and requires the user to manually fix it.

**How the source solves it:**
Forbids placeholders and provides a specific "Pause/Resume" message format for the agent to use when approaching limits.

**What this changes in svc:**
Adds a "Completeness Protocol" to `execute-changeset`. If the file is too large, the agent stops at a clean breakpoint and waits for "continue" instead of truncating.

**Why this matters:**
Eliminates the #1 friction point in large-scale implementation tasks.
